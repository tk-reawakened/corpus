# 3/3/05 Wet Dream Soon to be Reality

by John@aljo on March 3, 2005
After getting done with the NES PC its time to start looking for another wierd case to build as we got to replace our Server computer next. Well we had just acquired a snail and a beta fish and found out that they make a good combo as pets. We now need a bigger home for them and what better way to do it than a Fish Tank, computer case combo. Yep the next wonderful idea from the AlJo Bros will go and benefit all homeless beta's everywhere :P. I am right now currently designing the case. Trying to figure out the dimensions and crap that we need to make everything. This isn't no plexiglass box like aquariums are. No, we have a computer that must go in it, be cool, and most of all not get wet. Talk about a challenge. Interesting fact of the day, to hold once gallon of water, it takes a 6.14"X6.14"X6.14" (15.6cmX15.6cmX15.6cm)cube box. That is right handy information to know when building an aquarium :P. Best of all this project all in all is going to cost us about ummm $160 for all the parts that we need.
