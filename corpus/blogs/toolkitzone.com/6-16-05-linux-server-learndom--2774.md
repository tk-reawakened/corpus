# 6/16/05 Linux Server Learndom

by John@aljo on June 16, 2005
Yep. Thats what I have been doing in my free time lately. Trying to find some good tutorials on setting up a nice running Linux server computer. Though now days most Linux Distrobutions come with the wonderful Desktop managers, Server programs are usually command line which give us Desktop Dummies a headache. A nice gui can make any program simple. Command Line and text file configuration can be just the oppisite. I am in luck though! Learn by example is my style of learning and have been able to find a book that is much to that style. I managed to get my hands on a out of this book . I must say I was impressed on how easy it was to understand so I figured I would get the full book as it covers more of what I need to learn how to do. My other books and documentation for Linux command line programs usually do not explain the situation as easily as that sample chapter did. I now have 3 of the services for my current server machine figured out in this alternate OS. I am hoping that this move will negate any problems I am having sharing files across the internet. Besides what I have ran on this computer as the sample server has shown me that much less resources are used on Linux than that on Windows 2000 Server and I am using Mandriva! I admit it is a memory hog as far as linux distros go but it waumps all over ths Win2000 system of mine. Not only that but I can keep it on command line and be able to view logs without the brightness of a desktop at night. I mean I have changed my windows on the server to all black and white but still all the lines and buttons and stuff get rather noisey with light at night, but I leave the monitor on so when I get up to lets say, get a glass of water I can look over at it and see what is happening. Also plus of just command line is the vga text font is so much easier to read at night. on windows, they do not have a font installed that is near as clear to read as the vga font. We will just see how this goes. so far I can use linux for my every day computer needs, now to use it for what it was ment for, Server applications. If anyone has any tips on why websites cannot access my webpages via php please share your ideas here. I can not seem to find the problem, I am running a Windows 2000 Server Machine Apache 2.0 McAfee Desktop Firewall 7.5.1 That should be all that can be related to the problem. need more info PM me or comment here. I might also try running Xitami again to see if that helps any, Xitami was great and ran right out of the box with minimal configuration. Apache was just a tad harder to set up so it may have been a configuration error on my part. I am not sure. The only reason I stopped using Xitami is because at times it could be unstable and crash once in a blue moon while Apache has yet to crash once.
