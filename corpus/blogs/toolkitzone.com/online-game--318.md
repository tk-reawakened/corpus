# Online Game

by US Patriot on May 19, 2004
I was reading some forums and stuff and all of the sudden I came up with the idea why don't we all try to create our own online game. I have been dreaming of creating an online game that was real-world sized. My dream was to make it so that anything could be done, There would be an area only for combat or a store and stuff like that. Anyway that is unrealistic using toolkit. I was thinking more of a medival game or something along the lines of that. I think if everyone pitched in we could create a game like this really fast. Course it would be hard, but we have all the tiles and everything we need. It would be cool. Now I want to hear what other people have to say about this.
