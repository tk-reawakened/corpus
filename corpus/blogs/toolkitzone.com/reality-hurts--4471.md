# Reality hurts.

by Isolocis on June 2, 2006
Betrayal In Antara was one of the best RPGs I have ever played, despite the dated graphics and certain flaws. Since it can only work on slower computers, I played it on my Dad's old laptop. The sad thing about playing it on the latest computers is that I move too fast in software rendering travel, it has unexplainable, severe graphical glitches, and the game always crashed when loading battles. The game played well and I was about to complete the first CD. One day, I noticed that my first CD is missing. My Dad brought the laptop with him to work. I assume that the CD is still inside the computer so I waited until he brought it back home. I opened the CD drive and found nothing inside. I already searched the house for it so I conclude that I lost it. So I am stuck with the two other CDs and now I have to start the whole game from the beginning again. Playing in areas that you have already completed before can be pretty boring. And it reminds me of the "permanent death" idea that is going around in some MMOG communities.
