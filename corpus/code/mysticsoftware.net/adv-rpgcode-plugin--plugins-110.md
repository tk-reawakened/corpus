# Adv RPGCode Plugin

Plugins
Adv RPGCode Plugin
This is quite the novel plugin idea. Basically what BP does is rips all the callbacks from the plugin SDK and puts them into RPGCode, so you the normal RPGCode programmer can use them. A bit harder to use than some of the other plugins, but definitely gives you the most bang for your puck. Check it out to greatly expand your RPGCode world!
