# Jer1400's Image Editor

Misc Programs
Jer1400's Image Editor
Here we have another very cool paint program, written entirely in RPGCode. This image editor is mouse based, making it easier to use than Matt's and also comes with the feature of being able to save and load its pictures through the read-write plugin. Despite lacking some of the neater tools, this is certainly the RPGCode paint program standard!
