# Mystic Software

Methods
Custom Button
This cool set of methods from Martin will allow you to make an unlimited amount of buttons from any image, without using #SetButton! It was also the first released program to use 2.18+ new array system. Useful for things like battle systems where you may have a lot of buttons, but a limited internal TK button amount.
