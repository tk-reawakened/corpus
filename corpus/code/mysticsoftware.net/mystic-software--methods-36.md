# Mystic Software

Methods
DTS's Stat System
Another stat system, this one without any predefined stats and thus a bit more customability, but lacking some of the advanced stat-fiddling functions of Wintermoon's. Still a good way to get into the custom stat scene, and it's very easy to use for those of you constantly requesting a custom stat option.
