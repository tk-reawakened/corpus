# Mystic Software

Menus
DOS Menu
A sweet DOS based interface system. Almost an exact replica of our old friend DOS, with an easy way to add commands. Very customizable, but it doesn't come with a lot of default commands. Still great to check out if you're planning on a computer in your game or something (or you just love DOS)!
