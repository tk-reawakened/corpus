# Never Fail R/W Plugin V2.2

Plugins
Never Fail R/W Plugin V2.2
Rather boldly titled plugin from the Aljo brothers. Not only does it support ordinary read/write functions, it also has a shell function and allows you to print documents to the printer. If other r/w plugins don't offer enough for you, check it out! This Release of the Read Write plugin sports a nifty Append function and a split command for splitting strings. It also includes a few bug fixes to keep some of the read functions from sending back garbage.
