# Race Generator

Miscellaneous Resources
Race Generator
This application generates a random race with sometimes weird results for you to use in your games. This will help you break away from the whole "Human, Elf, Dwarf" thing. I haven't cracked a way to come up with suitable names yet, but maybe for the next release. Enjoy. This was programmed in Visual Basic. Just click the generate button to generate a random race.
