Scrollbar Menu
This method pack contains various commands for making a menu with a scrollbar. You can make multiple menus at once with different IDs, use custom graphics for the background, scrollbar and cursor, change the keys used for input, add and remove options from the menus and clear the menus from the screen again afterwards, all with very little coding effort.
