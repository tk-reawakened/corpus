# Wintermoon's Stat System

Methods
Wintermoon's Stat System
This stat system sets up predefined custom stats like Strength, Dexterity, Vitality, and Magic, but comes with an excellent algorithm system and can be modified to work with the stats you want. Be warned, a tad complicated for the newer coder, and the algorithm functions are a bit flakey, but it does come with instructions, if you want to dare it.
