# bits and bobs

By Xavier
As many of you have noticed, I coded a quick and easy poll feature for the frontpage. It's a nice way to check the activity of the community as well as obviously asking interesting questions. Only registered users can vote, guests will only see the results. You can now find the feature within the files menu option above. Files you have submitted to the site now appear as . The My Files tool will be expanded further next month when the codebase arrives. Overall, the recent changes have made the site much more organised behind the scenes from a developers point of view - allowing further expansion much easier. I also had a bit of fun and put together what I call the page. When you load the page it calculates all sorts of statistics for the site in a sentence format. Check it out, it's good fun (2,000+ blog comments!). The page has also finally made it's way back into the new design. And last but not least I also fixed up the news archive pages. With summer holidays coming to a close, I'll wrap up the design changes this week with a few more minor changes; the game section re-design being finished up, poll archives, integrating latest version of Matt's rpg code script and very possibly user ratings for files.
