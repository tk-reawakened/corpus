# bits and bobs (part 2)

By Xavier
Good to see the last poll got such a healthy response with 118 different users voting, I have added a new poll so check it out to your right. You can now access an archive of previous polls by clicking "view poll archive" once you have voted. I have added two new BBCode tags to the forums, making life easier when linking to things on this site. If you want to link to a game profile, simply put; A Game Replace X with the games id number and also replace the text within the tags with whatever text you want to link. There is also a blog tag; A Blog Again, replace X with the user's id number to go to their blog. You can now find a reference to all of our new bbcode tags here. My holidays are running out fast, just a few days left, so I might do a few more small changes here and there before the week is out.
