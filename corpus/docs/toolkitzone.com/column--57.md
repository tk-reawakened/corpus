# column

Games > Dev Gallery
First of a new series highlighting the latest game images posted on the screenshot forum, a great way to help give developers feedback on their latest work.
Welcome to the first edition of the Dev Gallery [DG]. The purpose of this column is to help expose some of the latest creations that have been posted on the screenshots forum to a wider array of users via the frontpage, which will hopefully give the game developers more feedback on their work. Displayed is the image in question, which you can click to go to the forum topic, the game title, date of post and a very brief description of the image. A selection of one or two feedback comments already given at time of publication are also included.
