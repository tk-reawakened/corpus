# column

Games > Dev Gallery
A quiet week for the screenshots board, so just two games getting the spotlight this week; Marovia and Leviless Woods.
The purpose of this column is to help expose some of the latest creations that have been posted on the screenshots forum to a wider array of users via the frontpage, which will hopefully give the game developers more feedback on their work. Displayed is the image in question, which you can click to go to the forum topic, the game title, date of post and a very brief description of the image. A selection of one or two feedback comments already given at time of publication are also included.
