# downtime

By Xavier
I apologise for the 20 hour downtime, but it was completely out of my hands. Something was wrong with the database software on the host's server and any pages that require database access errored out. Sorry for the troubles. I am setting up a mirror server so hopefully in the future it won't matter if one goes down. Elsewhere I made a couple of slight adjustments to the games section view to keep it in line with recent design changes.
