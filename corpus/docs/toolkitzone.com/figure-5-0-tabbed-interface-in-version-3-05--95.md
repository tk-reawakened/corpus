# Figure 5.0 ? Tabbed Interface in Version 3.05

Browse
TK3 Amelioration V ? User Interface
Unfortunately, version 3.05 is not available yet. That does not, however, mean there aren?t more exciting things to tantalize you with. Many would say that while TK3 has excelled in just about every imaginable area, it still has failed to provide you with even the most basic of simple, clean editors. Rather, providing you with an incoherent mess that takes weeks to find your way around. The coming version attempts to change all that.
I have been hearing a lot about ?s newfangled next-generation tabbed interface. Apparently, it even works with Windows XP?s visual styles. Supposedly, users are draws to this tool by its editor alone. Well, you know what they say ? if you can?t beat them, join them. The RPGToolkit, Version 3.05 will feature an amazing tabbed multiple document interface?reminiscent of professional development studios like ?and boast full support of XP visual styles. *Fury 2* *Visual Studio .NET*
![](http://toolkitzone.com/vault/documents/60.PNG)
**Figure 5.0 ? Tabbed Interface in Version 3.05**
When new editors are opened, they appear in a tab strip along the top of the main window. Scroll bars, buttons, et al appear in the XP visual style when it is available. The silly ?skinned? windows that the public hated so much have also been removed and replaced with fully-xp-skinned versions.
These improvements, as well as the others you?ve seen, are all being thoroughly tested, not only by me and the other developers, but also by select bug-hunters. Thanks in part to these measures; Version 3.05 should be one of the most stable released of the TK ever.
![](http://toolkitzone.com/vault/documents/61.PNG)
**Figure 5.1 ? Main File Editor with Windows XP Visual Styles Applied**
As you can see, if more than the maximum number of windows than can fit in the tabs are opened, they can be scrolled left and right with small arrow buttons ? a nifty feature in itself.
Sorry about this particularly short article ? rest assured that once 3.05 is released, I?ll be able to enlighten you on many more things. Whatever the case, the next time you hear someone being drawn to rival editors because of tabbed interfaces, redirect them to the RPGToolkit, Version 3.05.
