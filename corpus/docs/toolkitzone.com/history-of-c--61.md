# History of C++

C++ Basics A1 This is a new series of articles to help you move on from RPG Code to the (almost) limitless powers of C++, and is written in two parts: The history of C++ and Beginning C++.
***History of C++***
Before we begin, it may be important to know some history of C++. C was considered by most as the start of modern programming, and C++ is simply and expanded and more complex version of C. C was invented and first used by a person named Dennis Ritchie on a DEC PDP-11 using Unix. C was part of a developmental process that began with BCPL, an early language. From BCPL sprang B, and developed of B was C. Before C, languages were used mainly for academica purpose and trade corporations. C was different, it was made and developed by real working programmers (like might already be). C's features were tested and developed and rethought of by the people who actually used the language! Because of the fact that C put programmers themselves in control, it quickly became widespread. It became the favorite of many 70' and 80's programmers. C was made with the structured programming philosophy, which began in the 1960's as the need for developing moderately large and complex programs became imminent. You might be wondering now why the hell would you need something different if you already had such a good and widespread language like C? The easiest answer for that would be complexity. By the 1970's, programs were getting to complex and large for even structured programming to handle, and the need for something different arose. As a response to this growing concern, the newest way to program unleashed itself onto the world: OOP (object oriented programming). Using this, the programmer was able to develop even more and more complex programs without everything turning into spaghetti code. Seeing this need, a man named Bjarne Stroutstrup invented a programming language called C with Classes, four years of development later it became known as C++ (I think they got the idea of that from the increment operator :-/). Ever since C++ was originally created there was three major revisions, the latest one being the standardization of C++, the ISO (International Standards Organization) and ANSI (American National Standards Institute) grouped together for a few years and worked out what C++ standards should be. One major note of what happened during the standardization is a contribution by someone named Alexander Stepanov. He introduced C++ to the STL, or standard template library. Another thing you might want to know before we get to coding is how C++ relates to two other modern programming languages: C# by Microsoft and Java by Sun Microsystems. Both of those languages is simply a modified C++ with features added, removed, and changed to suit others' needs. One main differential factor is speed and portability. Java and C# both have intermediate translators, Java's is known as Java Virtual Machine (JVM), and C#'s is Microsoft Intermediate Language (MSIL), to make each language completely portable to other operating systems. Let me explain how this works... If you compile C++ code with a compiler, you get a result machine code that can be executed by your computers CPU, which you might notice means that it is OS and CPU dependent, Java and C# however, first compile your code into their intermediate language, (commonly known as bytecode), then the byte code is translated by the JVM or MSIL to suit your OS and CPU. You might recognize at this point that would generate some kind of overhead- well thats true, portability comes at a cost. C++ on the other hand, is extremely fast and efficient because it is specific. If you are just reading this to pick a modern language to learn, keep this in mind: it is not which language is better, simply which language will perform your task better then the others. If you want fast high end applications, choose C++. If you want to sacrifice a bit of speed and power for portability, pick Java or C#. Get on with the coding shall we? In order to effectively learn a language, its best to practice as you learn. It is your choice what kind of compiler you get, but I would recommend Bloodshed Software's Dev-C++. Most of the code in this series is dedicated to it. For all projects use Dev-C++ "Empty Project" type. I'll get into windows and DLL etc much later in this series. Most of this code will also compile under Microsoft's Visual C++.
***Beginning C++***
I will start with a simple "Hello World" program and explain the parts after. Please replace the asterisks(*) with lesser then and greater then symbols, as this document editor thinks they are HTML tags. //This program will display "Hello World" /* Written by Lord Partikle */ #include *iostream* #include *stdlib.h* using namespace std; int main(int argc, char *argv[]) { cout < < "Hello World\n"; system("PAUSE"); return 0; } Once you compile this program with Dev-C++, it simply types Hello World in a command prompt window, and "Press and key to continue....". The first two lines of this example are the two types of comments. For shorter, single line comments people usually use //, for anything longer then a line, I use /* comment line one comment line two */ Comments are simply for the programmers' ease of use and readability, the compiler ignores them. The next two lines use the 'include' preprocessor. I will explain them in more detail on later parts of the series, until then, just stick with those whenever you write a program (in this case, the second preprocessor line isn't needed). Under the preprocessors is the namespace, I will explain namespaces in greater detail when you have a better understanding of C++ for now, suffice it to say is that the namespace you are using now contains the STL (standard template library). Below the namespace declaration is the main function (or method if you're a Java junkie). Every C++ program has a main function, and only one main function. You have more then that, and it gives you an error message >. < . Each C++ method (and RPG Code) has brackets; these brackets can transfer information and variables, known as function arguments. The arguments currently residing in the main function right now are a bit more advanced, so I will explain them in greater detail later on. Again, trust me ^_^. To maintain good programming practice, after each function (i.e. main) put a curly brace and another when it ends, all the information inside a curly brace is known as a block of code. Use these with all your functions. The next line has a cout (console output) identifier, followed by a < < (output operator) and a string of characters to display between and ". One common practice with programmers who are writing smaller programs simple say: std::cout < < "blah blah blah", instead of declaring that your using the whole namespace, again, more on this later. The remaining two lines of code are simply for the command prompt, the system pause is only so that the user has time to actually read the program, for a better understanding, remove system ("PAUSE") and see the result. The return 0 simply ends the program, and it will be explained in more clarity on the next article, as it contains variables, operators and program control statements (this one being boolean). Then the program ends with a closing curly brace from the main function. As a last note, all statements (lines of code, with the exeption of functions) end with a ; (semi-colon).
