# Marz

Browse
Outstanding Literary Contribution
![](http://toolkitzone.com/vault/documents/1249.png)
A return to celebrating community contributions to the website as we roll into day eight, after jackyboy picked up the Outstanding Forum Contribution on Wednesday. It's a dying art in recent years, but nothing helps a user more than a well written tutorial or insightful guide. So today we're handing out an award for Outstanding Literary Contribution and it's not just limited to tutorials but also interviews, articles, commentaries, and so forth. Anything that goes in the library.
** And the winner is...
His primary contribution for which he getting this award is a continuing work in progress, constantly being refined and added to as the months pass by. The RPG Code tutorial is a mammoth compilation of code explanations and examples, broken down into several chapters starting from the basics about variables through to custom message windows. It's one of the most viewed and highly rated resources available and has been a great resource to new users and those still on the learning curve.
I am, of course, talking about...
**Marz**
