3.0.4 september release
Latest release is finally here, if a little late, packed with features.
Hi, everyone. Well, it's a month late, but I think the wait was worth it. is available for download now. The TK3 dev team really came together on this one, as I'm sure you all know from seeing the previews. You can access the source code release from the project page. You can download the binary release (tk3ce.zip) from sourceforge, or from the TK3 section . Enjoy!
