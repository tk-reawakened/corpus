concepts and actualisation
New frontpage and library concepts begin development.
You know, I think I need to take CBM's lead and start plucking lyrics out of some songs for my news titles, because there are only so many generic subjects you can use :P. No big news, just keeping you up to date on the current development of the site which might interest some. I should probably put this in a dev blog - but hey. I actually started work on the new documents system that will be the backend for the new frontpage and library concepts. I won't take you through the boring features in detail, but it'll support differing document types, multi-paged articles, assigning documents to a series, html and images, publishing system, editor/author notes during the drafting process and a few other bits. I'm away during the weekend, but hopefully the beta for this can be made available to the couple of writers already chosen to test next week. After that, I can concentrate on the cosmetics end of things (ie: how the frontpage and library section will look and be structured) over November and hopefully launch on TKZs anniversary. And for some bizarre reason I began a little bit of work on TK3 once more, putting in the ground work for what I call the "Multi-Tile" mode for the board editor. Basically, it allows you to select more than one tile and apply a single action, such as; set a program, set tile type or erase tile.
