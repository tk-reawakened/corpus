News on the next TK release and confirmed fixes/changes/additions.
A lot of people have been asking when the next TK3 release will be ready to ship, and I thought I'd address those queries here. Right now, unlike previous releases, we have set no firm deadline to work for as a group. We have talked of a tentative Christmas date, a suitable present for all, but this is yet to be confirmed. This release we have been using the CVS system throughout, meaning development has been much more fluid and robust for each developer. So what does this mean? Expect the next release to be just as jam packed as previous versions. Delano has put up a list of the latest confirmed fixes. changes and additions for 3.0.5 online . Check it out every few days as developers will be adding their finished work every now and again. As for a more concrete release date, expect more accurate dates come December.
