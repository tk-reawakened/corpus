Marovia
William's demo release based on a character of the same name. Features complete original graphics and custom battle system.
| First demo release of Marovia, a world in which a young man called William lives - and that's about all you get from the plot at the start of the game. The most impressive factor about this game has to be that it is seemingly 100% original. Tiles, animations, backgrounds - all created by William. The boards are well designed, not too sparse, and the tile art is consistant throughout, which is one of the many benefits of not using ripped sets. The battle system is very unique, allowing not only the usual attack/magic/run options but also involves you and the enemy moving around the board when fighting. So for example, for hand-to-hand combat you need to actually move next to the enemy you want to attack. No game ending bugs from first sight, but there are a few spelling errors which can be fixed with ease and the transparency effect is a little off at times but that's due to current TK3 version, not the creator. I highly recommend you play this well put together game, it definately exceeded my expectations. | [GAME PROFILE](/games.php?game=15) [DOWNLOAD](http://www.mysticsoftware.net/games.php?mode=2&category=-1&game=138)
