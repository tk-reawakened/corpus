Mortalis
Play as Bert in this promising adventure from Serge, sporting a flash battle system and sprites designed by Sophia.
| Mortalis was created by Serge and features your character Bert, with the game opening with your mother telling you to go to the graveyard and so the adventure unfolds from there. The sprite graphics were created by the talented Sophia (see Dustball, Rudolph's Adventure), while the rest of game uses original tiles by Serge plus the default fence tiles which give the demo a false appearence of using ripped tiles more than it does - surely it won't take too long to make original versions? It also sports a custom battle and menu system, and its real edge comes in the fact the former is made in flash and integrated into the game using Triuken's Flash plugin, which can be found . A fun demo that offers up to an hour of gameplay, which is rare for the average demo. So go play! | [GAME PROFILE](games.php?game=706) [DOWNLOAD](http://www.b.rpgtk.com/mortalis.exe )
