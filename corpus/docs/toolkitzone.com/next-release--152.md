# Next Release

By Xavier
After the relative success of 3.0.5, the development team are well aware of the still numerous bugs and issues residing in the editor and especially in the engine. As a result, the next released has been tagged as a "Bug Fix Only" version. The devers will endeavour to fix as many bugs as possible, and not waste precious energy and time on adding new things to the Toolkit. So for this release, it's imperative you guys report on the forums all the bugs you come across so we can hopefully capture a vast majority of them!
