# Open Sesame

By Xavier
I'm glad to say the documents tool no longer has restricted access and is now open to all users to create and manage documents they wish to submit to the library section. You should see the documents link appear as part of the My Files tool. Upon creating a new document you can edit its content as pure html, meaning you have full control of font and colors if you so wish. Images can also be uploaded to be used within that document or all of your documents. The documents tool allows you to filter and sort your entries by status (draft, re-draft, outbox and published) as well as title, date and so forth. When you've finished editing your document you submit it for publication, you can retract this at any time. Upon submission an editor will review your entry and do one of two things; publish or reject. Reject isn't as harsh as it sounds, it merely means the document enters a "re-draft" phase where you can make further changes. To aid the writing process, there is a simple "notes" page for each document. This allows you, the author, and the editor to discuss and leave notes on the document. For example, if a document is rejected the editor will leave reasons as to why. I hope many of you take up the opportunity to write tutorials, articles, interviews and so forth for the library. Soon there will be a more thorough help page on the documents tool as a whole, as well as the do and do nots when it comes to what to write about.
