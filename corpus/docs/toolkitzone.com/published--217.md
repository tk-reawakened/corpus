# Published

Browse
I am pleased to announce the arrivial of the bugfix only release, which addresses a whole array of issues in the editor and engine that have plagued users in recent versions. So what can you expect fixed in this release? You can find a complete list . This is the first release to also be fully documented and supported by our brand new and extensive online help site which you can find . A big thank you to Colin and Delano who did the all the development work this time around, they agreed to stick to the bugfix ethos from day one and produced an amazing number of fixes. Also thanks should go to Occasionally Correct for his writing skills in the new references and help files. This was the first release to publicly release periodic builds to help test the development, but in the last two or three weeks we've also had some dedicated behind-the-scenes guys using their projects to push the Toolkit to the limit and expose any problems. These guys, with thanks going to them, are; Ashe, Caliber Mengsk, Codester, Khin, oblivious_casualty, RDemusX and Serge. Some issues still remain that were far too complex and/or time consuming for this release, such as some of the Win9x problems. But the developers are already thinking ahead on how to set about fixing these in future releases - they haven't been ignored! If you encounter any problems when installing, please check out article which has some relevant information. Well, I won't delay any further. You can get the brand new Toolkit release by clicking . Hope you all had a good Easter holiday, happy game making! [here](library.php?mode=read&doc=216) [here](http://tk3.toolkitzone.com/help/)
