Isometric Tutorial
This is the first in a series of isometric tutorials for the board design of the Lost Epic, using MS Paint. In this tutorial we will make the basic house.
![](http://toolkitzone.com/vault/documents/1141.PNG)
1. Start by making the southwest and east baselines using the line tool. Then copy and paste both lines to make the northwest and east baselines.
![](http://toolkitzone.com/vault/documents/1143.PNG)
2. In most cases you would start building the house from the ground up, but considering its isometric it is the opposite. Easy copy and paste the original baselines and drop it to the depth of your choice.
![](http://toolkitzone.com/vault/documents/1144.PNG)
3. Lets make the roof. Find the center of the southeast wall and make a line. The longer the line the greater the angle or pitch of the roof will be.
![](http://toolkitzone.com/vault/documents/1145.PNG)
4. The door doesn’t have to have a circular top since it can be any design you chose. Make a oval, with the circular tool. Then use the far end points to make lines that drop to the base line.
![](http://toolkitzone.com/vault/documents/1146.PNG)
5. Lets add the illusion of depth. Use the southwest and east baselines as a guide then push the door inward.
![](http://toolkitzone.com/vault/documents/1147.PNG)
6. Simple window. Use the north and south lines above and below the window to keep symmetry
![](http://toolkitzone.com/vault/documents/1148.PNG)
7. Simply do the same with the door to the window.
![](http://toolkitzone.com/vault/documents/1149.PNG)
8. Adding frames to the door and window.
![](http://toolkitzone.com/vault/documents/1150.PNG)
9. The pop out on the roof can be tricky. Use the same principles from step 3. Using all baselines and pitch of the roof as guidelines.
![](http://toolkitzone.com/vault/documents/1151.PNG)
10. Adding the window. Should be as easy as adding the base level window and door.
![](http://toolkitzone.com/vault/documents/1152.PNG)
11. Now adding the framing.
![](http://toolkitzone.com/vault/documents/1153.PNG)
12. Add base colors and decide where the light source is. To allow the illusion of depth and shading, choose a range of several colors. Here I have choosen a range of browns, darkest to light.
![](http://toolkitzone.com/vault/documents/1154.PNG)
13. After setting the base colors make the boards. It doesn’t have to be vertical they can also be horizontal if you choose.
![](http://toolkitzone.com/vault/documents/1155.PNG)
14. Then to add the effect that they are boards add horizontal lines and nails. The roof is simple use the line tool to make it look like bricks.
![](http://toolkitzone.com/vault/documents/1156.PNG)
15. The finished piece. Using a lighter color then the base color of the roof. Chose random roof tiles to color in.
