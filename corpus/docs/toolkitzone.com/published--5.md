# Published

Browse
After a suggestion from fellow staffy Asimir, I have now added the option to view "entire entry" for blogs, so now it's like it used to be. Click "view all user entries" and you can read entry by entry down the page, as well as using the additional search and sort tools. Same "entire message" option is apparent on the main blog page and search page. Also added is a new menu so you can quickly add an entry or view you own blog directly from the blog section. I'll add the ability to edit and remove comments as well by the end of the day. Elsewhere, I have tidied the "my files" tool up to suit the design and look less stretched. Next on the "refine" list is the "my games" tool, which has dozens of pages. After that, all should be looking proper. I can then set about re-adding the new links section and adding any suggestions you guys make.
