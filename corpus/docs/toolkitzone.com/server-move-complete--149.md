# Server Move Complete

By Xavier
Well, this time around the move was an absolute breeze compared to the last one which was a disaster due to various reasons. Please note that FTP access for game profiles are yet to be enabled, but expect that to be sorted by the end of the day. I also advise all uber members to check the private forum for information relating to the server move and its impact on their own ftp and database details. If you spot an error which might be as a result of the move, please contact me via PM immediately. Thanks.
