# Testing, Testing...

By Xavier
It has been a couple of months since the last news, so I'd thought it best to keep you guys and girls up to date on the forthcoming release of the Toolkit. Designated a bug fix release, meaning developers are fully concentrated on finding and fixing bugs, 3.0.6 looks set to remedy a whole range of issues that have plagued users in TK3. Right now it's undergoing strenuous testing behind the scenes by a number of active game developers who can put the engine and editor to the sword. There have been far too many fixes thus far to list here, but you can find what is now an out-dated list by clicking . Although it is not possible to fix every single problem due to the complexity of some, the sheer number that have been addressed makes this arguably the version 3 release that finally surpasses TK2 in all areas. Also thrown in is an extensive help file that abandons the usual one page for all format and uses drop-down menus and categories to split the editor and aspects of the Toolkit into an easy to understand format. Designed by Colin, with the writing talents of Occasionally_Correct and Delano also included, it's a huge upgrade for all users. You can find the latest online version . So watch this space for more news as testing continues and we look to a release date.
