# Tinker, tinker...

By Xavier
I've been bogged down with exams these past weeks, but today with nothing better to do and an acute resistance to education I broke out into a code modding frency. Here's a list of the various tinkerings you may or may not notice; + Viewing blogs show user info such as avatar, location and recent entries in right column. + Cannot edit/delete blog comments after they have been responded to (directly or not). + Mods now have full moderation tools in the blog section. + Users can now report posts to moderators by clicking red exclamation button at top right of a post. + Automatic double-posting prevention for normal users. + Moderator control panel so moderators can edit excessive signatures etc themselves. + Users can collapse/expand the uber forums, this is always "remembered". + As opposed to bans, we can now remove posting rights of individual users. + User list for who's in chat now working and will no longer crash forum index (thanks to Colin for fix). + Special icon next to a private message denoting if you replied to it or not. + Quick reply for private messages. That's all for now, tomorrow it's back to the exam nightmare. If you have any more small suggestions for the forums and site feel free to comment here or send me a PM.
