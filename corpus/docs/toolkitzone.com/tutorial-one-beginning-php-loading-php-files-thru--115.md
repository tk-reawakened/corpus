# Tutorial One: Beginning PHP -(Loading .php files THRU PHP Designer)

Welcome Note
Welcome, this sub-article under is going to teach you step-by-step on loading a *.php file. [Tutorial One of Beginning PHP](http://www.toolkitzone.com/library.php?mode=read&doc=114)
Spoon Feeding
Follow the screens, and texts, it'll be easy.
Open up PHP Designer (no screen). Then, open up the *.php file that you want to load in your browser for testing, double click to open it. (Figure 1-1)
![](http://www.toolkitzone.com/library/images/docs/122.png)
Fig. 1-1
Next, in the top toolbar, point to Options --> Editor Preferences, or simply hit CTRL+E in the editor. (Figure 1-2)
![](http://www.toolkitzone.com/library/images/docs/123.png)
Fig. 1-2
Then, set your PHP interpreter and click "OK". (Figure 1-3)
![](http://www.toolkitzone.com/library/images/docs/124.png)
Fig. 1-3
Finally, point to the top toolbar, and point to Run --> Run and Debug, or simply hit F5 in the editor itself. (Figure 1-4)
![](http://www.toolkitzone.com/library/images/docs/125.png)
Fig. 1-4
