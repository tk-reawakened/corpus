3.1.0 Release
On behalf of the TK3 Development team I am very happy to announce the release of RPG Toolkit 3.1.0. The core of the release is the complete re-write of the engine in C++ that has led to, amongst other things, a brand new RPG Code interpreter and vector based collision system. The RPG Toolkit is now released under the GNU General Public License (GPL) to ensure the Toolkit will always be protected as open source software.
You will have to spend some time updating your current project before it will function in 3.1.0 as expected, thankfully the release features an RPG Code Updater and Board tile-to-vector conversion routine to help you. These will correct most but not necessarily all compatibility issues.
This release, as with any other, will not be bug free and we welcome your feedback in the way of bug reports. It is important that if and when you report any issues you ensure they are genuine bugs and not a result of incompatible code or human error.
Finally, for those of you using Vista you will have to ensure the software is set to "Run as admin", do so by right-clicking the executable and selecting the option.
Some highly recommended reading;
- - Details many of the changes and compatibility issues to take note of. [ReadMe](http://rpgtoolkit.cvs.sourceforge.net/*checkout*/rpgtoolkit/build/readme.txt?revision=1.20)
Thank you for reading and , [enjoy 3.1.0](http://www.toolkitzone.com/toolkit.php?downloads)
