# Abbrievated RPG Code Reference

Shortened version of the reference that comes with the RPG Toolkit for those who quickly want to check the syntax as opposed to have fully blown examples.
posted by on 2004-01-08 03:12:26 [TrentonZero](forums/profile.php?mode=viewprofile&u=113)
I did this because the orginal reference was over 100 pages long printed. This version has the examples and some of the more repetitive command definitions stripped out. It is about 12 pages printed. That way, you can have a hardcopy to study while away from the computer without burning a whole ink cartridge and half a ream of paper printing it.
