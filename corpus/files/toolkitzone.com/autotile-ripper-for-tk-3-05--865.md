# AutoTile Ripper (for TK 3.05+)

For ripping AutoTiles, which will be supported in the next TK3 release. AutoTiles are tilesets with tiles arranged in a certain preset, meaning when you apply them to your board it automatically draws them in a certain manner. Converts AutoTiles from RPG Maker XP, RPG Maker 2000/2003, Sim RPG Maker, and prearranged AutoTileset images, including some RPG Maker 95 tilesets, to tk3 compatible AutoTilesets.

To enable autotiler mode, click the autotiler button to the right of the iso mode button on the board editor's tools flyout. Select an autotileset via the usual method, you can pick any tile in the tileset. You can then draw using the normal drawlock/eraser tools, and the autotiler will handle the rest. In addition, you can hold shift while drawing to temporarily disable autotiling of inactive autotiles - this is useful for say, if you had deep water embedded within shallow water, you wouldn't want a coast to appear around the deep water. An autotileset is just a normal tst file arranged in a certain order, with "autotiles_" preceding its name, e.g. "autotiles_grass01.tst". I imported some example autotilesets from the rpgmaker xp rtp to play with or use as templates. Copy/paste to download - http://www.angelfire.com/rpg2/shao113/autotiler-samples.zip HamsterBob: Support for creating AutoTile sets within the TK3 IDE is not planned atm, but this utility does the job fine: just draw them in the RPG Maker XP format and import.
