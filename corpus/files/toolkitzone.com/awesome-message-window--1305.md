# Awesome Message Window

![](games/phpThumb.php?src=../fileman/images/500.PNG&iar=on&w=200&bw=2&bg=000000)
**Awesome Message Window**
Lord_Valanx's message window allows a profile image and text to be specified, as well as optional specification of a transparent colour for the profile image. Everything else is sadly hard coded, plus no commenting for those new to RPG Code to use it as a educational resource. Still, it works well enough.
