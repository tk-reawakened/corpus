# By Akira

Easy Terrain Tile Creation
**By Akira**
*Edited and Converted to HTML by Hablethorn*
The reason for this tutorial is not only to teach the basics of tile creation but also the sometimes-ignored features of the RPGToolkit's Tile Editor. Now people on the RPGToolkit forums seem to have trouble with things the are in fact, simple. In this tutorial you will learn how to make simple but effective terrain tiles using programs readily available on your PC. The first is the RPGToolkit easily available from . The second is probably FAR more advanced its MS Paint! This can be found on all hard drives running Windows 95 or later. Now that you have your programs, well get started.
<www.rpgtoolkit.com>
Chapter 1
* Rating: Stupendously Easy **The all-knowing grass tile**
Now this is the least complex tile you will come across but also the most important. In this tutorial You will learn an easy way to make a grass tile that some might think crude. If you are one of these people, skip this chapter or go away. The RPGToolkit is well suited for this exercise so open that up now (Normally found in Start>Programs>RPGToolkit 2/3). Now once its started open the tile editor. You should now have a blank canvas like this: Now see the little fill bucket that looks a bit like this well click it. Now see this panel at the bottom of the screen? This panel selects colors so we'll call it the Colour Selector Panel (or CPS if you want). Now to select a color from the panel (CSP) you click it so let us select a nice green color (if your not happy with your nice green color keep clicking until you are. Now click somewhere in this area . Now whats this?! Its changed color :o Yes the canvas should look somewhat like this. Now that thats over with go to Tools>Effects>Texturize>Texturize Heavy. Now for the fruits of your Labour your plain green tile should look like this! If you dont like the pattern go to Edit>Undo and then repeat step 4. And there we have it folks, easy grass tile goodness in only four steps (well five if you count the Extra bit). Now I dont want to see a bunch of tiles like this pop up on the forums. I did this to show how easy it is, but please try to keep your tiles original.

Chapter 2
* Rating: Stupendously Easy **The Powerfully Eye-Catching Water Tile**
This tile is simple but effective in any RPG game. This tutorial will teach you one of many different techniques in making a water tile. For the first part of this tutorial, we will be using MS Paint so open that up now (normally found in Start> Programs> Accessories > Paint) You should now have a screen that looks somewhat like this: Now your canvas needs to be 32x32 pixels (32 pixels high and 32 pixels wide) If you know it is skip to part 2, if you're not sure move on to part 1b). To check the size of your canvas click on Image> Attributes (Ctrl+E) a window should now open that looks like this: Of course your 'Width' and 'Height' will be different. Now make sure 'Units' is set to 'Pixels' and your 'Width' and 'Height' both equal 32. Now that your canvas is set up, we can move on. For this next part you will want to Zoom In. You can achieve this by selecting the 'Magnifier' ( ) and then the 8x option that should appear in this box on the left hand side of the screen. Now select the 'Airbrush' ( ) and this option in the same box as before. We now need some color. You should see a panel at the bottom of the screen with different colors in boxes. I'd advise you not to use one of these colors but it's really up to you. If you wish to use one of the colors in the panel at the bottom, make sure it's a shade of blue you choose then skip to part 3)(you will need three blue colors total). If you'd rather use one of your own continue to part 2b). To select your own colour, Double-Click on one of the colors in the bottom panel. A window like this should now appear: Click a shade of blue from on of the boxes then click 'Define Custom Colors >>' the window should now look like this: Change the shade of blue by moving the cross-hair around, Moving the arrow on the side up or down, changing the number in the Red Green Blue boxes, or a combination of these. Once you've done this click 'Add to Custom Colors' now the color you have chosen should appear in one of the white boxes. Create a new blue color 2-3 more times (each time clicking the 'Add to Custom Colors' button) once this is finished select the fist blue colour you made and click 'OK'. Now your ready to paint. You want to spray paint your canvas lightly and the faster you click the lighter it sprays. Make sure the color is spread evenly over the whole canvas. Now double-click on one of the colors in the bottom panel as in step 2b) when the window opens select the second blue shade you made (hehe that rhymes) and repeat this step. Your canvas should now look somewhat like this: Don't worry about those horrible white spots just yet, they will be dealt with in Step Select your final shade of blue (you should be able to do it by now) as usual but right-click on it instead. Now click the Eraser/Color Eraser tool ( ). Then left-click the white color in the bottom panel. The little box beside the bottom panel should look like this: (of course the blue will be different) Now all you have to do is right click on the white spots and they will magically turn blue! The end is in sight! With your new tile looking somewhat like this, you now need to save! Click File> Save As A window will pop up and all you need to do here is select where your tile should go using this box , name it something catchy like using this box , and make sure you've got it set to 24-bit Bitmap using this box . Once your happy with everything click Save, open the RPGToolkit, open the Tile Editor and move onto Step Right last step I promise (for this chapter anyway :p). In the Tile editor (which I told you to open at the end of the last step so if you haven't opened it already do so now! Quickly!) click Import> Import Icon, Bmp, Gif, Jpg, Wmf (Ctrl + I). In the window that follow click Open Picture. A window similar to the save window will open allowing you to find your image. Do so, click on it and click open. The first window should now look like this: Now click Import and your tile is done! You should save it by going to File> Save. Extra) Sorry if I got your hopes up but this is technically the last step. If you want some smooth lookin' water (as many of you 'hip' kids do nowadays) In the tile editor click Tools> Effects> Blur (Ctrl + B) There you have it folks, smoooooooth water just like momma used to make.
