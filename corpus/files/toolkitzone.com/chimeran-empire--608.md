**Chimeran Empire**
"Chimeran Empire is best described as a really good Godiva:Alpha. Though it uses ripped/default for all aspects of the game, this game is the perfect example of how a TK game can depend solely on game play to make it entertaining. Though the demo ends right when the plot begins really unfolding and more gameplay features arrive, the demo still delivers a great gaming experience that anyone in their right mind will enjoy."

To Spyder: I meant better than. Though I enjoyed G:A and will always be a fan of the game as I think you know, this game was better. The game had slightly better board design, and it also simply had more boards to explore and add on the game play length. Neither of the games featured much a plot, though Chimeran Empire did have the better plot just because, basically, the game was longer and had more time to introduce more plot to the game. I forget if the patch fixed the tailsman purchasing in G:A, but when I played G:A, the tailsman didn't work, and I believe that eliminated most if not all of special moves from the game. Chimeran Empire is one of the few TK games that uses a default battle system that has special moves worth using, so that was a great advantage to the gameplay.
