# Click to enlarge

ColorPix
He pretty much summed it up there. This is a great program to use when using the TK's Tile Editor. This little program returns the color value of the pixel that your mouse is hovering over in RGB, Hexadecimal, HSB (a.k.a. HSV), and CMYK formats. You can also lock it, so that when you move your mouse, the values won't change. The program also includes a zoom-able magnifier. This is a great Resource for anybody who pixels. *"This application is useful for getting the RGB color values of a pixel in the tile editor, which is very helpful when creating new shades"-zzz in "Note To Reviewer" file*
