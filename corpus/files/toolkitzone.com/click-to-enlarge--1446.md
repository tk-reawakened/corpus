# Click to enlarge

ChaoTileset
This set contains emotions/walking frames for 15 different chaos as seen in some of the Sonic Games. Some of these are ripped and some might be original, I couldn't track all of them down. But, it is a great tileset if you are making a Sonic game, or if you just need some cute,cuddly things or some evil,cuddly things. (118 tiles)
