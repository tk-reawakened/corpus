# Code Impression

This editor has many useful features such as a command list, tabbed multi-document interface, colour coding and a few wizards. A nicely designed and presented editor. This updated version has a few extra features and fixes.
posted by on 2004-11-22 10:04:32 [Colosseus](forums/profile.php?mode=viewprofile&u=718)
When the file version is set to "(update pending)", it's because it takes a while before the file has been tested and accepted here at TKZ. Meanwhile, the file at http://1080.mysticsoftware.net/files/CodeImpression.zip will contain the newest version available. From version 1.2 and up, there's also an automatic web update function implented in Code Impression, so that you won't have to visit any web sites to find out if there's a new version available. Play around with it and have fun =)
