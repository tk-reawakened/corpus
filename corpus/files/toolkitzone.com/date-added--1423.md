# Date Added

CFuryMsgBox
A message box class for displaying text to the screen. It automatically constrains text in a width/height, and also has the ability to float an image to the side of the text.

Perhaps I should explain. It's not a Message Window. It's not an Mwin replacement. Rather it's a class that you can implement into a custom Mwin. I intended on it accomplishing one simple task without the clutter of extra features. I included an example of how it can be used as a message window. Basically all it does it type out text. It handles a single floating image to the left or right, and handles left, centered, or right aligned text. The text wraps automatically, and will automatically fit inside a set width/height. I left it open ended for anyone wanting to use it on how it can be used.
