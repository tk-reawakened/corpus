# Date Added

Misc Plugin
Jackyboy's miscellaneous plugin holds a collection of functions per users' requests. Functions included are: * Set/get the background image/color for a board. * Save a canvas as an image file. * Get the filename for an item on a board. * Rotate a canvas * Get the number of item slots being used on a board. * Get the board's width/height. * Get an image's width/height. * Get a canvas width/height. * Get the experienced required for the player to progress to the next level. * A function to determine if the game is running as a standalone exe. * Mathematical functions: atan, acos, and asin * Get item by index.
