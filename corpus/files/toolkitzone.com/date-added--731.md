# Date Added

RaceGen
Rather simplistic tool by Mark of the Dragon to generate race descriptions, allowing you to set the environment in which they live. Could be expanded to include more options and a wider vocabulary, but nontheless a nice tool if you want some good-to-go descriptions.
[![TBD](thumb.php?src=forum/images/avatars/10153756344177f94b57e57.jpg&w=60&h=60&iar=false&bw=1)](forum/profile.php?mode=viewprofile&u=58)
As I stated, this is only the first release of version 2. I am adding some features at this time, and I'm writing up a better description method right now. The one thing I'm really looking forward to adding in is the visual representation, which will take FOREVER, considering that I need to sketch the black and white versions first, heh. That will definitely be for version 3 (the final release of RaceGen, then I'm done)

I used this for my Sprenta species, then added some more features such as horns and webbed fingers 'n such.
