# Dragon Warrior

A strange pack - most of these 18 files sound like really bad old ringtones from an ancient phone, however there are a number of different arrangements and remixes included which save this pack from the depths of pantsness. Some would be good for minigames, some for retro-style games. Generally, very old style RPG type things, brought up to date a bit with the new mixes.
