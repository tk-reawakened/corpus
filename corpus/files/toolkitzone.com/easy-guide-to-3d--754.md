# Easy Guide to 3D

Not the best tutorial Ive read, but if youre interested in learning to use some 3D images for your game, then this is the only choice youve got right now at tkz. There are three chapters: 1.Why 3D? 2.Basic Backgrounds 3.Monster tutorial. The file has no images to help you along, but it gives a link to a 3D creation program that you can download. The tutorial advises you to use the 3D programs tutorial to gain an understanding of the 3D program itself, which is a bit awkward.
