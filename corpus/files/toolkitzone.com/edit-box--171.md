# Edit Box

Updated version of the superior edit box plugin from the Aljo brothers which supports a whole host of customizable features and comes with a well written help file which includes details on commands and example code.
posted by on 2004-01-02 01:06:23 [John@aljo](forums/profile.php?mode=viewprofile&u=76)
Some times when used in conjunction with some other plugins and the multiplug, the edit box plugin don't work all the time. Has to do with initialization and what not. to fix this when ya use the multiplug name the edit box plugin to tkplug1 and enable it in tk2 main file. If it still doesn't work move it to tkplug0 and change multiplug to tkplug1. Plugins are freaky like that and seem to have a mind of their own. This is also the case with the VB plugin.
