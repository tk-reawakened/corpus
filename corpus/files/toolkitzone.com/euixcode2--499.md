20 April, 2004
You might need to register the DLLs. So just copy all the DLLs that came with EuixCode² into your System directory. Which is C:WindowsSystem for Windows 95, or Windows 98. And for windows NT and such, it's usually C:WindowsSystem32 or C:Win_NTSystem32. Once they are copied there. Goto Start>Run. Then type in the command to register DLLs and OCXs, such as below: regsvr32 FILEPATH so you would do this: regsvr32 comdlg32.ocx It should all work. If you don't copy to the system directory, just do the same as above, but with a full path. I hope this helps :S
