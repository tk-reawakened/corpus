# ExtendedPlugin SDK

For the people that just can't seem to grasp the whole idea of using c++ for plugins. Here is the alternative! This plugin sdk and plugin bundle is alot like the multiplug except you specify what your plugin is and it allows for activeX plugins to be ran by the RPG Toolkit! What does this mean? All the VB freaks can make plugins for the tk too! A must have for VB only programmers.
