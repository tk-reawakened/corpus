**My Programs**
A small collection of programs, with the required images. It includes a bank with an ATM, a roulette table and a shares program. Only the ATM program is documented, but they are all fairly self explanitory. These could make a nice addition to any game in a modern day setting.
29 September, 2004
Comments from the programmer: these files were created in toolkit2. I had a lot of stuffing about trying to get the coordinates right, as the visual editors I used didn't work, and working out the coordinates in pixels myself didn't work, so I played about until I got it all working. works fine in RPGToolkit2, but when I tried to use these files in version 3.0.4 the buttons were all out of position and stuff and the code didn't work properly. I would look at making a version three compatible lot of programs, but I don't think anyone will really care wether I do or not! ;D Koeran
