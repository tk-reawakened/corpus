# OC's Method Pack

**password**
Latest version of OC's method pack has made a vast improvement on the fadingText methods by making them into one and pretty much doing an overhaul on em.. The method pack comes with substantial help file you get you started. Pack contains methods and commands for; inn, bank, tournament, level-up, message window, prompt, fade text, drop shadow, fade in image, get player co-ords and get radius.
