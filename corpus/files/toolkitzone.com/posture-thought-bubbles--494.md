# 'Posture' Thought Bubbles

Very small and simple set of thought bubbles for use within your game to help illustrate the possible thoughts of your characters such as smiling face, question mark and so forth. If this set could be combined with some sort of rpg code tutorial for using them effectively within a game, say during conversations, then it would be a nice little download.
