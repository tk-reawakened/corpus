# Rainbow Colored Text

Was a small little program, Now is a great little Method, Rainbow text comes to portable code near you! great little method that makes text flash in a huge variety of colors. Funny Text finally does something also. It moves your text sideways over and over again for as many times you specify. Using these two together kinda gave me some funky results so I caution you. Even if it was a bit buggy the Rainbow Text method is a great little addition to the TKZone. A great improvement on it would be where you can set the x and y coordinates of the text.
