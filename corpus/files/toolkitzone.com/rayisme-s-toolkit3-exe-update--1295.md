# RayIsMe's Toolkit3.exe Update

Latest unofficial release, this time for the editor. Fixes three bugs concerning pasting in the code editor, overlapping frames when previewing animations and new slot being added when you edit an item. Also adds searching and comment/un-comment code blocks. Includes source and readme.
**This is not an official release, therefore not endorsed by the official development team. If you currently use another unofficial Toolkit3.exe patch then this will overwrite those changes so always back-up original files before using.**
