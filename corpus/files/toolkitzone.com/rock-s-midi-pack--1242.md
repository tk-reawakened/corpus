# Rock\'s MIDI Pack

An interesting pack here, containing about 155 files altogether. Some are superb - mainly those in the main root folder, as well as 'Main' in the TK folder. The Keith Bramich folder has some strange pieces in it- theyre not as musical as one would expect, but would perhaps be good if used in a dungeon type setting... A bit of a mixed bag then, but some excellent original tunes, and some very good ones at that.
