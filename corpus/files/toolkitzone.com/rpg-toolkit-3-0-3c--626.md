# RPG Toolkit 3.0.3c

May, 2004 Official TK3 binary release
**Review**
An array of fixes and features come along with the latest release of the Toolkit, with the huge addition of object-orientated support for you advanced programmers. The board editor has also had a huge facelift with a new toolbar exposing an array of new features and the engine has undergone a whole slew of fixes. Furthermore, a few commands were added and the TK should no longer crash when you start/close your game.
