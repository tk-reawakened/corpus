# RPG Toolkit 3.0.4

Official binary release of the RPG Toolkit Development System (version 3.0.4), also includes the patch update - September, 2004. **meaning you don't have to download this again if you already have done so, simply download the patch file . [here](http://www.toolkitzone.com/fileman.php?id=3&file=820)**
**in-depth review**
The long awaited 3.0.4 release is here after many delays and stoppages - all of which only helped make the release even more feature filled and stable. So what can you expect? Well, the big ones are the ability to make your game into one single EXE file for people to download and play. No need for lengthy installs! Secondly, the much awaiting pixel movement for characters - a much demanded feature. Along with these are countless additions, fixes and changes that make for probably the best ever release of the Toolkit for years. To read a full list of changes, click . You can also find the details of the included patch, . Open source credits go to, in alphabetical order, Delano, KSNiloc, Occasionally_Correct, Woozy and Xavier.
