# String Manipulation

A whole set of functions for manipulation strings, containing the usual suspects such as substring, length and split.
posted by on 2004-01-01 21:08:41 [John@aljo](forums/profile.php?mode=viewprofile&u=76)
contains several methods for string manipulation recently thought to have only been accessible by plugins. Includes methods like getting the length of a string, changing strings to upper and lower case, splitting strings into multiple strings, and getting a substring out of a string.
