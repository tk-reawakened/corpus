# VB Mini-Game

Scary concept first percived by CBM as "the main use for plugins" This mini game shows how easy the vb sdk can manipulate this idea. Not exactly the best mini game out there but I think KSNiloc ment it to be more of a tutorial or idea triggering plugin. btw put the shoot.dll in a folder called activex or change the plugins.ini accordingly. He has a file on how to configure the ini if need be.
