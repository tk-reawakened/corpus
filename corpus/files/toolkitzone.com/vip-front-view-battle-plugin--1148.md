# VIP Front View Battle Plugin

![](games/phpThumb.php?src=../fileman/images/464.PNG&iar=on&w=200&bw=2&bg=000000)
**VIP Front View Battle Plugin**
Derived from the TK3 battle system, Chris's plugin introduces various fixes for bugs in the default such as weapon animations not working as well as a new front view display. A very promising first release, with a side view version also available. Comes with easy to follow installation instructions.
