If you dont have it, search comdlg32.ocx on google. I think it comes with Vortex 3 as well. Put it in your system32 directory if you have 2000/xp, or system directory if you have windows 95/98. Go to start, run. Type in: regsvr32 "C:Windows\System32\comdlg32.ocx" Hit enter (adjust the above path to what ive described above. I believe windows 2000 uses winnt instead of windows as a directory) It should say something like registration succeded. If you dont want to go through all that, you could try puting the file in the same directory as the vortex file, although it doesnt always work that way. It ALWAYS works when you register it.
