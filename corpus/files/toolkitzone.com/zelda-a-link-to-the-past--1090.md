# Zelda- A Link to the Past

Another classic set of Zelda midis. Not, in my opinion quite as good conversions as the recent Links Awakening pack, but a whole set of delightful ditties nevertheless. Its all very Zelda-ish - towns, dungeons etc in the good old style. Worth having if only to remind yourself of the good old days...
08 May, 2005
Awesome,this is a great music pack for any Zelda fan! Link To the Past is perhaps the best Zelda game and now you can use the music for your game!
