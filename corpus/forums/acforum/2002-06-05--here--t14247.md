what you do is set this to be the program that runs when he is defeated:
#won!=1
Then the program to set to him:
#if(won!=1)
{
#addplayer("bob.tem")
#mwin("Bob joined your team!")
#wait()
#mwincls()
#end()
}
#if(won!=0)
{
#fightenemy("bob.ene","fight.bkg")
}
Hope that helps you!
