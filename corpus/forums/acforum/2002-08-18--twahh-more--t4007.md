### darq · 2002-08-18 09:41 · #A1002-4007

*Larger character/item graphics to allow things like horses and such (which are long, not tall).*
I agree 100%, along with others.
*Ability to store animated tiles in tilesets*
Yup.
*Ability to play .gif animations instead of just displaying images. That would be much easier than converting a gif to a toolkit animation of an .avi (especially since I don't have a program to create avi's with).*
I really wouldn't have much need for this, but it could come in handy is suppose.
*Should be able to set a program to run when the player enters a board, regardless of what tile he is on.*
Set a multitasking item, with a program to run while item is on board.
*Enemy animations (movement, combat postures, etc.) for scenes just before a fight, more detailed fights with the default bs, and for custom bs's.*
This seems almost completely useless to me, it can easily be done with a bit of simple coding.
*Ability to set separate colors for Mwin, text, drawn lines, etc. instead of constantly changing color rbg values.*
I don't see anything wrong with the current way of coloring it.
*Better support for #start command. I have had trouble trying to display a .txt file using that command. Would also like a command that can execute .exe and .bat files.*
It was removed because cbm relised people could be selling their game with copyrighted EXE's or something running in it.
*A feature that allows the user to customize the internal menu systems.*
Just make a custom menu, it looks better, can be a lot more advanced, and is liked a lot more than the default.
*Larger party sizes and a command that allows the programmer to set the maximum size of the party.*
Yup. 'nuff said.
*A command that can access a character's equipped and unequipped inventory (for creating custom menu systems).*
Check out MrG's Misc Plugin Pack at <http://mrgoldsoft.mysticsoftware.net>
*Better tools in the tile editor, like a selection tool, copy/paste option, etc. A gradient filter would be nice too.*
I actually sorta hate the tile editor, mostly because I make my tilesets very big and then import them and it's a bit buggy. *cough* The Gradient Tool Is Evil*cough* -Tsugumo.
*Improved targeting for some commands. The #NewPlyr command only effects the targeted player. You should be able to specify which player's graphics are to be changed.*
I think you can do this with some Target commands or something. If not it'd be sorta useful.
*A command like #NewPlyr that can affect items or enemies.* Uh...why? You can just change the item altogether.
