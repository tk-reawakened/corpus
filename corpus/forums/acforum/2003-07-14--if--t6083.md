### asimir · 2003-07-14 22:09 · #A1001-6084

**here....**

on the program where you leave the town, put this:
#if(battledgrandpa! = 1)
{
#send("boardname.brd",x!,y!)
}#if(battledgrandpa! = 0)
{
#mwin("I'd better see Grandpa first...")
}
then make a new program like this
#battledgrandpa! = 1
and put anything else you want to happen after beating his Grandpa in this program
then open your grandpa enemy, go to rewards and set this new program as the 'program to run upon defeating enemy'
