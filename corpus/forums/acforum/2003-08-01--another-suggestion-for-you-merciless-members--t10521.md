# Another suggestion for you merciless members...

### forsakenmarz · 2003-08-01 22:12 · #A1002-10521

*stabs nick* It was your fault! *stabs kronical* And then you started the wave! Ahem... on to the suggestion:
How about a command that creates a table? It would work something like this:
#Table(rows!,col!) { *shit goes here }
Now whithin the curley braces, there could be special commands as such:
#tabletext(row!,col!,text$) *this indicates which cell the text would appear in
#tableimage(row!,col!,image$) *this indicates which cell the image would appear in
There could be other table commands as well. For those wondering when the hell would they use this, their are a few things you could use it for. The first thing that pops to mind is a Custom Shop. It would be much easier to display items for sale through use of a table. Also, you could make Mwin's much easier, with a cell for the name of the person talking, one for a profile pic, one for the actual text, etc.
The possibilities are endless, and this command would most likely be used when making interfaces for our custom systems. Well, that's my little suggestion for the day. Adios!
