However I'd like to propose a small change. Instead of those simply being mp3 commands I suggest a new command #Sound that would encompase all the sound formats midi, wav, mp3, mod, xm, etc. and that command would also have the other related commands you suggested soundpause, soundresume, soundfade("out/in"[,file$]), soundvolume(volume!), soundjumpto(mins!, secs!). This would make working with sound files easier since you would only be working with one set of commands.
