### comfox · 2003-09-12 24:09 · #A1002-11022

#Triangle(x1!,y1!,x2!,y2!,x3!,y3!,name$)
#FillTri(name$,color!)
#TexturizeTri(name$,texture.bmp/jpg/gif$)
Or something similar. Perhaps eliminate name$ and make it work like #Rect and #FillRect do, except add #TexturizeRect and make #Tri commands instead of just rectanges and circles (which i believe are all there currently are...)
Also, inverse #Cos and #Sin. There should be a reserved variable for total steps made in the game (playersteps[0]! - playersteps[4]!, or whatever). You should be able to select a custom walking system the same way as you can select a custom battle system and menu. There should be a #GetTileName(x!,y!) that gets the filename of the tile at the specified location (if that doesnt exist already). Multiple #Savescreen memory locations (those might already be implemented, I'm not sure). You should be able to layer equipment and armour over characters instead of making new graphics from scratch, and when a character walks under a partly-transparent tile on a higher level, you should see part of him/her on the transparent part instead of just an arrow. A #Delay type command that only delays the currently running program would also be helpful, although I believe you can do that with some of the new commands.
Thanks, please reply to this if you agree with any of it :)
