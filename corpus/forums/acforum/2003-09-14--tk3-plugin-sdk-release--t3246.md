# tk3 plugin SDK release

### cbm · 2003-09-14 07:07 · #A990-3246

Hi, everyone.
I have just release the first version of the 3.0 plugin SDK. You can get it in the downloads section, or [here](http://rpgtoolkit.com/software/tk3-a-pluginSDK.zip).
Those of you migrating from version 2 plugins, please note that the new SDK uses std::string objects for strings instead of char* now (so you don't have to delete[] your strings when you're done with them).
That's it for now. I'm sure there'll be a surge of new plugins out there :)
