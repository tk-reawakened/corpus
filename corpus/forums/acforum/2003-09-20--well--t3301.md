### cbm · 2003-09-20 09:30 · #A990-3301

the change in license ot the sdk is more formal than anything.
the terms of the license for the SDK is very open-ended. BSD-style
licenses basically allow you to do whatever you wish with the code.
For the SDK, this means that you can create your own plugins and
release them and there is no obligation to distribute your code (you can
even sell them).
For the fight plugin and the menu plugin, the license is intended to force
you to redistribute the source code you have added. It has a clause
though that basically removes this obligation from those parts of the
code that belong to the SDK (so the SDK license remains just as open
before).
My intention was to force a source-code sharing model onto the fight
plugin and menu plugin without changing the open-ended term of the
SDK.
Anyay, if you make your own fight plugin or menu plugin with the SDK
(from scratch-- not by using the fight or menu plugins provided), you
are only bound by the open-ended license attached to the SDK, which
essentially allows you to do anything.
