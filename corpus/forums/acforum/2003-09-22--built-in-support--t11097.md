However, what I would enjoy more is if cbm took some time alone with a big DirectPlay book and then programmed some online capability right into the engine. Not every game may need online, and not every game will have a developer smart enough to code it online, but it would be much faster if we had some online TK RPG Code made official so that it could better work and interface with the engine.
