# Suggestion...

### woozy · 2003-09-28 16:29 · #A1002-11157

Maybe it would be nice to not have a program on a certain tile, but on a line of tiles.
If you have a chest where you can get some gold, you only need to put the program on 1 tile. Sometimes you need the program on more tiles. You can make it so that you have to walk through a path of 1 tile width so you cant miss the program, but if the path is let's say, 8 tiles width, you have to put the program on 8 tiles, and for all make sure they wont happen again. It would be nice if you could set a program from a tile to another tile (like a line), like from "10, 6" to "10, 16", that all the tiles between those 2 tiles have that program on it. I think all 3D games use this too.
