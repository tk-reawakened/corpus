### forsakenmarz · 2003-10-02 26:24 · #A1000-492

**Er... I had to memorize it...**

for my class that I'm taking right now. In fact, I also believe that Visual BASIC is the easiest programming language I've ever come accross.
The sheer number of programs and shit I can make with Visual Basic right now, with limited knowledge of If structures, is infinite. Perhaps it's because I know a little RPG Code and C++, but Visual BASIC, get this, DOES EVERYTHING FOR YOU.
I think I've written about 100 lines of code in about the 30 programs I've made. All I have to do is double click, declare a few variables, and tada! My program is finished. If you're a beginner and want to learn a programming language, you can't get much easier than Visual BASIC.

If you want the power of object-oriented programming, then go ahead and do C++, but I don't think many people here need that.

It's the second most common language in the nation (now) among database programmers. Visual Basic excels at linking with databases.
