### EB · 2007-01-16 22:32 · #K373076

Opera, IE(7) and Firefox are all very good browsers in their own way. IE7 is many leaps and bounds ahead of IE6, which is good.
Reason I use Opera is due to the speed and distinct lack of memory usage when comparing it to the others. Opera launches instantly, followed by IE6/7 and trailing behind comes Firefox (These tests all from non-cached memory). I don't know if it is a configuration issue, but a clean install of Firefox still takes noticably longer to open compared to Opera. (My default Opera startup even includes maybe 5 tabs by default, Google, Hotmail, TKZ, Penny-Arcade and Newsfeeds, and it still launches faster than Firefox.)
IE7 still has that annoying pop-up blocker, you know, the one where you have to refresh the damn page to allow popups. There should be no reason for that.
