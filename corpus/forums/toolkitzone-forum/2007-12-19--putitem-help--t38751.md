### k-hos · 2007-12-19 02:45 · #K425248

"target" and "source" are used if the .prg is the items multitask program when its on the board.
if its not the items multitask program then you need to put the items slot number on the board, such as 1.

### k-hos · 2007-12-19 02:59 · #K425252

then you want to use: createItem(string filename[, int &pos])
like:

**Code:**

```
createItem("MrMan.itm",MrManVAR)

putitem(MrManVAR, 5,5, 1)

Or:

createItem("MrMan.itm",0)

putitem(0, 5,5, 1)
```

### UltimaWizard · 2007-12-19 05:01 · #K425263

I think you're using the wrong syntax for PutItem(). Smile

**Code:**

```
CreateItem( "TV.itm", itemID );

PutItem( itemID, x, y, layer );
```

You pass it ID numbers instead of filenames. This gave me trouble in my grand week rush of building NAFRPG.
