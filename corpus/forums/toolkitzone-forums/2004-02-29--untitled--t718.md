### Noadi · 2004-02-29 22:26 · #B6000

Read the help files, the TK already has support for game pads.

**CBM in the Help Files wrote:**

> Game Controls
> Playing and moving around in the game is very simple. Here are the built-in controls:
> Arrow keys: Move around
> Shift button + arrow keys: Run
> Alt-X: Quit game
> Alt-D: Initiate debugging. The next program that is run will be debugged.
> Joystick: The d-pad of joystick 1 will cause the player to walk around
> Joystick Button 1: When held in during movement, causes player to run. It also acts as the general activation key.
> Besides those built in controls, there are also some custom controls that you define when you create the main file (rememberyou must set these up in the main file before you can use them):
> Internal Menu Activation Key: Pops up the internal menu system. I usually use the Enter key.
> Runtime Activation Key: This is a button on the keyboard that will automatically run some RPGCode program, as defined in the main file.
> General Activation Key: This is the key that will activate programs and items that can only be activated when the player is facing them and s/he presses the activation key.
>

### Ersuis · 2004-03-01 00:51 · #B6030

**Seafroggys wrote:**

> Why live with 6 keys on a gamepad when you got 35 on a keyboard plus the mouse?
>

Simplicity.
If you're working with 35 keys, plus the (now) standard three mouse buttons, you have all that room to overdesign your game to try to take advantage of all that stuff to press. If you're confined to only a few buttons plus a direction pad, then you have to be careful about what you want to include at the top level of your interface.
Diablo does this well. It has an intuitive interface that does a large number of things, but only uses a few buttons. I play games like Nethack and ADOM (and most recently just started trying Angband), and there is a huge number of actions using almost every key on the keyboard. I know the reasoning behind why it is like this, but having all that 'power' makes the game a bit harder to learn.
I like using a keyboard and mouse a lot better than using a game pad, but usually I think it's a better idea to confine yourself to a few buttons than to map everything that could be done onto the keyboard.
