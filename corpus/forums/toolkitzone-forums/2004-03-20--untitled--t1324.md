### Occasionally_Correct · 2004-03-20 23:46 · #B12697

Code for adding the member.

**Code:**

```
#AddPlayer(bob.tem)

#HaveBob!=1
```

Use this when you want to check if you have Bob.

**Code:**

```
#If(HaveBob!=1)

   {

      *Do stuff here.

   }

#If(HaveBob!~=1)

   {

      #Mwin("You don't have Bob, eh.")

      #Mwin(Get outta here.")

      #Wait(a$)

      #MwinCls()

      #End

   }
```
