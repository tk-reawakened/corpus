# Some guidelines

### Asimir · 2004-04-28 15:58 · #B26326

1. Use the code tag when posting code. (Put [code] before your code and [/code] after.)
2. If you're posting a large program, try to comment the important parts. You're much more likely to get help if people don't have to spend an hour understanding your code.
3. If you want help, try to explain your problem the best you can, and explain what the code is supposed to do.
4. If you're posting for the first time, read a few other topics first. If your code isn't as advanced as the stuff here, it may be best on the help forum.
5. When suggesting new RPGCode, give reasons why it would be useful, and maybe examples.
