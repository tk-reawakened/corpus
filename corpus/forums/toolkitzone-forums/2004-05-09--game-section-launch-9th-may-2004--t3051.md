# Game Section Launch - 9th May, 2004

### Xavier · 2004-05-09 13:43 · #B30575

Hey Guys,
Yep, it's finally here. After months of saying it would come soon...I got off my lazy ass and finished up the first release of our game section. Here's a rundown of what you get;
My Games
Allows you to manage your game profiles. Here you can add/edit/remove items such as news, images, files, game pages (your own custom webpages about the game) and team members.
You can also upgrade your game profile so you can use our dedicated game server to host games, patches and trailers.
Game Profile
This is what you see when viewing a game's profile, and what you will send other people to to view yours. It contains a frontpage with a summary of news and files, then a menu for the user to view more in-depth pages for the image gallery, files and so forth.
Users can add comments for items, and every game has it's own unique PHPBB board for feedback and discussion!
Game Section
The game section divides game profiles into various categories depending on where they are in terms of development. Users can sort games by name or last update.
I can assure you we will be continually improving this section for some time to come. So please feel free to suggest features on the board.
