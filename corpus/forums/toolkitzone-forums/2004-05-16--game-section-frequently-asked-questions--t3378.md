# Game Section - Frequently Asked Questions

### Xavier · 2004-05-16 10:47 · #B34056

IMAGE QUESTIONS
How do I link to an image page?
There are two ways to link to an image, if you want to take people to your game profile then use the following url and change GAME_ID for your games unique ID and IMAGE_ID for your image's ID.
<http://www.toolkitzone.com/games.php?image=IMAGE_ID>
If you want to load the picture, not link to it, you use the file path itself, again subbing in the GAME_ID and IMAGE_ID numbers and also the file extension.
<http://www.toolkitzone.com/mygames/images/GAME_ID/IMAGE_ID.EXTENSION>
We do not permit you to load image hosted here at TKZ onto other sites, so please instead link to the image page using the first method.
FILE QUESTIONS
How do I add a file?
There are two steps to adding a file. But before you do anything you need to request file hosting for your game profile. You only need to do this once for the game, and when your request is confirmed you will receive your FTP details via e-mail. From that time onwards, follow these two steps for adding a file;
1) Open your FTP program of choice, and enter your FTP details as included in the e-mail. Once connected, you may then upload the file(s) you wish to add to your game profile. Once uploaded, exit your FTP program
2) Go to "My Games" at ToolkitZone and click the "files" link for the game, then click "[add local]" at the top of the page. Here you will see a form, fill in the file details such as name, description, version and type of file.
You will also see a drop-down box with all the files you have uploaded listed in it. Select the filename you wish to add this time, make sure the form is fully filled out, then add the file.
Pretty simple when you look at it. It means the whole process of adding files is down to you once you have succesfully requested your file hosting, no need to go through us!
What is FTP Program?
In short, an FTP Program allows you to connect to a server using a username and password. You can then normally upload, edit, delete and download files once you have connected.
If you need an FTP Program, there are many available. To name but a few;
CuteFTP - <http://www.cuteftp.com>
WS_FTP - <http://www.ipswitch.com/Products/WS_FTP/>
SmartFTP - <http://www.smartftp.com>
These programs will also come with help files on using them
GAME PAGE QUESTIONS
What is a game page?
A game page allows you to add any type of information about your game, and you can create it using html or the editor - so it can look how you want it to look.
People have used game pages so far to tell people about the plot, characters, progress on the game and so forth. It's up to you!
When I try to add a game page, the page editor doesn't work!
This is due to the current version only working for recent IE (Internet Explorer) versions. Use IE to add and edit game pages. We hope to add Mozilla and Netscape support soon.
