### Vampz · 2004-05-22 12:59 · #B36720

Hey Guys,
I'm starting to check through the releases and compile the general history.txt update for CBM.
Like with the last release, I'll put up a list here, and update as I go, of all the changes.
The changes here are yet to be accepted by CBM, so some, for whatever reason, may not make final release.
TOOLKIT3
Character Special Moves and Enemy Special Moves: Editing special moves made easier. by Woozy.
Command Reference: Window enlarged to fit more commands and reference itself edited for better reading. by Woozy.
New commands added by open source developers documented and listed, also rpg code tutorial added. by Occasionally Correct.
Tile Editor: Added new tool allowing you to specify the transparent colour, and when selected all pixels change to transparent. Tile editor bottom bar also refined and improved. by Woozy.
Program Editor: Syntax colouring improved, now much more efficient. by Geoff.
Run Game: No longer crashes when you try to run your game from the Toolkit. by Delano.
Board Editor (all by Vampz):
+ Tile type positions and setting fully functional (as in Patch).
+ Slow board drawing when setting tiletpyes fixed.
+ Warps are now shown as a green X to differentiate from a normal program.
+ Background pictures now scroll correctly.
+ Refined bottom bar, added feature that layers now show layer name if one is present.
+ Board now refreshes when you set a program, item or warp so you can view it.
+ When using fill tool, it now fills with selected tiletype too.
+ Draw lock toggle control now set to selected when you open a new board.
+ Added ability to right-click a tile and then set tile type and erase it.
+ Added new optional Toolbar which has two main features;
1. Allows you to view and sort programs, items and warps. You can then click one of them to edit the object itself,
change the settings or remove.
2. You can set various display options such as always redraw all layers and have certain objects such as programs and items always be displayed.
TRANS3
New Commands: New item commands - GetItemName, GetItemDesc, GetItemCost, and GetItemSell. Also added are string manipulation commands StringLen and InStr. by Euix.
Classes: New OOP support added with the ability to create classes, along with helpfile. by KSNiloc.
Closing Game: No longer crashes when you close Trans3 when a program is running. by John@Aljo.
Board / Character Movement / Misc (all by Delano):
+ "target" or "source" now work in #Push("n", "target")
+ #Send failed, the board no longer re-aligns to the corner.
+ #PutPlayer now centres screen on player.
+ No pause when moving to a new board.
+ Tile placement corrected on large isometric boards.
+ Items can no move on "under" tiles.
+ Attempt to improve character and cursor speeds.
+ Moving to the same tile as an item no longer causes player to not be able to interact with board.
+ #PathFind now updated in line with #Push and #PushItem commands, now returns a string of directions separated by commas.
+ Enemies no longer die with one hit.
+ Small boards now centered on screen.
+ #Get command no longer inverts LEFT and RIGHT keys.
+ Added support for the number-pad for movement, and for cursor maps.
+ #Get and #Wait now return "SPACE" for the spacebar instead of " "
