# Writing Forum Guidelines :

### gcn_zelda · 2004-06-13 16:03 · #B44914

1. Don't simply post one paragraph. Wait until you have something of substance that can be commented upon.
2. If you are commenting on another's work, use only compliments and constructive criticism.
3. Literature comes in all forms, poetry, novels, biographies, etc. so be creative and don't put down other's work if you think that it is not a work of literature.
4. Don't post or link to other's literature, off-site or on-site.
5. Don't be like me and use horrible puns.
6. Don't try to change another's story unless you're asked to.
7. Try to use good line spacing in your writing, but if somebody doesn't, don't complain about it.(I hope I understood what you meant, Zap!) :P
That's all I can think of write(no pun intended :P) now, so get writing!
