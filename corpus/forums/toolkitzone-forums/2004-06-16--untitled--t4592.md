I've spent the last few hours making a Bug Tracker for the development of TK3, it will allow us to keep track of which known bugs have (and have not) been fixed.
It's ready for you to begin posting bugs on, but will continue to be updated over the coming days, so please be patient if you find any bugs in that system.
[Go to the system](http://www.dc-3.co.uk/tkbugs/)
Please don't post "Test" type bugs, you'll be banned from posting bugs altogether if you do.
Please also feel free to post bugs which have already been fixed, but mark them with the flag *fixed* so that the system knows which are fixed. (It will auto-update fixed bugs once a day, these will be double checked by me)
Developers, if you fix a bug that is in the list, until I get that part of the system set up, please email me at dan@toolkitzone.com with the title of the bug you fixed.
Hope you like it
