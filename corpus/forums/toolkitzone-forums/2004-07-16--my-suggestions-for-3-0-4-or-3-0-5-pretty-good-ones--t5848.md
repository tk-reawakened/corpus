# My Suggestions for 3.0.4 or 3.0.5,(Pretty good ones)

### ViperCat · 2004-07-16 20:37 · #B60163

Alright here are my suggestions-
1-Adding a map creator,along witha 'Map' button in the defualt window,or a #Map command.
2-Making the character graphics window in a maximized window,and making the walking graphics sections 64x64 so users can make characters as big or as small as they want,wich also has other advantages as giving you the ability to make the charcter seem more centered if the user desires to choose so.(Very complicated,yes,but some people might know what i'm talking about.
3-Adding a secondary or third optional battle system style,as in like Menu Bottom,Menu Top,and Menu Side(Left or Right).This will help them make it look a little more original if someone wants to use the default BS.
4-For those who might think its cool to have a little more detail,and the more of 3D-Diablo look,allow the user to choose on the tile editor weither they want the detail to be 16x16,32x32,or 64x64.This way more people will be able to make more impressive tiles for their games.(I know some people that want 3D-like graphics).
5-Also making a real life front-view board option like my example below-
![](http://www.posergallery.com/wip/20040716-16148.jpg)
6-Allow users to select in the Main File Editor what buttons they want to be up and down,left and right.
7-Have built in pixeling,and coding tutorials.
8-Let the characters also have animations like fighting item use and such,like the Final Fantasy series has,like a small glow then they attack,see so users can do that.
9-On the tile editor make an option 'Center',wich centers the object on the grid.
10-Option: 'Gloss' makes the object on the tile-editor glossy.
Thankyou for looking!!
