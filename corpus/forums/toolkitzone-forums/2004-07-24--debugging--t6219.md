### KSNiloc · 2004-07-24 00:53 · #B64232

I don't feel like doing C++-specific debugging but let me give you a few general programming tips.

**Code:**

```
struct playerstats

{

    int attack;

    int defend;

    int hp;

    int mp;

    int agility;

    int accuracy;

    int level;

};

struct enemystats

{

    int attack;

    int defend;

    int hp;

    int mp;

    int agility;

    int accuracy;

    int level;

};
```

These two strcutures are exactly the same! Why have two? While we're on the topic of stuctures, don't use them. They're so, so, terribly evil. Trust me. Use classes.
'default':s should have a break; too even though it's redundant for consistency.
Also, all variables should be initialized.
'choiceloop'... eew... a var that will only equal 1 or 0... scarey. Use a boolean.
Don't open up the whole std namespace when you're hardly using any of it.
Also, the whole thing has poor construction. You are going to want a main loop.

**Code:**

```
damage = (stats.attack - enemy.defend) + stats.level * 3
```

The ()s are redundant. You may have inteded for it, but the level is being multipled by 3 BEFORE being subtracted.
Don't use // for comments; not all compilers support it. Proper commentation is /*, */.
Anyway, I'm done ranting. Good luck fixing. Smile
