One thing that we could use in an installment in the next tk is better alpha transparency support. Now, there are a few ways we can go about this.
1) Screw the idea. Gonna be impossible to code.
2) Make use of the alpha transparency in png files (and other files like that)
3) Have rpg code that takes an alpha layer (gray scale image), and another image and pastes it together.
Also, a command to take an image and make it translucent would be useful also.
Speaking about translucencies, fix the friggin' under tile mode! I know there is a way around it, but having proper under modes really do fix a few problems.
And while we're talking about translucencies and sprites, having a command to make tiles translucent would be great. Same with being able to pixel in translucent pixels.
Thanks.
