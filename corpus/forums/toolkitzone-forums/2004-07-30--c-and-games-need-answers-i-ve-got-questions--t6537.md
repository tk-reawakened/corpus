### Ersuis · 2004-07-30 20:37 · #B67545

Heh, image handling can be a bitch in C++ if you don't have a decent library. It can still be a bitch if you have a decent library and have no clue on how to do it. :p
Can you program in any language yet? If not, you should try something a little bit different than C++. C++, while a fine language (sometimes), I don't think is a good beginner's language. Python [www.python.org] is an excellent beginners language, and through it's extension system can be used with C/C++.
I learned a lot of what I know about C++ the long way. I bought a book (SAM's Teach Yourself C++ in 21 Days) and read from that for a year (on and off), while writing test programs and experimenting with things.
I'm not sure I'd really recommend reading code to learn a language. By all means, read other people's code and pick up knowledge from that, but I think trying to learn a programming language by reading code would be the hardest way possible to learn a language. A little guidance can go a long ways. Wink
