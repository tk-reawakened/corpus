Ok To add music, go to File then Import (CTRL+R if you are using MX). Then select the music file you wish to import. After it has imported, go to the frame that you want the music to start playing on and go to the Properties window. On it is a drop down list called Sound. Currently it will be set for none. Click it and select your music file. Then where it says Event, click that box and select Start. Then if you wish to end it before the movie ends, select the frame where you want the movie to end. Repeat the above, only at the last step select Stop, not Start.
As for making it play through once, go to File then Publish Settings (CRTL+SHIFT+F12 if you are using MX). Go to the HTML tab and uncheck the Loop box. Then open your HTML editor and edit the page so it looks like how you want it to look. Then once you upload your movie, get the link location and go into the HTML file again. Look for: VALUE="yourmoviename.swf" and <EMBED src="yourmoviename.swf" loop=false Where it says yourmoviename.swf, put the link to your movie.
Hope this helps! Da real Flash guru fades into the background. Razz
