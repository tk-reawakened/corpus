### Gnarf · 2004-08-08 01:33 · #B71518

OC made this and he said it makes the right fade which you are talking about...

**Code:**

```
#Method FadeText(x!, y!, text$, speed!, color!)

{

   #speed! = speed! / 10

   #If(color! == 0)

   {

      #For(rgb! = 0; rgb! < 255; rgb! = rgb! + 5)

      {

         #ColorRGB(rgb!, rgb!, rgb!)

         #Text(x!, y!, text$)

         #Delay(speed!)

      }

   }

   #If(color! == 1)

   {

      #For(rgb! = 255; rgb! > 0; rgb! = rgb! - 5)

      {

         #ColorRGB(rgb!, rgb!, rgb!)

         #Text(x!, y!, text$)

         #Delay(speed!)

      }

   }

   #Kill(x!)

   #Kill(y!)

   #Kill(text$)

   #Kill(speed!)

   #Kill(color!)

   #Kill(rgb!)

}
```

### Dandy Masher · 2004-08-08 19:43 · #B71778

All #Fade commands are pants in TK2, but #Fade(2) works quite well in TK3.
Custom fade-outs never work all that well. They're always too slow to be practical, at least in my experience.
There are plugins out there that can give you smooth fade-outs. If you're using TK2, check out Kaimu's Plugin. It's got a #FadeToBlack() command that is excellent. Unfortunately, this plugin probably won't work with TK3. So, if you are using TK3, I'd suggest just using #Fade(2) for now.

### Occasionally_Correct · 2004-08-08 20:55 · #B71803

If you want to fade out the screen, simply send the player to a board, and use the ambient color variables to adjust the darkness of the screen until it's black. As noted by KSNiloc, if you want to fade out an image just set the image as the background of the board.

**Code:**

```
#Method FadeScreen(board$, speed!)

{

   *Save the current ambient colors...

   #red! = ambientred!

   #green! = ambientgreen!

   #blue! = ambientblue!

   #Send(board$, 1, 1, 1)

   #speed! = speed! / 10

   #For(ambient! = ambientred!; ambient! > 0; ambient! = ambient! - 5)

   {

      *Set the new ambient colors...

      #ambientred! = ambient!

      #ambientgreen! = ambient!

      #ambientblue! = ambient!

      *Redraw the board with the new ambient values.

      #ForceRedraw()

      #Delay(speed!)

   }

   #Kill(board$)

   #Kill(speed!)

   #Kill(ambient!)

}
```

board$ is the filename of the board to send the player to. Again, set a background image if you want to fade out an image.
speed! is the speed of the fade. Adjust it to your liking.
And when you want to restore the ambient values...

**Code:**

```
#Method RestoreAmbientColors()

{

   *Take the saved values from the last method

   *and put them back into the ambient variables.

   #ambientred! = red!

   #ambientgreen! = green!

   #ambientblue! = blue!

   #ForceRedraw()

   #Kill(red!)

   #Kill(green!)

   #Kill(blue!)

}
```

That should work out for you.
