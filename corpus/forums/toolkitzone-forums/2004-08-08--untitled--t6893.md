### MrB · 2004-08-08 17:08 · #B71730

There's different way of sending files by the internet. The most popular methods are attachments in emails or sending the files by an Instant Messager like AIM or MSN Messanger. If the file is large, you can upload it to a server via [FTP.](http://FTP.) The second question is up to the people looking to work together... sometimes people start a project as a team and release it as a team. Other times there is a main developer for the project and the developer finds someone to only do graphics or programming. The graphics/programming person would get their name in the credits, but the main developer usually gets most of the credit for the game. A good example of this is Rudolph's Adventures, developed mainly by Sophia, but the programming was done by MrG.
