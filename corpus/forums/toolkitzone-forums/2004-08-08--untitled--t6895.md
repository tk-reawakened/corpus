### zyrshnikashnu · 2004-08-08 20:43 · #B71800

i wrote this method a long time ago, and it's not perfect, but maybe you can learn from it. it wasn't meant for a special move, so you'll have to adapt it in your own way:

**Code:**

```
*************************************************

* #RandomFight(Range!, Minimum!, CharFight!)    *

*************************************************

* FP is a range instead of a set value          *

*************************************************

* Range! is the max attack-min attack-1         *

* Minimum! is the minimum possible attack power *

* CharFight! is your character's FP variable    *

** If you don't know what this is, it's just:   *

**        Character'sHandle[fight]!             *

*************************************************

#method randomfight(Range!, Minimum!, CharFight!)

{

   #random(Range!,att!)

   #min!=Minimum!-1

   #fight!=att!+min!

   #Attack!=CharFight!+att!

   #getdp("Target",def!)

   #if(Attack!<=def!)

   {

      #givehp("Target",-1)

   }

   #if(Attack!>def!)

   {

      #fight!=0-fight!

      #givehp("Target",fight!)

   }

   #kill(Range!)

   #kill(Minimum!)

   #kill(CharFight!)

   #kill(att!)

   #kill(min!)

   #kill(fight!)

   #kill(attack!)

   #kill(def!)

}
```
