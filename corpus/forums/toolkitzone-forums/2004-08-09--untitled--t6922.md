I think you could use Triuken's plugin to write a proggy with... I use it with TK3 and it works fine, so lemme try something here...

**Code:**

```
#AutoCommand

:top

GetSteps(steps!)

If(steps!==x!) *Replace x! with whatever number you need...*

{

   Run("blahblah.prg")

}

If(steps!==y!) *Once again, replace y!...*

{

   Run("uberblah.prg")

}

Branch(:top)
```

Maybe that'll give you some ideas to work with (if you're willing to use the plugin, of course Smile ). I really don't like using branches if I don't have to, but maybe this way it could be set as a multitask program somehow...
