Here's the deal: after playing games like Diablo, Baldur's Gate, EverQuest, blah blah blah... I've found that in many RPGs you can choose which character you want to begin the game with.

**Code:**

```
#AutoCommand

*let's say my main file character is dweeb.tem, and named Dweeb*

Method WhichPlayer()

}

   MWin("Please choose a character class to play:")

   MWin("   1 - Fighter")

   MWin("   2 - Wizard")

   MWin("   3 - Healer")

*The number of classes will likely be higher*

   done!=0

   While(done!==0)

   {

      Wait(choice!)

      If(choice!==1)

      {

         DestroyPlayer("Dweeb")

         AddPlayer("buff.tem") *this may be NewPlayer*

         done!=1

      }

      If(choice!==2)

      {

         DestroyPlayer("Dweeb")

         AddPlayer("nuker.tem")

         done!=1

      }

      If(choice!==3)

      {

         DestroyPlayer("Dweeb")

         AddPlayer("feelbetter.tem")

         done!=1

      }

   Kill(choice!)

   }

}
```
