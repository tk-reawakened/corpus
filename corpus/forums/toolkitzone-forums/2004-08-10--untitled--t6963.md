It's still the same day, you can't have such high demands.
In TK2:

**Code:**

```
#ItemCount("sword1.itm",num!)

#If(num!=0)

{

   *don't have item

}

#If(num!>=1)

{

   *have item

}

#Kill(num!)
```

In TK3:

**Code:**

```
If(ItemCount("sword1.itm")>=1)

{

   * have item

}

Else

{

   * don't have item

}
```
