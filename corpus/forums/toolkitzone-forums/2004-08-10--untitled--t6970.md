### Dont_Think_So · 2004-08-10 18:12 · #B72766

Actually, it's a problem with the way you put down the wander program; you can't set the program on top of the item -- if you do it that way, when you walk over the item, it would cause wander to run in an infinite loop. Also, ensure that wander is set as multitasking, NOT activation.
