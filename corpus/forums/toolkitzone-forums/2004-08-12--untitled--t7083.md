> Command: OnEvent(Event$,Command$)
> Usage: Declare this at the beginning of your start program. Event$ can be any event in the game, such as "Step" or "DrawBoard". Command is the command to run when the Event takes place.
> Example:
> #autocommand
> OnEvent("DrawBoard","Methods.Drawhealthbar()")
> Method Drawhealthbar()
> {
> ColorRGB(0,255,0)
> Fillrect(0,0,hp!,30)
> }
>
