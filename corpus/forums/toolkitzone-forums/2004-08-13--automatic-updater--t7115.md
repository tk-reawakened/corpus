# Automatic Updater

### Marz · 2004-08-13 13:29 · #B74644

Hey peeps,
This isn't really a major suggestion, nor is it an important one, just a pretty niffty one in my opinion. When Windows needs to be updated, Microsoft makes sure that you are aware of this with Windows Critical Updates, and with most other programs, you can also "Check for Updates". Well, how about we do that with the TK?
Whenever there is a new release/patch, and you are connected to the internet, the TK will detect that there is a newer version available, prompt you with the question if you'd like to upgrade, and then carry out the installation process. Sort of like how cbm gave those little "update" files to powerhouse users, except this time the TK will automatically detect and install those update files.

### matt72186 · 2004-08-30 22:31 · #B85103

It's not about checking for a new version, but rather, only downloading the files changed in the upgrade. Unfortunetely the TK cannot be done this way for most of the part because it is mostly built into one exe other than the dlls for the battle system, menu system, and various other plugins. So each update your going to have to download toolkit3.exe anyway and trans3.exe which are the biggest files in the download. If the toolkit components were each compiled in a dll and the executable were made to load them then it would be useful to have a update feature to only download the updated components.
