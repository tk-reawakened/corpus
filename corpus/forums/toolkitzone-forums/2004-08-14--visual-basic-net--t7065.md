### Cyranoid · 2004-08-14 04:58 · #B75105

Windows 2003 is a server operating system. Most people dont have it, and wouldnt have it because it mainly works with server architecture and doesnt run great on normal hardware. I know, ive installed it on my pc and half the time it locked up (on a P4). Something like Windows 2003 would have to have a Xeon Pentium processor (server processor) or something along the lines. Sure .net may be bundeled with Windows 2003, but it makes no difference. The next windows to come out is Windows Longhorn (by some other name most likely). And I dont know if you've read Dan's blog, but I dont think that would run on most of our computers. (look near the last page of dan's blog to find a link to a site that describes recommended system requirements).
Yes .NET has a hudge 20MB framework download. But I highly doubt that TK is going to be ported to .NET because of that reason, and simply because it isnt like coverting VB5 to VB6. VB.net is completly different. VB.net, C#, etc... operate nearly the same. THe only big difference is syntax, but they compile pretty much the same (IL). I tried porting a simple project to VB.net once, from VB6, and there were several errors during the conversion. Think about how TK is coded. Its very very complex and interlaced. You would have alot of errors trying to port it. Sure it may be a plus, but in the end you have people complaing about the 20 MB download. And such a port would take rewriting the whole toolkit.
I saw someone mention 3D. Im sorry but the toolkit is never going 3D. Some of you may not realize how much more complex 3D is. Alot of you do, which is good.
RPGA is coded in .NET because its meant to be a professional grade game kit. The games created with it can be big. Its a MMORPG kit, so thats expected. Some of you play MMORPG's 500MB or larger Razz. (And im not saying that it cant be used for non-professional games either. Can be used for hobby use like the toolkit).
The toolkit is a hobby gameing kit. You start making these kids download 20MB frameworks and they arnt going to be happy.
