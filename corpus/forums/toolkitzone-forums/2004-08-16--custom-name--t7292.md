### Occasionally_Correct · 2004-08-16 21:18 · #B76671

So far, I've only seen you asking for people to code things for you. You really should try to learn how to program. It's a lot more productive than asking for programs to be made for you.
I'll tell you how to program what you want, but as for the actual code, I'm leaving that up to you.
First, use #Prompt to ask what the players name is. Store the name in a variable called 'playerName$' or something similar (this way, you'll always know what it's for). Next, use the left and right angle brackets (< and >) at either end of the variable inside of the Mwin() command, and then whatever you want it to say.
To use the same name for the player later on, use the same variable. Variables in the TK are "global", which means they always exist in memory while the game is running, or if you don't Kill() them. So, that variable is still accessible to you.
Hope that helped. And good luck.
