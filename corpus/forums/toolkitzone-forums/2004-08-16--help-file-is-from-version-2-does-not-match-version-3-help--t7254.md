# Help file is from version 2. Does not match Version 3. HELP!

### Chamgorie · 2004-08-16 03:45 · #B76354

I recently downloaded RPG Toolkit Version 3 from the official website. Since I do not yet know how to use it, I decided to check out the Tutorial. When I selected the Tutorial option from the Help mentu, all I got was a prompt that said, "tutorial". So I decided to check out the "Table of Contents," which lead me to a tutorial. The tutorial was from version 2, so it did not exactly match the program as it was. This proved to be a simple matter of application though... to a point. Once I got to Walking Graphics under the Character Creation section, it became a massively different interface from what the tutorial described. The tutorial described a series of twelve editable character graphics. What I saw in the program, however, was a list of positions which I had to select an animation for. "No big deal," I said as I proceeded to choose the animations, "I don't need custom character graphics right now anyway". However, I am now at the "Enemy Graphics" section, and it describes an editor used to create graphics for my monster. Again, what I get is the "animation selection" screen. Obviously, enemy graphics are vital to the very existance of the enemy. Can anybody tell me how I am actually supposed to create and add these graphics?
