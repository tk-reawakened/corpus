### Occasionally_Correct · 2004-08-16 15:04 · #B76532

Yep. MrG made this method (which is found in his T&L method pack).

**Code:**

```
*The next chunk of code is for a multitasking invisible item

*similar to the torch code above. It does a pretty decent rain

*effect, IMO, which use to be thought not possible or not

*easy/fast to do in the TK.

*

*The instructions are the same as the torch program above.

*-------------

*-Rain Effect-

*-------------

:start_cycle

#GetLoc()

#DrawRain()

#GetLoc()

#DrawRain()

#GetLoc()

#DrawRain()

#Branch(:start_cycle)

#Method GetLoc()

{

 #Random(608,rx!)

 #Random(340,ry!)

 #Random(608,r_x!)

 #Random(340,r_y!)

 #Random(608,r_x3!)

 #Random(340,r_y3!)

 #Random(608,r_x4!)

 #Random(340,r_y4!)

 #Random(608,r_x5!)

 #Random(340,r_y5!)

 #Random(608,r_x6!)

 #Random(340,r_y6!)

 #ry2!=ry!+10

 #r_y_2!=r_y!+10

 #r_y_3!=r_y3!+10

 #r_y_4!=r_y4!+10

 #r_y_5!=r_y5!+10

 #r_y_6!=r_y6!+10

}

#Method DrawRain()

{

 #ColorRGB(0,150,255)

 #DrawLine(rx!,ry!,rx!,ry2!)

 #DrawLine(r_x!,r_y!,r_x!,r_y_2!)

 #DrawLine(r_x3!,r_y3!,r_x3!,r_y_3!)

 #DrawLine(r_x4!,r_y4!,r_x4!,r_y_4!)

 #DrawLine(r_x5!,r_y5!,r_x5!,r_y_5!)

 #DrawLine(r_x6!,r_y6!,r_x6!,r_y_6!)

}
```

Set that as the 'program to run while item is on board' in the item editor, then put that item somewhere on the board where the player can't reach it. This will make a rain effect.
