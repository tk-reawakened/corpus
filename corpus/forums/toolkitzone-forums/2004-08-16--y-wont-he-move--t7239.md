### Occasionally_Correct · 2004-08-16 00:44 · #B76216

The wander program has an infinite loop. So, of course your character can't move. To fix this problem, do not set the wander program on the board, and don't set it as activation only. Set it as the 'program to run while item is on the board' in the item editor.
Hope that helped. Smile
