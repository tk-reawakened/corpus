### Dan · 2004-08-17 22:33 · #B77256

You'd have to code something like that yourself.
A simple example would be:

**Code:**

```
Method DepositItem(ItemHandle$)

{

TakeItem(ItemHandle$)*Dunno if TakeItem is a command, but there will be a command like that

ItemsInBank! = ItemsInBank! + 1

ItemsBank[ItemsInBank!]$ = ItemHandle$

}

Method WithdrawItem(ItemHandle$)

{

While(i! <= ItemsInBank!)

{

if(ItemsBank[i!] = ItemHandle$

{

GiveItem(ItemHandle$)

ItemsBank[i!]$ = ""

Branch(:after)

}

}

Mwin("Sorry, you can't withdraw that, as you don't have it in your bank")

:after

}
```

Please note that I havn't used RPG Code in at least a year, so don't expect that to work.
