### Occasionally_Correct · 2004-08-20 05:30 · #B78796

I think everyone posting in this topic is making it way more complicated than it needs to be. Razz
All you need to do is use the actual filename of your items (without directory information. Just the filename and the .itm extension). So, let's say you had an item saved as "sword.itm", one saved as "cure.itm", and another saved as "armor.itm". You'd just call the shop like this:

**Code:**

```
#CallShop("sword.itm", "cure.itm", "armor.itm")
```

Just make sure the item filenames are in quotation marks, and each one is separated by a comma (,).
Hope that helped.
