### Levi · 2004-11-29 21:59 · #B131728

That whole downloading of the file thing won't always work in the same manner. Technically anytime you view a site the page you go to is downloaded onto your computer anyway. But there are plugins like Word in IE that will allow you to view a word document rather than download it. So it depends on the file, if its text or something like that chances are they'll be able to open it in their browsers. However stuff like .zip and .exe will need to be downloaded. If they want they can simply right click the link and select save Target as. But he is correct that you simple create a regular link to the file you want them to download.
