# Posting Guide - Read Before Posting

### Xavier · 2004-09-17 13:31 · #B95729

Getting Help
+ Try and be detailed in your questions, dont just post questions like My RPG Code doesnt work.
+ Use an appropriate title for your topic, "help plz!!" does not count.
+ Dont bump your posts, if people know how to help you, they will do it. If your post goes un-answered, it usually means they dont know the answer.
+ Try and remember to use the [ rpgcode ] tag when posting code, as it colours and auto-indents your code.
+ For quicker answers to your questions, try searching the forum first as someone may have already encountered the same problem as you.
+ If your question has been fully answered and you are happy with the response you received, edit the topic title to include *answered* or *resolved*.
Giving Help
+ Dont post in a thread simply to say read the help files or do the tutorial.
+ If you know that the question has already been answered, dont post to say this question has been answered before, post a link to the existing thread for the user to view.
+ Dont post in any thread in this forum unless your response is useful to the thread, responses like I dont know or Why dont you learn RPG Code first are not welcome.
+ Try and remember to use the [ rpgcode ] tag when posting code, as it colours and auto-indents your code.
