# MathianCreations tutorial2: Matthian Forum System.

### Sevat Syvalluis · 2004-10-08 14:54 · #B107055

(I assumed this is creative writing if in the wrong spot please move, and dont lock or delete)
Ok, This is a Tutorial on devolping a system for forum based rpgs. lets break it into parts
1. Character building
2. Town building
3. Battle systems 4. How to controll the game
5. Adding Story
6. Running the game fairly Twisted Evil
7. Open Comments(stuff i didnt go over)
-------------------------------------------------
1. Character Building
When building characters for a Forum based game, use these features.
Name:
Age:
Race:
Class:
Skill:
Hp:
Bio:
lets break each one down.
Name- is what a character will be called by, if you have a special race name (like a race where all creatures rank is said in their name, say like Worker Gravel, Hunter Avan, Liekos Savo, Liekos Romanji)
Age- hold old a character is, this is not important but in some games if a character reaches a certain age they will die.
Race- what species a character belongs to. some species might a have bonus skill. Or some races might have special conditions.
Class- what job a character does. some jobs give skills.
Skill- the main attack or ability the character has. skills should be assigned by veiwing the characters other stats. skills should also be listed somewhere so the game mods can determine Damage values.
Hp- How many hits someone can take before they die.
Bio- a description of a character.
You should list options and restrictions at the first post to let people know what to do.
--------------------------------------
2. Town building
Now the hard part, the easy way to do this. make a post for each town, type the name of the town. type in places and things to do i.e.
My Town
My Town Center-gain quests, infomation and meet important people.
My Blacksmith-buy and sell weapons
My Inn and Pub- Hang out or rest
My NPC1 house- NPC1's house
My NPC2 house- NPC2's house
My well- get water, sit and relax
My barracks- enlist in the army.
--------------------------------------
3. battle systems
now the fun part. devolp a monster list write attacks out and everything. heres a good template
Name:
Skill:
Hp:
Bio:
By editing posts you can goto your town and location posts and make a whos here list.
just get the value of the attack and subtract it from the player life.
also to help things out make a player list post write out the names of the characters and what thier hp and status is at i.e.
Kilo-100hp-normal
Jon-98hp-normal
Triop-53hp-posiend -3 hits per day
Kireal-20hp-bleeding -10 per day
Hans-0hp- Dead, Died on Fri Oct 08, 2004 2:22 pm
Zaff-100hp-Zombified for 3 days
you can be creative with the list, if other mods are in the game they should make a list to keep up to date incase you are not around to play.
------------------------------------------
4. How to controll the game
These are some suggestions for controlling the game.
1. assign game mods to good players or people online alot. (these are not the same as the TK mods, these will controll the game and have no status what so ever.)
2. place a start date and who ever signs up by the start date can play.
3. when some does an action respond to what happens asap. if multiple actions occur between posts qoute them and list actions.
4. make a mod list. this prevents cheating.
5. keep things simple
-----------------------------------------------------
5. Adding story
when you start the game write out a story.
if more storys are added or one is complete post it.
try not to add new storys untill one is complete.
allow players to interact with the story, if a player finds an ultimate weapon allow them to set a story i.e.
mod1: argo found a dragonsphere. (argo may post story about dragonsphere if he/she wishes)
argo: I have found the ultimate weapon and with it i shall take down the kingdom. I will crush all who oppose me.
Mod1: New Quest! :the king is in danger can any one stop the dragonsphere?
-------------------------------
6. running the game fairly
to run a game fairly. discuss possible unfair posts with the poster.
also try having another mod help with decisions. always stay calm.
