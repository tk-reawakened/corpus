### blackpanther6389 · 2004-10-16 15:59 · #B111410

Some of the plugins have installers with their plugins. But if that doesnt work thats because they probably are in a folder. Take the plugin and just drag it to the plugin folder and if you dont have the multiplug, then you'll have to name the plug like tkplugx.dll where x is the number of the plugin. There are instructions on how to do this within the help files because I not sure if that is the format in terms of the name. But im pretty sure that is how its done.

### Akira · 2004-10-19 05:50 · #B112967

Even if you install plug-ins correctly they won't work if your testing your code in the program editor. Try placing your code into a game and testing it through "test game" or whatever its called. if this doesn't work, I suggest you download the multiplug and rename it tkplug0.dll this will mean you don't have to worry about renaming plugins you download Very Happy
