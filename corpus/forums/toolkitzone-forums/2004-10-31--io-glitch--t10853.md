# IO Glitch

### catwhowalksbyhimself · 2004-10-31 19:26 · #B119600

I have been experiencing (only sometimes) a strange glitch with tk 3.04 on my brand new Window XP SP2 computer. I have a custom save/load system and use an array to store savenames. This array is then saved to a file so that they can be loaded whenever a save file is loaded, thus preventing the computer from forgetting the save names. I am using the included methods. It saves perfectly fine (I checked the generated file) but sometimes misses parts of the array while loading others. It seems to be quite random.
