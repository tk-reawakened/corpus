### RDemusX · 2004-11-09 03:52 · #B122979

For the item screen you could make this program:

**Code:**

```
******************

*Item List Method*

******************

#method itemlist1()

{

   #fontsize(18)

   #color(0)

   #bold("on")

   *Call All Item Counts*

   #itemcount("potion.itm",potion!)

   #itemcount("potion2.itm",potion2!)

   #itemcount("potion3.itm",potion3!)

   #itemcount("fcure.itm",fcure!)

   *Call Slot Varables*

   #itemslotx! = 14

   #itemsloty! = 4

   *Call All IF'S and Text To Screen Position*

   #if(potion! >= 1)

   {

      #itemsloty! = itemsloty! + 1.275

      #text(itemslotx!,itemsloty!,"Cure 1                                               <potion!>")

   }

   #if(potion2! >= 1)

   {

      #itemsloty! = itemsloty! + 1.275

      #text(itemslotx!,itemsloty!,"Cure 2                                               <potion2!>")

   }

   #if(potion3! >= 1)

   {

      #itemsloty! = itemsloty! + 1.275

      #text(itemslotx!,itemsloty!,"Cure 3                                               <potion3!>")

   }

   #if(fcure! >= 1)

   {

      #itemsloty! = itemsloty! + 1.275

      #text(itemslotx!,itemsloty!,"Full Cure                                           <fcure!>")

   }

}
```

That would be a basic way to do it. I have a fully cutsom menu but it has over 60 different customized methods, and NO I don't want to share ... I am feeling stingy. Try it yourself and the "SMALL" parts of it that you have problems with let us know and we can help you.

### Talyn · 2004-11-09 14:30 · #B123097

The best way to start with custom menu systems is to just redo the front page and then use the #InternalMenu command. However, this is Advanced RPG Code, so you'd want to not do that.
Arrays are the only way of doing a fully custom system. You can also set other properties to them as well which is cool. The only problem is that if you don't start doing this from the beginning it can take a long time to save all the array's. I'm speaking from experience here as I'm on my second Demo and have only now decided to make all my items custom. Confused
