### Delano · 2004-11-09 17:53 · #B123141

In the Board Editor, go to the Board Settings > Board Information... menu, and on the tab that appears you can set the directional links, i.e. the boards to connect to for each direction.
You can also set "Warp Tiles" that send players to specific locations on other (or the current) boards; you can set these in the RPGCode > Set Warp Tile menu. When the player walks on the warp tile, they are sent to the target board.
In both cases, these methods are "one-way" - you have to manually set the return links, if you require them.
This kind of information is in the help files, so check those out next time.
