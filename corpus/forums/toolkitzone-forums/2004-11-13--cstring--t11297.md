# CString

### Colin · 2004-11-13 00:34 · #B124496

I've spent the better part of today coding a nice string class, if I do say so myself. I've had a number of people ask me about string manipulation in C++ recently, hopefully the source of this should help a bit. Critique is welcome...
[Download Here](http://www.toolkitzone.com/stuff/files/226/CString.h)
Types
The VB_STRING is a BSTR allocated with ASCII characters, VB will convert these characters to UNICODE itself, and that is why they must be ASCII.
The UNICODE_STRING is an array of wide (two-byte) characters; useful for apps that require localization.
NOTE: The VB_STRING, the BSTR, and the UNICODE_STRING are size-wise, the same. As a result, all operators will assume BSTR, and where differenciating is required, named functions will be provided.
The ASCII_CHAR is a single ascii character; ascii strings are made up of these one-byte entities.
The ASCII_STRING is a traditional, ascii, C style string; ideal where speed, memory conservation are required, and localization is not.
Methods
Prototype(s): ASCII_STRING copy(void) const
Purpose: Returns a copy of the string; allocates new memory.
Example:

**Code:**

```
ASCII_STRING myStringReturningFunction(const ASCII_STRING charIn)

{

   // Create a CString from the param

   CString x = charIn;

   // Replace the word "hello" with "BOO!"

   x = x.replace("hello", "BOO!");

   // Return what we've done

   return x.copy();

   // Copy is required because the string's internal

   // ASCII_STRING will be killed when the object

   // exits scope.

}
```

Operators
Addition (+) - return a string with the new text appended to it
Relative Addition (+=) - concat the new text to the string
Stream Write (<<) - Write the string to a stream
Stream Read (>>) - Read from the stream, appending to the string
Equality (==) - Check if two strings are equal
Inequality (!=) - Check if two strings are inequal
Subscript ([]) - Access the characters in the string (as ASCII_CHAR) from 0 to x
