# help with tiles

### semi · 2004-11-13 20:20 · #B124818

i have downloaded tiles like barrels swords etc. how do i edit these tiles so that the grey/turquoise/black background of the downloaded tile is transparent or at the very least the same as the tile i want to place it over.

### Delano · 2004-11-15 18:33 · #B125603

You can erase the background colour in the tile editor by flooding with the transparent colour. You can select the transparent colour by clicking the thin button at the right end of the colour palette.
If you're using tiles in animations, you can select a transparent colour for the animation frame in the animation editor.
