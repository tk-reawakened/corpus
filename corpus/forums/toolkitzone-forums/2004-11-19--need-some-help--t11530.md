### Delano · 2004-11-22 22:39 · #B128602

Um, not quite.
First off, you've created an animation for the item; now you need to create the information about the item and attach the animation to it. You can't use an animation as an item.
Create an item by going to File > New > Item. You can assign information about how the item works here. For instance, if you want to use the item on a board, set the Tick Box next to "Board-Driven". Then, you can click "Edit" and set a program to be run when the player activates it. You can assign graphics (i.e. animations) for the item in the "Graphics..." screen.
Hope that helps.
