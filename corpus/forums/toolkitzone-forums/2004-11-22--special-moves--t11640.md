### marcos · 2004-11-22 11:05 · #B128334

Go Character Editor Arrow Click Special Moves Arrow Pick a Special Move Arrow Click Special Move Info Arrow Or variable: Type a Variable. Arrow Equals: Type something different than 0.
OK, so the SM will only be available if the variable is different than 0, let's say, 1.
Now Go Item Editor Arrow Check Equipable if it isn't, click edit, then go set two programs, one for equipping the item, another for removing.
Then, assuming the variable you chose is variable!
the equipping program must have this line:

**Code:**

```
variable!=1
```

At the removing program:

**Code:**

```
variable!=0
```

So the guy forgets the move.
Go on, try it, will surely work.
