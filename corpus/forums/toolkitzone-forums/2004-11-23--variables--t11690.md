# Variables!!!

### ReidE96 · 2004-11-23 08:42 · #B128915

I'm trying to set a variable for the player's name. I have set the variable, it works in text, but when I set it to the player's name, his name comes up as <playername$>.

### catwhowalksbyhimself · 2004-11-23 23:37 · #B129172

When you set the variable, did you put quotation marks around playername$? If you did, that is the problem. Quotation marks means to set those exact words. Not having quotation marks means you are using a variable. If you are using quotes, remove them, and that should solve the problem.

### Dont_Think_So · 2004-11-23 23:42 · #B129176

If you remove the quotation marks, remove the < and > too.
Although, I assume that's not what you are doing. Rather, you are setting their name in the character editor as <playername$>. You must instead set their name variable (by clicking advanced) to playername$. You can then set it to whatever you want in any program.
