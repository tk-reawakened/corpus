# Weird Problem with Outlook Express

### Talyn · 2004-11-26 20:25 · #B130527

Ok, here's a problem for you:
On my gf's family computer, they run Outlook Express 6 for checking their mail. All worked fine. Then the other day we uninstalled Netscape Navigator cos it was just sitting there doing nothing. Or so we thought. Now when you click a link in an e-mail, it won't bring up a window following that link, something which Netscape used to handle. Now how can you set Outlook Express to use IE as it's web-browser? I can't find the setting anywhere.

### Spyder · 2004-11-27 01:49 · #B130695

Go to Start --> Settings --> Control Panel --> Internet Options --> Programs. There's a check box at the bottom of the window that says "Internet Explorer should check to see whether it is the default browser". Check it. Now Run Internet Explorer. When it asks you if you want to make IE the default browser, click yes. Now your links from programs should be handled by Internet Explorer.
