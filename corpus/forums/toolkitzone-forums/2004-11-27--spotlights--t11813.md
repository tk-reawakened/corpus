Here it is. This should work, i did not test it. Just save this into a .prg then set it as a thread.

**rpgcode:**

```
// pixelx = tilex - 1 * 32

SpotLightThread()

Method SpotLightInit()

{

     SpotLight! = CreateCanvas(800, 600)

}

Method SpotLightKill()

{

     KillCanvas(SpotLight!)

}

Method SpotLightThread()

{

     px! = playerX[0]! - 1 * 32

     py! = playerY[0]! - 1 * 32

     ColorRGB(0, 0, 0)

     DrawRect(0, 0, px! - 32, 600, SpotLight!)

     DrawRect(px! - 32, 0, 800, py - 32, SpotLight!)

     DrawRect(px! - 32, py! + 32, 600, 800, SpotLight!)

     DrawRect(px! + 32, 0, 800, 600, SpotLight!)

     SetImage("Light.bmp", px! - 32, py! - 32, 96, 96, SpotLight!)

     DrawCanvas(SpotLight!, 0, 0)

}
```

For Light.bmp, make it 96x96 pixels (3 tiles).
