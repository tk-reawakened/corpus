# Battle Specs

### RPGFan · 2004-11-28 23:24 · #B131312

Is there a way besides placing the same program all around in an area to have battles happen only on certain parts of the board. The only example I can think of is Pokemon, where u have to be in the grass to battle.

### Moo Of Doom · 2004-11-28 23:58 · #B131326

You could do it but it would be complicated...
Instead of using the internal battle system, make a program that first checks what tile you're standing on and then initiates the default bs (or your own, if you have one).
Basically, you set up your chances for a fight to happen in the fighting editor. When a battle comes up, have your program check what tile you're standing on (or better yet, place all your tiles on layer two, and then just place invisible tiles on layer one that are battle tiles... then just check for those), and initiates a fight if you can battle there, or not if you can't.
It may be more trouble than it's worth, but it's possible.

### Dont_Think_So · 2004-11-29 00:19 · #B131331

Hey, look. It's another TK2 workaround I never shared with the community. However, if you do this, you will have to recreate all boards where you battle this way.
1) Set up your board as normal, except start at layer two instead of one.
2) Create a blank tile, and place it into a tileset called "BattleMask.tst". Repeat for every boardskill.
3) Wherever you want to battle using a boardskill, place its appropriate tile in the proper place on layer 1. (BattleMask.tst000 is boardskill 0).
4) Set the following program as your Battle System:

**Code:**

```
#GetPlayerCoords(0,playerx!,playery!) //Requires MrG's Misc Plugin

#Getboardtile(playerx!,playery!,1,filename$)

#ParseSkill(filename$,skill!)

#Fight(skill!,background$)

#method ParseSkill(filename$,return!)

{

#charat(filename$,16,temp$)

#return$ = temp$

#charat(filename$,17,temp$)

#return$ = return$ + temp$

#charat(filename$,18,temp$)

#Return$ = return$ + temp$

#Castint(return$,return!)

#Returnmethod(return!)

}
```

Hurray!
