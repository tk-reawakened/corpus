### Spyder · 2004-11-28 21:26 · #B131246

You can't install it, or you can't run it after it's installed? To install it, open the .zip file, extract all the files to a temporary folder, and run Setup.exe. If it's installed, there should be a folder in your Programs directory labled RPG Toolkit 3 where the various shortcuts to run the program are located.
