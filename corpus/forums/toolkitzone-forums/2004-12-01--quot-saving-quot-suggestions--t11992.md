# &quot;Saving&quot; Suggestions

### Koh Wei Zane · 2004-12-01 05:52 · #B132751

I think this has been suggested before... But I'm not sure if you guys, the developers remember of this.
Tabbing - Suggested (Woozy mentioned that it might be done, like the Firefox tabbing version.) But I'd like to add on to it. If an opened file is modified, eg. board: a tile is changed/added, or eg. .prg file, a letter is modified, to the right of the filenames, an asterik (*) will appear, too, in the tab to make note of a change in the file.
File Closing - On file closing, if that modified file has not been save yet - a warning prompt will appear (like notepad) asking whether to save the file, not to save the file, or to cancel closing of the file. Eg. The prompt will say: "Are you sure you want to quit without saving? Yes . No . Cancel"
That's it... for now.
