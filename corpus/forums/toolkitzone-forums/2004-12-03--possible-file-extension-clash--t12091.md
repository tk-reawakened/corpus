# Possible File Extension Clash

### Talyn · 2004-12-03 18:16 · #B134199

The file extension used for the new Isometric Tilesets (.iso) is already used by NTI CD and DVD Creator. This hasn't appeared to have caused a problem yet on my computer, but I just thought to let you guys know just in case.
As I said, the tilesets all work fine, it just makes the tilesets icon one of NTI's.

### Delano · 2004-12-03 19:05 · #B134217

Hehe, yeah: they do share a file extension, but they won't cause you any problems because of it. The extension is just a method of identification, the contents of the file isn't affected by it. CD image .iso's won't open with the Toolkit (and Tk .iso's won't open with CD creators) because the structure of the file will be different.
The problem isn't exclusive to .iso's either, there are probably more file types in the world than there are 3-letter combinations to name them!
