# IO Labels

### catwhowalksbyhimself · 2004-12-04 23:14 · #B134720

As I am now using IO commands to create my own custom item/enemy file system, I have thought of something which would make things much simpler.
For example, if you wanted to keep the information for several items' custom stats in one file, you would currently have to read the file one line at a time using a while loop until you get to the beginning of the line you wanted. Wouldn't it be easier if you had labels like in program files?
For instance FileLabel("program",":sword") Would go to the label :sword. The next line to be read or written to would be the line after that. This would allow for all sorts of RPGcode IO possibilities.

### Serge · 2004-12-04 23:22 · #B134728

What I do for my custom save program is write directly into a ".prg" file, and when I want to use it I do run("whatever.prg"), or I just write the stuff into the file as a method, and do include("whatever.prg")
It works pretty well and easy.
