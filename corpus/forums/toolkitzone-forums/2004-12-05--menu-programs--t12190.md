### Dont_Think_So · 2004-12-08 01:30 · #B136257

It's been a while since I've tried to run an item from the menu, and that was back in TK2. I find that a good way to test whether it's your code or a problem with the TK is to assign your program as a "Run-Time" program in the main file editor, then press whatever button you set it to. If it runs just fine, then it's the TK, if not, then there's something wrong with your code.
I have a hunch its a problem with If(BoardTitle[1]$ == "Subway Track"). A lot of things start at 0, and I believe BoardTitles are one of them, so unless you set the second layer to "Subway Track", then nothing would happen.
Try:

**Code:**

```
If(BoardTitle[0]$ == "Subway Track")
```
