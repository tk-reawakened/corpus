# Suggestion for tile editor

### Z · 2004-12-06 22:51 · #B135700

Ok I have a suggestion, Instead of one 32 x 32 canvas you could have a canvas with a multiple of 32 (like 64 x 96) canvassas in one canvas, the you could save this canvas and it will seperate the tiles into a TST like; if that was too confusing for you heres a simpler description:
You open the tile editor
then theres a button saying "Edit multiple tiles"
Then it comes up with Message box letting you pick Height and width (of course multiples of 32)
The you can draw a picture on a canvas of the size you picked
Then click a button that says "Make TST"
Then it splits up the tiles into a tileset
This will eliminate all those big bitmaps that you made then grabbed and/or imported them into TSTs, That means you do not have to open MS Paint or anything,make a bitmap, save it, grab the tiles with the RPG Toolkit, then never delete the bitmap because you're too lazy
This editor will make it alot easier to make multiple tile things too
