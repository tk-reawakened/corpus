Just to clear up a small belief that a few people have:
RPGCode is no harder to learn than it was when TK2 was the main version. All Colin and the other developers have done is added more advanced options. There's no need to act like all of the basics have been taken away from you. They're still there. That, and I can assure you that you won't be forced to use advanced features, just like always.
Aside, I've added a heck of a lot more documentation to the help files. If you give it a read when TK3.0.5 comes out, classes will seem a lot easier.
As for RPGCode turning into a clone of C++... There are C++-like features, yes. But there always have been. The syntax itself has always been like Java and C++. Don't worry about that - it's not turning into C++.
