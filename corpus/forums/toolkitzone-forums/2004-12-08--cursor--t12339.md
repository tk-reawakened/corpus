### solaceinsilence · 2004-12-08 23:30 · #B136658

to extend on Occasionally_Correct's comment. You can use the CursorMapHand() command to specify a image to be used in place of the default TK hand. the syntax is:

**Code:**

```
CursorMapHand(imagename.filetype)
```

You can also have an option of streching the image you specify, if you'd like that, you can use this syntax

**Code:**

```
CursorMapHand(imagename.filetype, 0) // 0 for no strecth, 1 for.
```

More information can be found in the RPGCode Reference Smile
