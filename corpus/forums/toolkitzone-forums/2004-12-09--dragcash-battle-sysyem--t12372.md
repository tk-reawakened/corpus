### dragcash · 2004-12-10 06:26 · #B137463

There has been a lot of fuss about Dragbattle. Dragbattle in itself is old, it was made for TK2. More so, since its release TK2 has changed.
I dont recommend using it as your battle system, but I do recommend using it as an example and a reference for coding your own battle system. Wink
The COMDLG32.OCX problem is one of file dependency. The program, more specifically the editor, needs to use the file COMDLG32.OCX in order to work properly.
COMDLG32.OCX is a common file used by a lot of programs developed in VB, so it should not be too hard to find if you Google it. But since Dragbattle only works with TK2, I recommend not wasting your time, just use the code as an example and reference.
Sorry for any inconvenience Confused
