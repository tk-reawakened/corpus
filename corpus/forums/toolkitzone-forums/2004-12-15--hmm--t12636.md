### Colin · 2004-12-15 02:04 · #B139847

Let me explain:
I've added garbage collection now. The object create with CCanvas() is collected, killing the object and the canvas. Before this, it copies the object's members to the new object (NewCanvas). However, this is not good because the canvas is dead. The solution lies in the copy c-tor. The copy c-tor is a special c-tor that takes the type of the class itself (CCanvas, in this case). In this case, the copy c-tor will copy over width and height directly, but blt the canvas over rather than just taking its member. Since you're defining a copy c-tor, you'll also want to define an assignment operator.
For a general rule: whenever a class allocates memory (this includes dynamic arrays), you need both a copy c-tor and assignment operator
Some code:

**Code:**

```
method CCanvas::CCanvas(CCanvas rhs!) // '!' makes you get actual object

{

   width! = rhs->getWidth() // Create this method

   height! = rhs->getHeight() // Create this method

   canvasIndex! = CreateCanvas(width!, height!)

   rhs->draw(0, 0, this)

}
```
