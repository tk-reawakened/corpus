# A new note about using Droids/Clone

### khin · 2005-01-17 09:42 · #B156748

**Quote:**

> Can be used by either Machinists or players who mastered Robotics. Droids can be issued the following orders:
> 1. Find Wood (Droid ID,<location>)
> 2. Find Stone (Droid ID,<location>)
> 3. Find Mineral (Droid ID,<location>)
> 4. Return To Base (this is for when you wat the robot to return to the base)
> Droids can harvest 4 units of a particular resource a day. All earnings shall not stack up on the inventory until the Droid has returned to base. Droids must return to base to be able to accept another agricultural command and to add earnings to the clan's resource stack. Droids shall be given its own status sheet. Requires a Factory to produce droids.
> It costs 1 turn for creating a Droid and 1 turn for making it return to base.
>

**Quote:**

> Clones can be issued the following orders:
> 1. Find Wood (Clone ID,<location>)
> 2. Find Stone (Clone ID,<location>)
> 3. Find Mineral (Clone ID,<location>)
> 4. Return To Base (this is for when you want the clone to return to the base)
> Clones can harvest 3 units of a particular resource a day. All earnings shall not stack up on the inventory until the Clone has returned to base. Clones must return to base to be able to accept another agricultural command and to add earnings to the clan's resource stack. Clones shall be given its own status sheet.
> It costs 1 turn for creating a Clone and 1 turn for making it return to base.
>
