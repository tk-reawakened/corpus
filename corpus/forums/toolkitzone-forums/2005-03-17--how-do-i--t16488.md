### Colin · 2005-03-18 03:15 · #B182092

How would that help, Zap?
Putting the '&' in a parameter passes things as references. Unlike pointers, references cannot be reassigned. That is,

**Code:**

```
int x = 1;

int *y = &x;

// &x != &y
```

But, with references,

**Code:**

```
int x = 1;

int &y = x;

// &x == &y
```

Nonetheless, if you're heard that passing things by reference is somehow faster, allow me to tell you otherwise. If anything, unless you are passing a composite data type (e.g., a struct), ByVal is faster, and safer too. Better yet, be const correct.
