### CG-I · 2005-09-25 16:17 · #B260148

I'm seeing a lot of 'TK2 sucks' in this thread, which I'd have to both disagree with and plead grievances for. It is rather offensive considering as some of the best games made on the Toolkit were made on TK2. Furthermore, TKZ and Mystic Software were both founded upon resources specifically for TK2, and that's what everyone used for ages.
I'm a TK3 user (I used TK2 for ages before though), and feature-wise it's better, but that's because it's supposed to be a step up from the previous versions of the Toolkit. CBM did start almost from scratch when he coded TK3, but if you look closely there's still some remaining elements from TK2 (The tile editor looks almost exactly the same, as does the main file editor).
As for the 'rumor' that all TK2 files will be compatible with TK3, that's the idea. The Toolkit has long stood for backwards compatibility with older versions (Which is why the TK's STILL supporting .gph tile format, to retain compatibility with version 1!), so while it might not be perfect yet, it's intact enough so that most of my old TK2 files from aborted games can still be used.
So guys, don't go off saying that TK2 sucks. It may be in comparison to TK3, and it certainly may be dying, but it deserves its respect.
