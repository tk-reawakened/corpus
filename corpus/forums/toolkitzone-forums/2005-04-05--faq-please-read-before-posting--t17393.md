# FAQ: Please read before posting!

### Delano · 2005-04-05 15:23 · #B190641

Before posting bugs or questions, please check to see if your problem has already been fixed or answered, as it saves developers and moderators a lot of time when monitoring the forums. The Toolkit's help files were completely rewritten for 3.0.6 and contain a large amount of information on the TK, along with many troubleshooting solutions. This material is also included in the 3.0.6 download under Help -> User's Guide (F1).
- Browse other posts on the page for similar topics.
- Use the forum's [Search](http://www.toolkitzone.com/forums/search.php) tool to bring up similar posts in this forum.
- Read the Toolkit's help files: <http://tk3.toolkitzone.com/help/>
- Frequently asked questions: <http://tk3.toolkitzone.com/help/?page=23>
- Technical issues: <http://tk3.toolkitzone.com/help/?page=25>
- System Requirements: <http://tk3.toolkitzone.com/help/?page=26>
Reporting bugs: if you believe you've found a bug, first check to see if it's listed as known and/or fixed at <http://tk3.toolkitzone.com/>. If it is not listed, then please post with as much information as possible - your system specifications (especially Windows version, cpu speed, DirectX version, RAM and VRAM) and how to reproduce the bug. Give your post a descriptive title, not just "I've found a bug!" or anything similar!
Some commonly reported, currently unfixed bugs are:
- "The" Windows9x bug: sprites and/or boards are not displayed properly on Windows9x machines, and appear as fuzzy boxes, or have horziontal coloured banding.
- CallPlayerSwap() inactive.
- Alt-Tabbing out of fullscreen mode, a game cannot be reactivated.
- Save and Load file dialogs are not visible in fullscreen mode.
