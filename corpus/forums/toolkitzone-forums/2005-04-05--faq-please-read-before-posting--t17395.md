# FAQ: Please read before posting!

### Delano · 2005-04-05 15:34 · #B190647

Before posting questions, please check to see if your problem has already been answered, as it saves developers and moderators a lot of time when monitoring the forums. The Toolkit's help files were completely rewritten for 3.0.6 and contain a large amount of information on the TK, along with many troubleshooting solutions. This material is also included in the 3.0.6 download under Help -> User's Guide (F1).
- Browse other posts on the page for similar topics.
- Use the forum's [Search](http://www.toolkitzone.com/forums/search.php) tool to bring up similar posts in this forum.
- Read the Toolkit's help files: <http://tk3.toolkitzone.com/help/>
- Frequently asked questions: <http://tk3.toolkitzone.com/help/?page=23>
- Technical issues: <http://tk3.toolkitzone.com/help/?page=25>
- Read user-submitted help [articles](http://www.toolkitzone.com/library.php) and [resources](http://www.toolkitzone.com/index.php?id=2).
If you're question is not answered in these resources, please post with a descriptive title and as much information as you can.
