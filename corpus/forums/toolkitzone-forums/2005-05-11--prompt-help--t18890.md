# Prompt Help

### SonodroidStar · 2005-05-11 14:39 · #B206033

How do you make #Prompt so that it only has two options like yes and no
It would be of great help if you helped me, Thanks much

### thing · 2005-05-11 15:55 · #B206057

A #prompt isnt' the best way to do that, you're better of using an mwin, e.g.

**Code:**

```
#mwin("So whats the answer?")

#mwin("Answer with Y or N")

#done!=0

#while(done!=0)

     {

     #wait(a$)

     #if(a$=Y)

          {

          **insert code for the answer yes**

          }

     #if(a$=N)

          {

          **insert code for the answer no**

     }

}
```

The while loop is in case the user presses a key other than Y or N.
