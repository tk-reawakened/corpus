### Walker-san · 2005-10-26 09:06 · #B266756

Okay I'm runnin off a very old printout (2.06) but RPGCode hasn't changed too awful much and if you're using 2.2b then it should remain the same.
#wingraphic("filename.ext") is what you want to change the mwin graphic.
the example pulled straight from the printout is:
#MWin("Here we are before the background is changed.")
#WinGraphic("mwin.bmp")
#MWin("Now with a snazzy graphic!")
#Wait(a$)
obviously we now have support for more than just bmp but that's the basics of how you use that. Problem I see with this program is that it won't wait for a key press between the first and second mwin commands. But that's old rpgcode examples for ya.
As for the position of the mwin....umm....i don't remember. this printout doesn't have the command for it, if it existed. #text along with #bitmap or #drawrect #fillrect would work, but you'd have to count pixels then.
And ONCE AGAIN...i'm pulling this off a really old printout I have. Before I get flamed and yelled at for how there are MUCH better codes to use and MUCH easier ways to do it, I can't help it. I don't have an uptodate command list for 2.x. The basics are the same though.
