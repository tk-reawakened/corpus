### brandan34 · 2005-08-20 11:20 · #B248272

*only instructions are:
*1) Set variable clock! to your starting time as military time * 60, (ie 0800 = 480)
*2) Set variable day! to 0 (just for purposes of initialization)
*3) attach this as a multitask program on an item (ie Clock.itm )
*4) put Clock.itm in whatever boards you want the clock to advance on / boards that
* you want to be affected by Day/Night

**Code:**

```
:start_cycle

#DoTime()

#CheckTime()

*#NPCEntry()

#Branch(:start_cycle)

#Method DoTime()

{

   #clock!=clock!+2

}

#Method CheckTime()

{

   #If(clock!==240)   {#DrawChange1()}

   #If(clock!==300)   {#DrawChange1()}

   #If(clock!==360)

   {

      #day!=day!+1

      #DrawChange1()

   }

   #If(clock!==1080)   {#DrawChange2()}

   #If(clock!==1140)   {#DrawChange2()}

   #If(clock!==1200)   {#DrawChange2()}

   #If(clock!>=1440)   {#clock!=clock!-1440}

   #If(clock!==360)

#Method DrawChange2 ()

{

         #AmbientRed!=AmbientRed!-clock[dimmer]!

         #AmbientGreen!=AmbientGreen!-clock[dimmer]!

         #AmbientBlue!=AmbientBlue!-clock[dimmer]!

         #ForceRedraw()

}

#Method DrawChange1 ()

{

         #AmbientRed!=AmbientRed!+clock[dimmer]!

         #AmbientGreen!=AmbientGreen!+clock[dimmer]!

         #AmbientBlue!=AmbientBlue!+clock[dimmer]!

         #ForceRedraw()

}
```

Thank winter moon. For more see his/her methods in the library.
