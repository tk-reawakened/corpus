# Fading images...

### Juggernaut · 2005-07-26 16:31 · #B238320

Well, this isn't too advanced but, I was wondering if there was a way to speed this method up a bit. I don't remember exactly how it went, but this should be close.

**Code:**

```
#Method ImageFadeIn(image$,x!,y!,width!,height!,speed!)

{

      fadecnv! = createCanvas(width!,height!)

      For(fadeim! = 0,fadeim! <15,fadeim! = fadeim! + 1)

      {

            setImageAdditive(image$,0,0,width!,height!,fadecnv!)

            drawCanvas(x!,y!)

      }

}
```

Like I said, some of the commands may not have the right parameters, but I assure you they are correct in the actual method, this doesn't run fast with large images, and it seems to run the same speed no matter how low Speed! is. Any help appreciated.

### William · 2005-08-03 16:43 · #B241215

Speed is not needed, since it doesn't do anything:

**Code:**

```
#Method ImageFadeIn(image$,x!,y!,width!,height!)

{

      fadecnv! = createCanvas(width!,height!)

            setImageAdditive(image$,0,0,width!,height!,fadecnv!)

            drawCanvas(x!,y!)

}
```

And you dont need the loop either. This is for speed:

**Code:**

```
#Method ImageFadeIn(image$,x!,y!,width!,height!,speed!)

{

      fadecnv! = createCanvas(width!,height!)

      For(fadeim! = 0,fadeim! <15,speed! = fadeim! + 1)

      {

            setImageAdditive(image$,0,0,width!,height!,fadecnv!)

            drawCanvas(x!,y!)

      }

}
```

the higher speed is the slower it will work. so make speed 1 for ultimate speed.
