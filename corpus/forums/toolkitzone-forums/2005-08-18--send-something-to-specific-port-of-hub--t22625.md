### Michael J. Hill · 2005-08-18 03:47 · #B247405

you're hub is likely configured as either 192.168.0.1 or 192.168.0.255 - you're PS2 should have one of those IPs, no matter what, unless the hub has a built-in firewall, if you enter the IP for the ps2 to send data to, it should receive it.

### bracken · 2005-08-18 04:33 · #B247418

But it does differ a little between setups. For example, my router is 192.168.1.254, and whatever device requests an ip first gets 192.168.1.1, and the next gets 192.168.1.2 etc... Find out what your computers ip is, (run ipconfig in the console will tell you i believe... but i'm not sure, I haven't done stuff like that in windows much lately, i'm sure the network config stuff in control panel will tell you too.) It's probably something like 192.168.x.x. Try pinging other consecutive address and see if that works. If it does, that should be the ps2.
