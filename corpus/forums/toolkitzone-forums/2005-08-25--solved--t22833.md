### Caliber Mengsk · 2005-08-26 14:46 · #B250390

Suggestion...
Rather then putting your connect information on every webpage that connects to the database, make a new file called dbconnect.php and dbdisconnect.php, or something like that. That way instead of typing in 3-7 lines of code to connect and disconnect, you simply type

**Code:**

```
Require(dbconnect.php);

*Your code here that uses the database*

Require(dbdisconnect.php);
```

Remember when you program with PHP, most servers are linux servers. In that kind of situation, if something isn't calling from the require/link/include command, it IS case sensitive, and will not work unless you use it correctly. The same does not apply to usernames and such.
