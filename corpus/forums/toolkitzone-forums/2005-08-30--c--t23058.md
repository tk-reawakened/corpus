### p90m16mp5a4 · 2005-09-02 03:52 · #B253032

STOP. Forget everything you *know* about C++.
C++ Is a programming language. You use software called "compilers" to compile the code you write. Then, you use a "linker" to run them. C++ is not a file. Most integrated development environments for the C++ language come with a compiler and linker, and many other things. If you want to learn C++, go to the bookstore, library, or read some tutorials online. You will need a compiler. It isn't something you will learn over night, or over month Sad

### Ersuis · 2005-09-02 22:14 · #B253250

If I remember correctly, the Microsoft C++ compiler can be downloaded from the Microsoft website. It's a damn good compiler (if you happen to be on Windows), and free. You'd just have to learn how to use it.
I hate to be pedantic, but Dev-C++ isn't a compiler. It happens to have a compiler with the distribution (MinGW, the Windows port of the GNU C++ compiler), but it isn't a compiler itself; it's an IDE, which is an important difference to note when talking about downloading compilers.
Don't get DJGPP; it smells of wee.
On Windows, I'd very much recommend downloading the MinGW compiler (http://www.mingw.org) and getting the Relo IDE (Google it, fool). Both are free, and Relo is an great IDE on Windows if you can't afford Visual C++.
