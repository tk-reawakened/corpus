You do realise any patches on the site, as they clearly state themselves, are for previous versions, meaning you just managed to downgrade your version of the Toolkit - congratulations! The version [3.0.6](http://www.toolkitzone.com/fileman.php?id=3&file=1058) is all you need, there are no patches for this release - it is the most recent. Furthermore, re-downloading software does not fix bugs, it'll be the exact same software every time.
As for your "problems", all seem to be user end problems and not software bugs. For example, when downloading tilesets you have to unzip them to your tilesets folder - otherwise you will not see them. And the whiteness around the character, you need to set the transparency colour. Please try using the search facility and the [help](http://tk3.toolkitzone.com/help) files to find solutions before posting endless lists, they have been answered many times elsewhere Smile.
