### Caliber Mengsk · 2005-09-07 13:59 · #B254931

Personally, Never even seen ===.
Doesn't make sense...
Now, there is a difference between = and ==.
= is to set something, say:

**Code:**

```
$bob = "My string";
```

And a double = (==) is for comparioson (best used in if/while), Something like:

**Code:**

```
If($Bob == "My string"){

//your if code

}Else{

//your else code

}
```

As for the != and !== is simply Not equal.
As well, if you are just looking in your if statement to see if something is set (Generally used for a form of some sort like login, or anything with a submit button) you can use isset(). Example

**Code:**

```
If(isset($bob)){

//your if code

}Else{

//your else code

}
```

Though, in any of the above statements, you do not "NEED" the else. But it is there if you need it.

### Ersuis · 2005-09-07 14:51 · #B254936

Reading from the PHP manual, it seems that === evaluates true if the operands are equal and of the same type.
By comparison, == only evaluates true if the operands are equal.
