### Colin · 2005-09-10 17:03 · #B256018

You don't need to be an administrator to do everything, but some things perform actions that require such an account. Changing the tips settings modifies the user account section of the registry. It is hilarious that an administrator account is required for this, but it apparently is. Getting in a fight requires that the fight plugin be registered. It tries to register itself when you run your game, but it'll fail if you're not an administrator, because this requires modifying the registry too.
The sad reality is that you can do few things practical on Windows without being an administrator.
