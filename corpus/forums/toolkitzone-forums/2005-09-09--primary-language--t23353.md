Hi I study Information Technology (software Development) at some private college, during which I get to choose an sd elective i.e a language to further study. My options are C, COBAL, Java or Visual Basic, I was wondering which one I should choose.
This is what I've come up with so far by process of elimination.
COBAL sorta sounds dead, so I won't do that.
Visual Basic sounds like it's microsoft friendly, so I'm not exactly keen on that idea, after reading Linus Torvalds' autobiography I've become rather intrigued with Linux.
Java sounds like it's more internet related thus it feels kinda limiting.
Therefore I'm thinking of choosing C. C's sort of the first language I know aside from pseudocode, so I'm quite biased atm so I don't really know the advantages of the other languages. But I think in the long run C would be more beneficial for me in ways other than employment prospects.
From what I heard C is a more difficult language to grasp than BASIC languages, therefore C should not be intended as a first language. Allow me to make a similie.
English is what I understand, the second hardest language to learn. The majority of people who speak english would say nah it's not that hard, it's easy and it makes sense. LEARNING ENGLISH IS NOT THAT EASY. I've only learnt to come to that understanding while trying to learn another language, Tagalog (the more universal language of the Philipines). If you were completely ignorant you'd say that learning tagalog would be harder than learning english. In fact Tagalog is extremely easy to pick up, word construction and word pronounciation is very easy to grasp, because the language is restricted to few rules and very little exceptions. For example vowels in Tagalog have only 1 sound, where as in english a vowel can take on various sounds which is dependant on preceeding consonants and following consonants, or even the formation of consonants create for different pronounciation of words e.g ti gives a shh sound like in motion, gh makes an f sound like in enough, ph gives an f sound like in elephant thus the complexity of English would resemble a far more difficult language to learn than Tagalog. But it's because of the complexity that makes English more of a complete language, one can express themselves clearer and communicate on a more precise level because the overall complexity of the language allows for effective and in some cases simpler interactions.
Thus from that similie it would seem beneficial to choose the more complicated language. Ofcourse I also plan on learning C++, which I've come to understand to be C with an extended vocabulary and more object oriented perspective to programming.
Any feedback would be appreciated if I should consider any of the other languages.

### Ersuis · 2005-09-09 14:38 · #B255616

If you can, learn them all.
C, for someone that wants to be a professional programmer, is probably the number one language to learn; it's sort of the "standard" language among programming languages now. On some occasions, I've even found documentation for languages other than C that made explicit reference to how things work in C. If you have no other choice, learn C.
Java was the future, six years ago. Give it a go, since the idea of byte-compiled code and compile once, run anywhere is a great feature. It's not just an Internet language, but the ability to run as an applet within a browser is distinctive about Java.
COBOL is dead, but that's all the more reason to learn it, if you plan on being a professional. There are millions and millions of lines of code still out there that have been written in COBOL with nobody to maintain the code, so you might be able to fetch top dollar for skills in a language nobody knows anymore.
Visual Basic is nice if you're working on Windows, since it makes it easy to create the graphical interfaces. It's fun, but take care that you don't get too caught up in it, since it's easy to lose sight of doing actual work in place of building forms visually.
Really, learn them all. All languages are useful to know, and it doesn't hurt to know more than one. Learn some BASIC-derived languages, learn some C and C++, learn some Java, learn a dead language, learn Python or Ruby, learn LISP or Scheme. One of my professors claims to have worked in 45 different languages over his career (and I believe him). They're all just tools in your toolbox.
Is your degree Information Technology or Software Development? At the university I atttend, they are quite different, with IT being the maintanence, networking and administration part of computing, while Software Development (as Computer Science) being the actual program of study to learn how to engineer software. While IT majors do often take a few of the lower CPS courses, the programs of study are different.
