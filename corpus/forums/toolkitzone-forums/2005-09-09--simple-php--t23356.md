### Xavier · 2005-09-09 16:11 · #B255641

It's good to learn the basics of coding with PHP first Smile. There is a key difference between = and ==, the former assigns a value to a variable, therefore always evaluates to true unless it's assigned false, and the latter compares two values and evaluates to true or false. Thus the very first statement is assigning "Aquarius" to the variable.
Use == in your if statements for comparisons.
