### Khin · 2005-09-21 13:06 · #B259089

**Code:**

```
colorRGB(sR!, sG!, sB!) // shadow color

PixelText(x! + 1, y! + 1, text$)// depends on the direction and distance of your shadow, this one has light at northeast

colorRGB(fR!, fG!, fB!) // forecolor

PixelText(x!, y!, text$)// real text
```

Alright, here's a method for that...

**Code:**

```
method drawTextDropShadow(x!, y!, xDistance!, yDistance!, sR!, sG!, sB!, fR!, fG!, fB!, text$)

{

   colorRGB(sR!, sG!, sB!)

   PixelText(x! + xDistance!, y! + yDistance!, text$)

   colorRGB(fR!, fG!, fB!)

   PixelText(x!, y!, text$)

}
```

If you're using TK2, you can't use PixelText, so change it to Text(), but mind you the x! and y! coordinates would change, as well as the shadow coordinates Confused
