in TK3, an always running thread

**Code:**

```
While (true) //AKA always run

{

   delay(1) //wait a second

   seconds! += 1 //adds 1 to seconds

   if(seconds! >= 60) //checks if it is 60 or greater (just in case it somehow gets above 60.

   {

      minutes! +=1 //adds one to minutes because there are 60 or more seconds

      if(minutes! >= 60)//checks for 60 or more minutes

      {

         hours! += 1 //adds one to hours

         minutes! = 0 //resets minutes because of hour roll over

      }

      seconds! = 0 // resets seconds because of minute roll over

   }

}
```
