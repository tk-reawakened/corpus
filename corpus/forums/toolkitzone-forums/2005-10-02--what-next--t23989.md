# what next?

### chasingxsuns · 2005-10-02 01:29 · #B261705

im working on rpg code. i want to get really good at coding, not so much visual stuff. and i finished the language features on the TK3 usersguide and now i dont know what to learn next. the language features dont seem to teach you very much, just the basics. and the next thing on the users guide list is the function reference...and i dont even know where to start on that. should i just start learning all the stuff on the function reference or something else?im lost on what to try and learn next lol. if you could help me, id really appreciate it.

### Talyn · 2005-10-02 09:21 · #B261759

Probably one of the best ways of learning is to start doing it. Try programming some simple stuff, like maybe a lottery style mini-game or a basic bank system. When you get stuck, you can then use the function reference to help you.
Another thing you could do is go to the [Coding](http://www.toolkitzone.com/index.php?id=6) section and pick apart someone elses program. If you come up against a command you don't recognise, look it up in the function reference.
If you start off with some of the three star programs, then work up as the 5 stars tend to be quite high level.

### DarkMoon · 2005-10-03 01:30 · #B261940

Right, the only way to get good at anything is practice. So, just start programming stuff. Start small, learn the basic codes first. When you learn them, you'll be able to look at complex codes and see that they're simply simple codes put together. Use your imagination. Coding isn't that hard if you really want to learn it and you take some time to sit down and do it. The most important thing is to have fun. Happy coding.

### p90m16mp5a4 · 2005-10-03 02:26 · #B261961

Make methods that have a few parameters, return some variables with methods. Make canvases and understand them. Make a dozen #For loops, make a Dozen #While loops, make #Switch and #If statements until you cant possibly not know how they work. If you know how those work, then you need to learn most or all of the RPGcode commands. How can you successfully finish a project if you don't know the tools that you have?
