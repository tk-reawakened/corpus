When using cookies, as you are, the commands relating to them must be sent before (or as part of) the header (<head></head>). The error message is telling you the problem, this file occurs after the header has been closed.

### Colin · 2005-10-04 23:18 · #B262456

Header refers to the part of the HTTP request before the content. It has nothing to do with the <head> tag. The problem is that once some content gets sent, the header can no longer be added to.
e.g.

**Code:**

```
<html>

<?php // header is sent by here ?>
```

You have two choices: put your PHP that requires modifying the header before any content  even a blank line  or use output buffering in a way that makes sense. In this case, you would do:

**Code:**

```
<?php ob_start(); ?>

<!-- whole page here and all the php you ever dreamed of -->

<?php echo ob_get_stream(); ?>
```

That solution is, however, somewhat lazy.
