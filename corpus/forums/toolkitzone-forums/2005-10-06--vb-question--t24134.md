### Levi · 2005-10-07 14:12 · #B263111

Where is check declared?
Telling by the code, it would have to be a global variable or you're not using the Option Explicit command.
Also if text1.text = check do you ever change text1.text? If not you could simply make check = text1.text.
But my thinking right now is that if you don't have check previously declared outside of a sub or function then your call inside the timer sub routine is a local variable that is destroyed after the sub is finished running.
Option Explicit, in case you don't know, does require that you declare each variable you're going to use. Which I don't see you doing. So based upon this code alone I can't help you.
