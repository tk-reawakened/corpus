### Mick · 2005-10-13 14:28 · #B264394

I was wondering...why can't one use an asterisk to comment something out on the same line as a command?
Why is this allowed:

**Code:**

```
hi$ = "Hello" //Hello reader

mwin("<hi$>")
```

But this messes up the value of the variable:

**Code:**

```
hi$ = "Hello" *Hello reader

mwin("<hi$>")
```

?

### Colin · 2005-10-13 21:53 · #B264450

Don't use the TK2 comment at all.
The asterisk just makes no sense on the side of lines; it is mistaken for the multiplication operator. In the example you've shown, this consequence is emphatically obvious. It is less obvious in some other places, but the problem is ubiquitous.
<http://tk3.toolkitzone.com/help/?page=23#faq_3.1> (Is the TK2 * comment still valid?)
