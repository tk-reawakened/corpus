# TK2 Tile?

### Telah · 2005-12-28 03:44 · #B283402

How do I make a tile's background transparent on Tk2?

### Talyn · 2005-12-28 09:26 · #B283452

Don't paint on it. If the pixel is still showing little grey and white squares, it's transparent.
When you first start the tile editor, every pixel is transparent. Any transparent pixels you want should look like that (or at least similar) when you're done.

### Hubert Cumberdale · 2005-12-28 19:26 · #B283529

Also make sure you place the tile on layer 2+, if it's on layer 1 it will still show up white and whatever ground tile you have won't blend in.
