### legomaster88 · 2006-01-25 14:29 · #B292260

It would take a lot of time, and you can't use the default systems, but it is quite possible. Instead of using the numbers in the character editor, declare each of that characters stats in a program. Like for a character named 'Bob' make variables like: bobFP, bobDP, bobHP, et cetera. Then, when you want to include commands like getFP, replace that with the variable. Hope everyone who reads this makes some sense out of it.
