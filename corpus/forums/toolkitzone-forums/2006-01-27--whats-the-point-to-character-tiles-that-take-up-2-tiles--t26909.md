### DoUBelievInFear · 2006-01-28 00:06 · #B292973

Actually, get your hopes up Neutral. l do it all the time Neutral. OK, l am assuming that you have successfully downloaded one of the character packages, right? If so, you are in the exact same boat as l was Neutral.
Here is how you do it, just scroll your mouse up to the big blank page with the drop menu, this is how you make new things, select a "Tile Bitmap". Ok, now, set the "Y" coordinate to "2" and hit "OK" Neutral. Now, place the images in there appropriately, do this by oppening up the folder with the tiles and using them just like you put tiles on your board (the easiest way l have found is to hit the black squeare to the right, this makes life nice and easy Neutral).
After you have the tiles in an appropriate place, just hit CTRL+A this is "Save As". Place the image in the default folder, because for some wierd reason it will end up there either way (even subdirectories of that one don't work Neutral). Repeat this to make each of those 'cut tiles' (by this l mean the tiles that appear to be 'cut' into pieces) a sepperate file. Then, go back to the place to make new stuff, and this time select "Animation". Be careful not to select "Tile Animation".
Now, assuming that you are creating the animation for a character, select the "Sprite" size (32x64) click in the middle of the screen and a new window will open asking you which file to add. Add one of the files you just made. Now, VERY IMPORTANT!!, hit the select button underneath the box with the color in it. Now, hit "OK" on the dialogue box, and select the outer portion of your image (only needs to be done once per animation). This will make that color (only on the border of the character) transparent so you don't have this nasty box around your characters once you are playing Neutral.
Hit the button to go to the next frame (top left, it is an arrow that points right) and repeat this process. Once you are done, hit CTRL+A and save your animation, the name should probably include things such as, the direction the character is facing, the action taking place, and the character that is performing the action. This will make it easier to distinguise between them later Neutral.
Hope this helped ya Neutral, if ya need help on anything else, l am still n00bin it at this, but am a very fast study Neutral.
