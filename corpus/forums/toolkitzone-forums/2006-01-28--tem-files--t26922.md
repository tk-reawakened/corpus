# .tem files

### micklo · 2006-01-28 12:56 · #B293080

everytime i try to load up my game, it says 'character file (start.tem) not recognised'. it then cuts to a white screen with a green square moving about. how can i overcome this problem?

### DrakeLord · 2006-01-28 16:37 · #B293102

You have to go into the Main Project Editor and click the tab: Startup Info. Then browse for the Initial Character File. And for the white board just browse for the Initial Board File.
You probably deleted the default character (which isn't bad). Thus making the computer have no start.tem to load.
