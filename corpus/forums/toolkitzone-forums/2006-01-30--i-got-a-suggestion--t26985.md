# I got a suggestion

### TK Game Boy · 2006-01-30 18:46 · #B293725

It's about the random number of steps before a battle starts.
It would be better if you made a variable for that. I thought about this after remembering FFI, where you're in this cave and the battles come at you like 1:70 steps or so but when you enter this small confined space, it changes to 1:20 steps or so.
A variable will help create a better illusion that there are more monsters inside a cave than the outter world.
