# fonts

### Lisha · 2006-02-12 20:19 · #B297257

I have a question on fonts:
If you use such-and-such font for your game, and a person who plays it doesn't have that font on their computer, does it change the font the times new roman or something? Like a website... if I used the font randsom on my website and a person who visited it didn't have randsom, the font would show up as times new roman. Is it the same way with games?

### vrn790 · 2006-02-12 21:07 · #B297272

Well, usually, when you give the person the game, the fonts folder comes with it. But, if you don't give them the fonts folder and the person playing the game doesn't have the font, then here's what happens:
Somewhere in your start program (or wherever else you did this), you have the "font()" command, which switches the default font with the one that you want to be used in your game.
If the person playing doesn't have the font that you chose for the font() command, the debug window will appear and the game will pretend that you never used the font command in the first place.
In that case, the default toolkit font will be the one that shows up in your game.
