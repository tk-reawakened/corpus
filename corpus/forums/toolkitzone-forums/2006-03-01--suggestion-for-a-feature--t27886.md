# Suggestion For a Feature

### sumkeep41 · 2006-03-01 22:49 · #B302622

I frequently use the Indent Wizard to organize my code. It's just incredibly helpful. I was thinking that it might be the same level of complexity to write a program that rearranged your code in the most streamlined way, not making code changes, just simply reorganizing it. I just think it'd be nice to have a program organize my code into the fastest executable way for me. Wink

### Plasmius · 2006-03-01 22:54 · #B302623

That's a really good idea, but I think it might be confusing for some people. If it changes your code in the way you're used to writing it, it would cause problems if you come back to the code and are completely unfamiliar with it. If something like this were added, it would have to tell the user exactly what it was moving in a preferably graphic way to prevent this from happening.
