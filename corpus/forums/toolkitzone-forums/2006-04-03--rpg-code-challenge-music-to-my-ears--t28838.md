Oh and yes rpgcode is easily used to make a media player.

Ain't that a media player right there? Granted it wouldn't win any contest.
matter of fact here is a simple media player.

**Code:**

```
//=====================================================

//

//  Basic Startup Program

//  ----------------------

//

//  Look for all lines commented as TBD (to be done)

//  to see what you should change.

//

//=====================================================

//=====================================================

// Preprocessors

//=====================================================

#include "system.prg"

//=====================================================

// Initial settings - you may want to change these

//=====================================================

font("Comic Sans MS")      // Initial font

fontSize(18)         // Font size

bold("on")         // Bold text on

menuGraphic("layout.gif")   // Menu graphic

winGraphic("mwin.jpg")      // Message window graphic

//=====================================================

// Clear the screen

clear()

loadMedia()

until (done!)

{

   // Draw the title screen

   drawTitle()

   text(17, 10.5, "play")

   text(17, 12, "stop")

   text(17, 13.5, "open file")

   // Run a cursor map

   cMap! = createCursorMap()

   cursorMapAdd(295, 180, cMap!)

   cursorMapAdd(295, 210, cMap!)

   cursorMapAdd(295, 230, cMap!)

   res! = cursorMapRun(cMap!)

   killCursorMap(cMap!)

   // Switch on the outcome

   switch (res!)

   {

      case (0)

      {

         #show(File$)

         mediaplay(File$)

      }

      case (1)

      {

         mediarest()

      }

      case (2)

      {

         loadMedia()

      }

   }

}

//=====================================================

// Draw the title screen

//=====================================================

method drawTitle()

{

   clear()

   text(1, 1, File$)

   // TBD: Set some graphic for your title screen (remove //)

   // Bitmap("title.gif")

}

method loadMedia()

{

   File$=Dirsav()

   #show(File$)

   mediaPlay(File$)

}
```
