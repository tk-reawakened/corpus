I got a whole bunch of work done last week. One of which was the bubble mwin, which is working flawlessly. I posted a topic in Screenshots because I was wondering which "style" I would use for it.
Another one is the bubble prompt (thanks to Moo of Doom for giving me a way of doing it so it actually works). The prompt is technically the mwin, but with a question, three answers, and a cursor map. It's used when a character asks a question. Like in some of the FF games.
