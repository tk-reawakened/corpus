### Scott92002000 · 2006-06-03 22:46 · #B324818

**Sharmandra wrote:**

> Is there a remove player command? If so, if you remove the character, then add him back to the team later in the game, wikll he retain his stats and equipment, or lwill he ose it all?
>

There are two codes for something like that:
RomovePlayer and DestroyPlayer
Their format is like this:
NAME: Remove player from team
FORMAT: removePlayer(handle$)
This command removes one player from your party. There is a maximum of five players at one time. Unlike destroyPlayer(), this command allows you to bring the player back in using CallPlayerSwap() or restorePlayer().
- handle$ is the handle of the player to remove.

**Code:**

```
// Remove Tano from the team

removePlayer("Tano")
```

-----------
NAME: Destroy Player
FORMAT: destroyPlayer(handle$)
This command removes a player from the party. Unlike removePlayer(), however, it destroys the players stats so you won't be able to bring back the character with restorePlayer().
- handle$ is the handle, or name, of the player.

**Code:**

```
addPlayer("Frap.tem")

destroyPlayer("Frap")
```

For more info on the various RPG Code functions...refer to the [RPG Code Function Reference](http://tk3.toolkitzone.com/help/?page=19&PHPSESSID=259450446a1457ed9f1b65802f261062)
