# the win9x bug....

### spoopryme · 2006-06-10 23:18 · #B326390

i dont know whats up here, but i am having problems with my character sprites being corrupted running the toolkit (version 3.0.6) under windowsXP pro!
i have tried saving the pics for the walking animations in every format MS paint supports, as well as 3 different screen resolutions. i even tried making move animations using frame in windowed mode as i dont have the extra crap installed to enable vsync. i did not have this problem pre 3.0.5, but some of the bugs in the earlier versions are too aggravating for me to go back a few steps.
now heres the kicker. i am using windowsXP pro on another, much older computer, with the same version of TK, and there is no sprite corruption! (i use the older computer to pre-process the various media, and the faster one was to test run the game...)
i am starting to think that it might be a video driver problem. both computers run ati radeon video cards, and i think the slower computer has much older video drivers. im not sure if both computers are running the smae version of directx, and since i am not fluent enough in driverspeak to know any better, simply cannot tell if that would be a cause.
either way ill toy around with stuff and get back to the forums with my results. many apologies if this has already been resolved, but i lack the patience to wade through more than about 10 pages of forum postings, and the search function was no help either.

### Mick · 2006-06-10 23:26 · #B326392

The only thing I can recommend is checking your color quality is at the same amount of bits (usually 16, 24, or 32) on both computers, and in your TK game's project settings. To check your version of Direct X, simply Start > Run > And type in "dxdiag" (without the quotes, ofcourse).

### spoopryme · 2006-06-11 02:04 · #B326449

discovered that the video driver i was using was in fact the native winXP driver that was installed when i installed windows, so i installed the version 5.10 catalyst drivers and now the character sprite is not a technicolor box, but rather a static-filled box containing several vertical lines that flash as the sprite moves around the field.

after running dxdiag on both computers, found that the driver is the same, and that they both have directx9c. on the computer that has the graphics issue, there is a file 'quartz.vxd' that has no info on the same line with it, whereas the computer that runs TK just fine doesnt have this file listed at all... maybe my directx install was corrupted? ill try to remove it and reinstall it and see if that helps...
