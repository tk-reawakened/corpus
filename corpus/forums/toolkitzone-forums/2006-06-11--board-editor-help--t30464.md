# Board editor help

### Earth Archer · 2006-06-11 23:00 · #B326665

Hey I m haveing major problems with the board editor, i cant get 2 boards to link together, I followed the way is tells you to in the Quick start guid! but it wont work!!! anything i mite have left out??? Confused

### spoopryme · 2006-06-16 14:13 · #B328137

click file, then new, then new board.
put some stuff on the board.
go to board settings (up top there...) then board information.
then in any (or all) of the link boxes there, enter the name of the board you want to link to. the complete name with the file extension... like start.brd not just start.
now go to file, then save as, then give your board a name that does not match any of the ones you have in the link boxes.
