# Windows Vista Beta 2 : A modest review

### Colin · 2006-06-19 21:59 · #B328981

Windows Vista Beta 2 is utter crap!
You may have remembered the screenshot I took to illustrate [overlapping windows](http://toolkitzone.com/stuff/files/226/Overlapping%20Windows.PNG) in Beta 1. Out of concern for your health, for Beta 2, I will present just one window (the grey outline is part of the window!):
![](http://img377.imageshack.us/img377/5594/ultracrappytitlebar2zh.png)
But there's more to an operating system than its look. To show my open-mindedness, I present this brief list of things that no longer work in Windows Vista and will not work in the final version (evidenced by Microsoft telling me to "purchase new products" in the installer in truly as obvious prose):
- MySql ( [example](http://209.89.134.24:8080/serenus/))
- Norton Internet Security, but you are encouraged to buy Microsoft OneCare!
- Microsoft Office 2003, unless you consider opening Windows Installer every fifteen seconds working
- Printer sharing from Windows XP to Windows Vista (only the other direction works)
- Just about everything else
Windows Vista also includes an interesting new "ratings" system, with which it will decide what software you can use (and not allow you to manually override it!):
![](http://img503.imageshack.us/img503/4102/ratings3vz.png)
(Higher is better.) My pretty good processor and memory are averaged to one, the lowest rating, because of the lack of "gaming graphics", whatever that is supposed to mean. And more amusingly, each time I refresh, my processor and ram fluctuate from three to seven. That is an extremely high margin of error.
Windows Vista is also quite possibly the first operating system to check if it's okay to do everything. Is it okay to open that folder? Is it okay to copy that file? Is it okay to open the control panel?  it's dangerous, you know. Is it okay to print to that printer?  the admin may not like it, you know. Is it okay to launch that program? Is it okay to uninstall Windows Vista? Is it really, really okay? Really, really, really okay? Hmm, well, is it really, really, really, really okay?
I gave up on uninstalling it if not only because the install took literally twelve hours (the Beta 1 install took only forty minutes!).

### Euix · 2006-06-20 03:46 · #B329070

I installed Beta 2 a while ago, I downloaded the [public beta](http://www.microsoft.com/betaexperience/default.aspx). You can find various betas of Office 2007 and Vista there.
Beta 2 of Windows Vista is really pretty horrible. It's irritating, cluttered, and full of useless, pointless things that seem to just be programmed in order to force people to buy new PCs so they can buy newer Microsoft products.
Here is my review...
Installation
I see others had problems, but Beta 2 installed fairly easily for me. I mounted the disc image to a virtual drive and had the installer copy files to a partition on a spare drive, then proceeded to reboot my PC and let the installer do whatever it had to do.
Security
Vista has the most annoying and frustrating security mechanisms i've ever seen in an operating system. After logging in, it gets difficult to do things like renaming, deleting, or moving files (even if they are on your desktop). Security is too simple to bypass, too. It's as simple as clicking a few continue buttons.
Interface
The interface for Vista looks pretty refreshing, but that's about it. The interface for the shell is now a bit strange. It feels quite cluttered to me. There's widgets and buttons everywhere, the "prettiness" takes away from the usability, at least in my experience.
What got really annoying was how much crap is spread throughout Vista. Everything seems to be "split up" now, for example - there is no longer "Display Properties", there is now groups like Themes, Screensaver, Personalization, Display Device Settings, etc. This was done for a few other groups as well (networking...).
There is also a ton more services, hogging memory and providing seemingly useless features... what is Microsoft aiming for? To see how pointless they can make Vista? I think it would have been better off with WinFS, Monad, etc... all of the features that they took out that actually served a purpose.
Conclusion
This is a poor release and I would wait for the next beta, or for the final release version. The security and interface give some annoyances, and the 'other features' seem to serve very little purpose, like the 'rating system' Vista has to rate your PC.
By the way, if you installed Vista and want to uninstall it, the fastest way is to probably restore your old boot loader (e.g. NTLDR from Windows XP) . If you use Windows XP, enter the recovery disc (or installation disc, then go into the recovery manager) and type in:

**Code:**

```
fixmbr

fixboot
```

After doing this, I deleted my Vista partition and I was all clear. THis might not be the safest way, but it was certainly fast and provided no problems.
