# Sabbath (Working Title)

This is a brand-new game from Joseph Gaston Productions. It is an official replacement to the Revenge of Vinnie series and is currently awaiting the release of 3.0.7 so that serious work can actually get done. The first chapter of the story should be posted by next Friday. FEATURES: -A brand new BS based upon FFX's CTB (the concept, not the graphics!) -New menu system (design yet to be determined) -New weapons system ASSISTANCE REQUESTED: -Graphics -Music -Programming (maybe)
