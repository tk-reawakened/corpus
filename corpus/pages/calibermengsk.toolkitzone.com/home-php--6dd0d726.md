I plan on users being able to upload 1-2 megs for images and such so that you can show off you stuff to anyone here. Personally, this will help further anyones experience here. Because I know that not to many places let you upload php scripts to be run off of a site. This means that any forums that you can link to useing HTML will let you run these scripts.
