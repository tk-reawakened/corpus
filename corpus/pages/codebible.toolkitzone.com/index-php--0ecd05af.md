Define Functions
To define a function you use the keyword "function" followed by a name for your function, and last any variables the function will ask for separated by commas between parenthesis. The code will be written in lines between curly brackets. Any code you write will be able to use the variables passed to the function which makes it very useful for converting a commonly used segment of code into one line.
For example:
```
function function_name(var1, var2, var3, ...) {
// Code goes here
}
```
Naming Rules
Function names, like names, follow the same rules. They may consist of alphanumeric characters or an underscore, that would be uppercase/lowercase A-Z, 0-9, and _; however, the first character must be a letter. [variable](/index.php?title=Variable&action=edit)
Naming Conventions
Certain conventions go into naming a function. They're optional to use, but are highly recommended as it makes your code much more readable.
Some examples of conventions are as followed:
Capitalize each word
```
MyFunctionName();
AnotherFunction();
```
Capitalize all but the first word
```
doThis();
doSomethingElse();
```
Separate words by underscores
```
some_function();
try_this();
```
Choose the right words
Besides how you write the functions it's also very important to choose what words you use wisely. Most coders name functions based on what they're doing and to what. If you follow this schemes you'll usually write a verb (action), followed by a noun. For example:
```
takeItem();
giveItem();
buyCandy();
```
