# Code Bible

Purpose
The Code Bible intends to provide the most complete and accurate reference to the scripting language. The primary objective is to give every function an easy to understand description, to inform as to what each parameter is for and finally to illustrate how to use the function with a usable code example. [RPG Code](/index.php?title=RPG_Code)
History
The most recent RPG Toolkit release adopted an automatically generated RPG Code reference with no explanation or code examples. This change led to great confusion among new and old users alike as it was difficult to not only determine what many functions did, but also what functions existed.
As the complaints mounted within the community a decision was made in late 2008 by the community webmaster, Xavier, to begin a wiki based project to address the issue. To ensure a smooth and consistant setup, he drafted the help of a limited number of community members who had a proven interest and knowledge of RPG Code. The users were Asimir, furyX639, Marz and zyrshnikashnu.
After many hours of entering and categorising the several hundred functions, the Code Bible was officially launched as part of the Zone Awards on Christmas day in 2008.
