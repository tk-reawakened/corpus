# No value is returned.

GetRes
Get the screen resolution. **getRes(** &x, &y **)**
Get the current game resolution (as set in the Main File Editor).
Parameters
The width in the x-direction.
The height in the y-direction.
Return Value
*No value is returned.*
Examples
```
getRes(width, height);
mwin("You are currently running at " + width + " by " + height + " resolution.");
wait();
```
