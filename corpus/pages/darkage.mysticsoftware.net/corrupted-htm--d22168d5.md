# Xorlak's Guide to Annoying Corrupted Files

Files occaisionally become corrupted and unusable when they are downloaded. If you are experiencing problems with a file downloaded here, try re-downloading it before e-mailing me. Often, this will solve the problem. Possible causes of corrupted files include resuming an interupted download or a bad ISP.
