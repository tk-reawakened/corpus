# Creator of Dark Age

Dark Age
Welcome to the Dark Age web site. Dark Age is a available to download right here, free of charge. Screen shots, character descriptions, game tips, and more compose the rest of this site. A preview of my current project, Dark Age 2, is also a main feature. *full game*
* -Xorlak
*Creator of Dark Age*
***05-01-2002![](Erik.GIF)***
First of all, I'd like to congratulate the 40% who actually beat Dark Age (heh...). April was another one of those months where I didn't have much time for Dark Age 2. Unfortunately, May looks like it will be more of the same. Some good news though: so far, there is almost an hour's worth of gameplay in Dark Age 2.
A few days ago, I also put up a new single installation file for Dark Age. This one shouldn't be missing any files.
***04-21-2002![](Darius.GIF)***
The Dark Age site is now hosted by [Mystic Software](http://www.mysticsoftware.net) ! Hopefully, this will be the last move for a long time.
***04-14-2002![](Vance.GIF)***
Well, I'm sure everyone has heard the fate of the Toolkit Zone by now. As a result, I had to temporarily move this site back to my old Angelfire account.
