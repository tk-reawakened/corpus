# This game is suitable for all ages

Rudolph's Adventure
*This game is suitable for all ages*
![](rudolph/screenshots2.jpg)
Game Designer: Sophia Y. Hsu
Battle System Programmer: Mike Young (MrG)
Time in Production: June 2002~Nov 2002
Game Status: (4.35 MB) (1.44KB) [Full game](http://www.tk-x.com/rudolph_adventure1.3.zip) [Battle system guide](http://gamestudio43.mysticsoftware.net/rudolph/Rudolph_bs.txt)
![](rudolph/screenshots1.jpg)
*The Story:*
As Rudolph the red nosed reindeer, you must recover the item that Santa has lost and save Christmas!
![](rudolph/screenshots5.jpg)
*Features:*
-Original tiles and graphics.
-Random items/map for each replay.
-Custom snowball battle system
-Custom status and item menu.
-25+ unique characters to interact with.
