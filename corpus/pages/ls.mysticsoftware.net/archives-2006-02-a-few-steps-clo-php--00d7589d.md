# A few steps closer

February 2006 - 22:48
I'm in a personal conflict here. I want to call this 2.0 now, but truth be told, there are some things that I haven't converted, nor probably will. There are a few system templates that I'll probably never run across, and as such, left them be. There's also the fact that my nav link update only applies to individual entry pages, but I'll probably leave it like that too. So, I guess it's safe to say that this is 2.0 now.
Changes since 1.9.0: 1) Individual Entry pages converted to new layout. 2) Banner added! (Okay, maybe I didn't need as much time as I thought I would. Finally adds some color to the site too.) 3) Nav links for individual entry pages. 4) All files are rebuilt in with a PHP extension. This will allow much easier tweaking, especially when I come around and replace the blogroll. (Making a new one is simple enough.)
To Do: 1) Push towards a 2.1 with some extras. 2) Do something about the blogroll.
