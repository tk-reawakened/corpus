# Took some time, ne? (Part II)

February 2006 - 00:12
Comments | | Posted in: , [0](http://ls.mysticsoftware.net/archives/2006/02/took_some_time_1.php#comments) [Post a Comment](http://ls.mysticsoftware.net/archives/2006/02/took_some_time_1.php#comments) [Anime](http://ls.mysticsoftware.net/archives/anime/) [Site](http://ls.mysticsoftware.net/archives/site/)
I bet everybody wonders if I have fun annoying people. I do. That's not the point of this though. It is at this point that I'd like to welcome everybody to Kangae Rourou version 1.8. Why 1.8? Easy, read: 1) I'm not done finishing the layout. The basic setup of this front page I had already built two years ago, and I spent the better part of a day reformatting it to work with movable type. 2) In concert with 1, there are elements still missing. Notably: I don't have quick comment access to front page posts. 3) Also in concert with 1, this is the only page that has been modified so far, but it represents the biggest milestone with regard to the new layout. 4) I haven't started one of my intentions, and that's really, more a laziness factor at the moment. I do intend to blog anime, just, in a bit. 5) I don't even have a banner yet. I guess you could say I rush converted, but brining a banner titled Rurouni no Hihyou to a blog titled Kangae Rourou, doesn't make much sense. 6) I've got to actually adjust the sizing of my blocks on the right and add a site block for pages that are non-MT generated, like an About Me page. 7) There are elements that don't display properly across all browsers (Firefox tends to slightly reduce the sizes of the right blocks, IE doesn't.) That, and I want to get the calendar centered in the block, but it was getting late when I finished up this far, so I didn't bother working on it yet. 8) I might still add some more features, give me time.
As I mentioned, I'd rather get myself started into anime blogging (even though it may seem oversaturated). To be truly conducive to that, I've still gotta make more adjustments. That, and I've also gotta play catch-up in a mid-season run. Unlike most of the other bloggers, I'll be waiting for subs. Which does afford me a little time. I'll come up with a list some other time, so, until then, I'll sleep, and plod along on finishing the layout to other pages. Eventually I'll make 2.0! Hmm....I need to add the links to my RSS feeds!
