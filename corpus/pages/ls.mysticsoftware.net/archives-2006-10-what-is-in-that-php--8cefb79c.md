# See Ayu. See Ayu run. See Ayu run into a tree!

What is in that jam? Do I want to know? - Kanon 2006 - Episode 2
October 2006 - 13:23
Comments | | Posted in: , [0](http://ls.mysticsoftware.net/archives/2006/10/what_is_in_that.php#comments) [Post a Comment](http://ls.mysticsoftware.net/archives/2006/10/what_is_in_that.php#comments) [Anime](http://ls.mysticsoftware.net/archives/anime/) [Kanon](http://ls.mysticsoftware.net/archives/anime/kanon/)
It just gets better and better. While you may be expecting an image related to the jam, I think this one is more amusing.
![See Ayu. See Ayu run. See Ayu run into a tree!.](/images/anime/kanon-02-00.jpg)
**See Ayu. See Ayu run. See Ayu run into a tree!**
They did the jam. What is it, some sort of weird narcotic? Must be, but I don't think I'd want to know. Then again, it'd end the mystery.
Yet another amazing episode! This one follows the game a little more closely, sorta. Elements like the opening dream sequence, Nayuki's asking Yuuichi if he remembers the path to the school, running outta the town, Ayu's "romantic" reunion, the faceplant into the tree, Shiori's plop of snow, and even Makoto's entrance. Those are done well adaptations from the game (that I can recall.) Unfortunately though, to compare with the Toei's series, I'd have to rewatch that again now, as elements are sliding outta my brain. Time for a storage upgrade!
Now, what are we going to do about our taiyaki thief? It seems all to convenient that you've got a cat coming up in episode 1, and now a dog in episode 2. What's she gonna use in episode 3? A duck? A squirrel?
What also amazes me are the increasing foreshadowing details. That "placemat" in the desk, at the top of the stairs, will become much more relevant in future episodes.
The school, I think is a 50/50 of KyoAni original and game layout. It definitely seems to work well.
And before I head off....did I mention that everybody seems much cuter in this run? (Note, as far as Kanon goes, my preference order goes as follows: Ayu, Shiori, Sayuri, Mai, Nayuki, Makoto. With the first 5 being pretty close in ranks, and Makoto not too far behind.)
