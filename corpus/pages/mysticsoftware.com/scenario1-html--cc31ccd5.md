> Problem:
> The existing centralized dispatch system was frequently unavailable due to network and system issues impacting production. The system was character-based and inflexible in its design and did not accommodate the client's growth (lack of salability). The system was not real-time and required each individual dispatcher to manually refresh their screens frequently to see what other dispatchers had done.
>
> ** Solution:
> Mystic Software designed and implemented a real-time distributed graphical dispatch system. The dispatch system was built on Windows NT using the MS SQL database with a combination of workstation client applications and a custom NT Service to facilitate branch-to-branch data distribution. Each branch office is capable of operating with or without WAN connections, communicating with the other branches on the network. Each client's workstation view of dispatches in progress is concurrently maintained. The system was designed for maximum flexibility, including dynamic definitions of all meta data, reconfigurable screens, screen layouts, status codes. etc.
>
> **Results:**
> Each branch was able to maintain productivity without being impacted by network and hardware problems outside their shop. Each branch was able to add more concurrent dispatchers, increasing responsiveness and productivity. The learning curve for new dispatchers was shortened.
