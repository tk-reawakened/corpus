# Mystic Software

Is there a program size limit?
Programs can be as long as you want. There used to be a 2000 line limit, but that was removed back in version 2.19b. I think the internal editor might still have the limit, though, so you may want to consider editing larger programs in Wordpad or one of the RPG Code editors available here.
