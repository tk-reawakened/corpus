# Mystic Software

How do I rip tiles?
The easiest way to rip tiles is to take a screenshot of the game (press Print Screen on the keyboard), paste the image into MS Paint and save it, then import the image with the Toolkit's tile editor (Import -> Grab Tiles). Of course, you'll have to make sure the image is aligned correctly. In some cases, you might find it easier to cut 32 x 32 squares (or 16 X 16 for ROMs) out of the image and import them singly.
