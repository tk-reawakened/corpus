# Mystic Software

How do I tag characters in battle like in Final Fantasy X?
This really depends on how you're doing your battle system. If you load temp variables for each character in battle, it will just be a matter of replacing the swaped character's values with the new character's values and redrawing the new player to the screen. Hmmm... with the default battle system I don't think this will work. You could try making a special move with #removeplayer and #restoreplayer to make the swap, but that might cause strange things to happen (might be fun to give it a try though, heh...).
