# Mystic Software }.net{

RPG Code Challenge -- Breakout
![](../images/uberbunny.gif)
Breakout (a.k.a. "Magic Ball" or "Arkanoid") is an old pong style game where the object is to deflect a moving ball with your pong-style paddle on the bottom of the screen into a bunch of blocks on the opposite side. Destroying all the blocks wins the game, but the catch is you can't miss the ball. ( . Warning: Very old DOS program!) The challenge? You've guessed it. The object of this contest is to create a Breakout style mini game. The original doesn't have to be matched exactly; it just has to involve hitting something into something at the other end, destroying it, bouncing back the first object, and repeating (heh...). As usual, no outside graphics/plugins are allowed. The entry must be in pure RPG Code and must run in TK2. [Example here](arcanoid.com)
The deadline is tenatively scheduled for May 29th, but from previous experience, judging a contest with just two entries is no fun! So I'm going to try something a bit different this time. After the 29th, the contest will continue to run until I get five entries (provided I don't get five entries by the 29th). If it takes four months, so be it!
