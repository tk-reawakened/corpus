**Get your game hosted FAST!**
If you know how to use an FTP program, simply FTP to using the username and the password , and upload your game directly to the site! Make sure you email me at after your done uploading though, or your game may never be listed. Please be patient when waiting for your game to be listed. I only update once or twice a month, thank you. Make sure to include the following when submitting an email... www.mysticsoftware.net ***games_new@mysticsoftware.net*** ***user***spyder@mysticsoftware.net
A. Your name and/or Alias B. The name of your game C. Whether the game is a demo or full game, and what version D. Filename (IMPORTANT!) E. Company name (optional)
**NOTE** *BEFORE you upload your game, we will not accept games that have not been setup correctly using either the Toolkit's setup utility (.zip, .tpk, or .exe (registered only)), or another setup utility (ie Install Maker). If you use a 3rd party setup utility, the game must be playable upon installation, without the need to install additional files, including the Toolkit. Trans2.exe and all it's required files should be included in the install.*
***All games must be created using the RPGToolkit, we do NOT host games made with software other than the Toolkit***
