# Mystic Software

Many people think that custom AI is just for cinematic sequences, but it can be used for more practical things. For example, maybe you want an enemy to be able to use a certain recovery spell if low on health, or maybe you want an enemy to be able to use a rage attack once his health is really low, that increases his attack speed and power. Well, now you can see that with custom AI you could do many things. Here is an example that makes the enemy use a "rage" attack when he has a mere 20 health left: #gethp("Source",enemhp!) #if(enemhp! < =20) { #if(rage!~=1) { #text(10,1,"RAGE") #rage!=1 } } #if(rage!=1) { #givehp("Source",50) #battlespeed(7) :selplayer #random(5,playattack!) #playattack!=playattack!-1 #curplayer$=playerhandle[playattack!]$ #gethp(curplayer$,curplayer!) #if(curplayer!>0) { #givehp(curplayer$,-50) #end } #branch(:selplayer) } #ai(1) Step-by-Step, this is what the program does: 1. Checks if it has less than 20 HP 2. If so, it gives itself 50 HP (this only happens once), then randomizes a player, then attacks them with 50 power (it will do 50, regardless of their DP). 3. If not, it runs through normal ai techniques with the #ai command. Just attatch this to an enemy as their "RPGCode guided tactics", and you're all set. Well, thats the end of this very short tutorial. -Dont_Think_So
