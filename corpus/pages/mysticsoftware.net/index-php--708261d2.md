# NEWS UPDATE

RPGToolkit 3.0.3 Released!
posted by Spyder on May 24th, 2004
The latest version of the Toolkit is now available at . There are way too many improvements in this release to list them all on the page, but here are a few of my favorites... - Added new optional Toolbar which has two main features; - No pause when moving to a new board. - Enemies no longer die with one hit. - Added support for the number-pad for movement, and for cursor maps. And plenty more! 3.0.3b has been released, with additions to the tile editor by Woozy CBM is planning on releasing 3.0.3c later today, which includes some additional stuff by Delano. [The Toolkit Zone](http://www.toolkitzone.com)
* 1. Allows you to view and sort programs, items and warps. You can then click one of them to edit the object itself, change the settings or remove. 2. You can set various display options such as always redraw all layers and have certain objects such as programs and items always be displayed.
