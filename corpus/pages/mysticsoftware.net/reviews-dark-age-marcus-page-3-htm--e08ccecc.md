Programming:

Well now come on lets do the math so far this game is brilliant this guy basically programmed his own bug solution so what do you think I'm going to say about the programming? Dark Age basically uses nearly every basic Rpg code command from the basic Mwin to the colour transparently. The code, which is probably used the most, would have to be the push and push item command it's used constantly and fits in well with the story and story sequence. Xorlak uses many more programs… and uh, ummm… Oh screw it he can probably program better than Chris Matthews himself he is using some of the most advance programs ever! He has got every thing! he has even programmed his own gambling machines and slot machines, I said it before and I'll say it again, you do the math!
