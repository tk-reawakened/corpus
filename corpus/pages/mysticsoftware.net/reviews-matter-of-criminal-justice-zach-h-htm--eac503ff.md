# Game:

![](../images/ms.png)
![](../images/updates.png)
Game:
Reviewer:
Score:
A Matter of Criminal Justice
Legendary Fox Productions
Zach H
20/100
Story:
2/5
There wasn't much to go on as this is a Beta, but the story at the beginning is actually kind of cool. There's not really enough gameplay to have had it develop though.
Graphics:
0/5
All of the graphics so far are from other tilesets. The characters from said tile sets weren't even given attacking, defending, etc. animations.
Bugs:
3/5
Some tiles that should have been solid, weren't. I consider this a pretty big bug.
Programming:
1/5
The only reason this was credited a point in this category is because there was programming. Very little though.
Battles:
0/5
Standard battle system that comes with the TK, no animations for characters.
Fun:
0/5
Wow, that took about three seconds to beat. I get a key card, walk into a room, then I'm done with it. Hardly Fun.
Originality:
1/5
Well, it get's credited some points here. The story line is pretty original, but all the graphics are ripped, so it looses points, also the battle system and menu system are un-original.
Final:
7/35 or 20%
You should know that this isn't worth the download. Hopefully the next version will actually contain some gameplay.
This review was written by Hyren, dated July 2, 2002
