# Mystic Software

Submit a Resource
File
Submission Guidelines
- File should be some type of resource that is either compatible with the RPG Toolkit or helps in RPG creation in some way.
- Make sure the filename doesn't contain any symbols (i.e. ' #, etc.). Keep it to letters, numbers, and underscores (_).
- RPG Code submissions:
- Should be a single program file (.PRG) or a ZIP file containing a collection of PRG and any auxiliery files.
- **Make sure you've tested your program** **and/or methods and have ensured that they work as advertised.**
- Readme files are nice if the program is large.
- Tilesets
- Tilesets compress nicely, so please ZIP them up to save us some space.
- Media, animations, and other graphics
- Again, a ZIP file is usually the best way to go.
- Articles / Tutorials
- Plain text format is preferred, but DOC format is okay.
- So far we only have a section for RPG Code articles, but we'll most likely expand on that soon.
