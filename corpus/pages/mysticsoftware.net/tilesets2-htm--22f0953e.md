Here you'll find TileSets For use with the RPGToolKit in *.TST format, downloadable in *.ZIP format, due to problems with saving using Netscape Navigator. There are not many TileSets here, yet, as this Site is pretty much just starting out. Help out and**submit your own** ! Any submissions are GREATLY appreciated! Just click on the screenshots to start downloading the files.
For more tilesets, check out ! [The Toolkit Zone](http://www.tkzone.net)

Moonews' Exile Set
Creator: Moonews

Moonews' Exile Characters Set
Creator: Moonews
Info/Rating: **
Details/Comments: Another set ripped from Exile III, this time it's the characters. Although the characters look quite good, the lack of usefull tiles (movement, fighting, defense, etc) and bad organization makes this set only useful for 32x32 enemies.
