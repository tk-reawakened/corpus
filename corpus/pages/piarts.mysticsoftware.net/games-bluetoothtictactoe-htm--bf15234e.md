# -Affiliates-

Bluetooth TicTacToe Title:
Mobile/cellphones Platform:
Arcade Genre:
: 2 Player/s
This particular program was actually finished around May 2006, but I was not able to release it in public. In fact I not allowed to release it in public since this was a paid project. However times have passed and I'm sure they've put the program to good use, seeing as they passed their thesis. Now you can enjoy the game for free. Please take note however that for the program to work you'll require a mobile device (cellphone) with Java MIDP2.0 installed and is bluetooth-capable. There's also no 1-player mode so you'll have to find an opponent to play the game. NOTE: Designed for mobile phones only. Screen size 175x175 pixels. Tested under Nokia 6600 series only. *was*
