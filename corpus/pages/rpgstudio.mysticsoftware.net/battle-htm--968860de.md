# Battle System

G. I tried a lot of battle system (bs) in my time with toolkit. First of all, I had the default battle system, that I don't like that much. And I had it for a long time. Until my first game was finished. After that I tried almost all battle system on the RPG Code Shack, but I didn't like them either. So then I made my first battle system, it was a text based battle system. But that wasn't that fun. So I wanted to create a game without a good battle system. Then I find Sophia's site: and in Rudolph's Adventure, I found a pretty good battle system created by Mr. <http://gamestudio43.mysticsoftware> So I tried it and I used it for one of my games. But now I'am still searching for a new battle systems, so every ides would be great.
