***Project Immerse***
What is Immerse? It's a new game engine that is currently in the very early stages of development. It will work along the same lines as the RPG Toolkit, but it will not be an RPG engine. Immerse is more, and less...
**Immerse is not:**
- Not a traditional RPG engine. No overhead views here!
- Not a replacement for the RPG Toolkit. The Toolkit will always be the engine for RPG games. Since Immerse is not for RPG games, it won't replace the Toolkit.
- Not tied to Windows. Immerse will be portable across many platforms, including Linux.
- Not anywhere near completeion
**Immerse is:**
- An immersive, first-person style engine. Something like Myst, but not so restrictive.
- Written in Java. Immerse will be a 100% Java Application. This means it will be portable, small and efficient. Java is far better than languages like C++ when it comes to Object Orientation, GUI development and networking.
- OpenSource. No code will be available until the first release, though.
[![Immerse now looks totally different, but this shot should give you some ideas...](images/immerse_shot1.jpg)](/disks/c/website/images/immerse_shot1.jpg)
So, Immerse is sort of a vague concept of an engine. Like I said, it'll be able to create first-person Myst-style games easily, but it'll be able to do a lot more. Fighting, ImmerseCode, Text commands (you could revert the whole thing back to a text adventure, if you wanted), and loads of other stuff. And it's all optional. You can turn any one thing on or off.
Immerse is in such early stages that it'll be interesting to see the direction it leads me in. Perhaps elements out of the RPG Toolkit could be lifted up and placed right into Immerse (ie Enemies could be compatible with the Toolkit, for example). Anyway, Immerse will become more defined as time moves on. Until then, just be patient. I will provide regular updates on Immerse on this site.
When will it be done? I'm sure I don't know.
