**is (was) version 2.10 frustratingly buggy? -- May 31, 2000**
Seems that 2.10 created more problems than it solved. And patch 11 wasn't that big of a solution, either. So, I dived back into the source code to see what the problem was. I have re-uploaded patch 11, hopefully with a solution to many of your problems. Some ppl are having problems with tkgfx.dll, the new graphics engine. So, the first patch 11 had an option to use the old graphics engine. That's sort of a clunky way of doing things. To prevent confusion, the Toolkit now automaticaly determines what graphics engine it should use. So, once again, you can select Hi-Speed or Internal Graphics Engine. The Toolkit figures out the rest. Some people were having problems with wav files. There was, indeed, a problem with the #wav command that is now fixed. Finally, some people were having problems with getting dialog.ocx working correctly. The solution is fairly simple. When you install the Toolkit, make sure you let it overwrite dialog.ocx and comdlg32.ocx (correct me if I'm wrong; I didn't have the problem, some people did have this problem and have found a solution). Anyway, sorry about all the troubles. Download patch 11 again and it should be a lot more stable for you. In other news, has been updated for the first time in a long time, and it's a major update. Also, Serafroggys has a new site .

Hi. I just fixed some bugs in 2.10 (simple bugs), but mainly a major bug with the board editor that prevented proper scrolling. As a consequence, you can download patch 11 to fix those things. **version 2.10 is here -- May 26, 2000**
It's here. Go to the downloads section and get it. A good number of bugs have been fixed, and the new graphics engine has been implemented. Some new features include: mp3 integration for sound effects (not background music), new commands, full Windows NT compatability (tested under Win2000) Not much else to say right now. Just go download it!
**status of version 2.10 -- May 17, 2000**
Version 2.10 (yes, I decided upon using 2.10) is coming along nicely. Hopefully it'll be released next week. The new graphics engine has been tested to be 27% faster than the old graphcs engine (on my Athlon 650). That's a pretty good speed increase. And good news for NT users (Martin!) Windows NT will now be able to use the hi-speed graphics engine as well. Yesterday I went thruough the Bug Board and printed off all the bugs. You don't have to worry about re-posting old bugs. I have them all on paper now, and marked according to their priorities. I hope to have the Very High priority bugs fixed for the next release (well, I'd like to have them *all* fixed, but we'll see). I have a new site to announce. The is the most comprehensive archive site I've seen yet. It's definitely worth a visit! I've updated the rest of the website, to fix the links and stuff.
