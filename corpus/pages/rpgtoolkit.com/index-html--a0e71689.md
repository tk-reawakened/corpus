# pressing on -- August 27, 2000

**pressing on -- August 27, 2000**
Wow! It's been awhile since the last update, but I've been very busy! I've been hard at work getting the registered version ready for production. I'm happy to say that excellent progress has been made. I have gotten the manuals printed off, and I only have now to get the CDs made. Hopefully I can begin accepting orders at the end of the week. Also, I registered Awesome Software as a business, but I've decided not to use that name anymore. From now on, the Toolkit is being produced under my own name, Christopher B. Matthews. Nothing much has changed, but it is just easier to do it this way. Some assorted news: MrX has submitted some music for the game dev section. Also, the link for Spyder's chat room has changed (it has been updated on the message board). I've got a few more things to do to get the Toolkit ready for shipping. Anyway, back to work!
**new stuff in game dev section -- August 5, 2000**
I have removed the link to the new board. It wasn't working out, and the votes for the poll show that the old board is preferred. I will likely set up the 'new' board as a suggestion board or something in the near future. Well, after spending a few days downloading D&C, I must comment Cyrus and Randy on a job well done! For those of you who haven't downloaded D&C yet, I highly reccomend it. And if 60MB is too much for you, you will be able to get one shipped to you with the registered version of the Toolkit (which is now finished apart from updating some of the manuals! It should be ready very very very very soon!) There are a few new rescource in the Game Dev section. The Head Taker has put together some guides on tile art, as well as some tiles to go with it. Also, you will find some music by Chris Reeves.
**message board, new D&C demo and other cool stuff -- August 3, 2000**
It seems that a lot of people like the new message board and a lot lot of people hate it. I have found that things seem to be getting a little out-of-hand with the new board. So, I have set the link to the official message board back to the old board for now. I have posted rules on the new board. I expect them to be followed, even though it is not the official board right now. And, of course, they apply to the old board as well. Anyway, to sort things out, I have set up a poll to see which board we should use. Keep in mind that this poll will not be the final word. Right now I'm leaning mostly towards the old board. Anyway, other than that, there is a nfew new things to mention: First of all, Cyrus has released Deceit and Conquest, Chapter 1. This is the latest version of one of the most worked-on games in Toolkit histroy. It is definitely worth a look! Click for more info. Also, D&C Chapter 1 will be released on CD packaged with the Registered Version of the Toolkit if you don't want to sit though a long download :) Also, there are some new sites to mention: KrazyGames Entertainment is , and Sunglass Software is .

I decided to try out a new style of message board. Follow the link to the left and tell me what you think. If people don't like it, we'll just go back to using the old board. **2.11 has been released! -- July 15, 2000**
I got a little impatient and just released it. It doesn't have the movie editor that I promised, but it's got some good stuff. You'll find some new rpgcode stuff that we have been deperately needing for a long time, mostly to do with layers and graphics and things. There are also a lot of bug fixes. As I work on the registered version, I am also fixing stuff in the standard edition, so the Toolkit is really benefiting from all of this development. Anyway, read history.txt for a full explaination of the new stuff. You can download it in the downloads section. Also, Cyrus has released a new article on RPG design. You can find it in the game dev section.
**it's gettin better (man!) -- July 8, 2000**
Hi. I've been working solidly on bug fixes lately, so the next release of the Toolkit should be a bit more stable than we currently have. 2.11 is progressing well and will likely be released either slightly before or at the same time as the registered version (since both take advantage of the latest bug fixes and new features). Some things to look out for in 2.11: * The #Mp3 command plays mp3's without pausing the entire game. Plays a lot ike a wav file does now. * Layer specific put/mem/scan commands (at last!) * Hopefully, I'll be inserting a movie editor that will generate rpgcode for a sequence of jpegs and wav/mp3 files * A good lot of bug fixes Some other news: Psycopathic has released some player graphics. They are in the game dev section. Also, Chris Reeves has released a couple of midi songs that you can also find in the game dev section. Martin has officially opened his new site ( ). Anyway, that's all for now.
**cool demos and stuff -- June 26, 2000**
Hey, everyone! Yes, some demos were recently released. First of all, Arakis02 has released his excellent demo Mecha: Genesis. Also, Seafroggys has released his game, Blue Winds, another well put-together game. You can download both in the games section. New websites to mention: The website for Destiny's Path is , SpradSoft is . More news on the registered version-- I just finished writing an RPGCode debugger for it. Those of you who have used debuggers like those in Visual Basic and Visual C++ may find it familiar. Basically, it allows you to watch how your program flows as it runs, and you can modify the program itself while it runs. It's pretty cool. That means that the registered version will be ready *really* soon. I just have to put some graphics together and put together the first actual package and it will be ready for shipping! I'll be updating the registration section with some screenshots shortly.

**welcome newcomers! -- June 9, 2000**
Well, things have really been taking off lately as far as the size of the community is concerned. I'd like to say welcome to everyone new out there. Sorry if I haven't been responding to all your emails-- I have a lot these days! Anyway, as far as some news: I have nearly completed the upgrade feature for the registered version. If you purchase the registered version, you will have access to special upgrade files (.upd) that will keep your copy of the Toolkit up-to-date with the standard editition. There seems to be a lot of configuration bugs lately. This may be due to an incomplete installation. There are a few things you can do: 1) The Toolkit now comes with a batch file, ManualInstall.bat that will manually install the Toolkit, no questions asked. You might try running that. 2) You might want to copy the ocx and dll files that come with the setup program manually into your Toolkit2 folder. For some reason your system may not be looking at your Windows/System folder properly. As for community news, there is some to mention: Neo of has asked me to tell you that he will advertise our sites on his site. Also, GameSync2000 has moved to . Finally, you can get to Disrupter's site . And something else-- Project Immerse has sort of fallen by the wayside in the past few months. I'm going to start actively developing it again. If there are any suggestions, just email me.
