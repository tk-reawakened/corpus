# Registration for Version 3 is not yet available, but will be soon. Stay Tuned!!!

The RPG Toolkit 3, Community Edition, is a free product. But I offer a for-sale version to support further development. The Professional Edition is a way for me to give a little extra to users who want to give a little extra in return. Also, some users wish to have the option to sell their games. the Professional Edition includes a license to re-sell Toolkit games with the trans3 engine. The Professional Edition ships as a CD, and has the same system requirements as the Community Edition. Order the Professional Edition and enjoy these added features (more info will be added when version 3 registration is available): If you decide to register, you will have access to all of these benefits. You will also feel good in knowing that you are helping me develop newer and better versions of the Toolkit. I know it's the same old thing you've heard a million times before, but I believe that Toolkit users recognise the amount of work the Toolkit actually represents for me. And I know that most people don't mind paying a reasonable price for a really great program. Registration is not yet available, but will be soon. Stay tuned! Registration (RPG Toolkit, Version 3)

Professional Edition Features
- Includes CD and optionally a printed manual.
- Includes the source code for the Toolkit, as well as the menu and fight plugins
- Includes a royalty-free redistribution license so you can your games commercially. sell
- Create your own Windows EXE files with the Toolkit's EXE builder.
- Includes extra features in the editor to make game design easier.
Added Features
- You can debug your RPGCode programs with the built-in RPGCode debugger. It allows you to modify a program while it is running as well as modify variables and trace program flow.
- Auto-update allows you to install Toolkit UD3 (update) files to keep your copy of the Toolkit (version 3) up-to-date. These files are freely available on this website.
- Your files are protected with your own licensed serial number, so no-one can tamper with them.
- And, of course, the hundreds of features that already exist in the Community Edition.
- You get the warm, fuzzy feeling of helping out the developer :)
