# Registration

***Order Now!***
The RPG Toolkit, Standard Edition, is a free product. But I have recently started offering a for-sale version to support further development. The Powerhouse Edition is a way for me to give a little extra to users who want to give a little extra in return. Also, some users wish to have the option to sell their games. the Powerhouse Edition includes a license to re-sell Toolkit games with the trans2 engine.
The Powerhouse Edition ships as a CD, and has the same system requirements as the Standard Edition.
The registration option for the RPG Toolkit is now open! Order the Powerhouse Edition and enjoy these added features:
**Powerhouse Features:**
- Includes CD and printed manual.
- Includes the Toolkit's Source Code.
- Includes a royalty-free redistribution license so you can sell your games commercially.
- Create your own Windows EXE files with the Toolkit's EXE builder.
- Includes extra features in the editor for making game design simpler.
**Added Features:**
- The engine can play MP3 files as background music.
- Included is an RPGCode menu editor which allows you to design RPGCode menus visually (see graphic below).
- You can debug your RPGCode programs with the built-in RPGCode debugger. It allows you to modify a program while it is running as well as modify variables and trace program flow.
- Auto-update allows you to install Toolkit UPD and UDC (update) files to keep your copy of the Toolkit up-to-date. These files are on this website. [freely available](downloads.html)
- An extended version of the Jewel of Destiny demo game is included.
- Your files are protected with your own licensed serial number, so no-one can tamper with them.
- And, of course, the hundreds of features that already exist in the Standard Edition.
- You get the warm, fuzzy feeling of helping out the developer :)
If you decide to register, you will have access to all of these benefits. You will also feel good in knowing that you are helping me develop newer and better versions of the Toolkit. I know it's the same old thing you've heard a million times before, but I believe that Toolkit users recognise the amount of work the Toolkit actually represents for me. And I know that most people don't mind paying a reasonable price for a really great program.
Registration is now available! The price is only $39.95 (US), or $27.95 without the printed manual (the manual is saved in the CD in PDF format) which is pretty good, considering everything you get (including the royaly-free commercial license). All orders are shipped by air.
***Order Now!***
