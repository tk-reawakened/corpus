# TK3 Shots

The RPG Toolkit is one of the most advanced and complete RPG Editors available on the Internet today. Below are a few screenshots showing off some of it's features. You can see that there is virtually no limit to what you can do with the Toolkit. (Click on an image to enlarge it). RPG Toolkit Screenshots
TK3 Shots
Version 2 Shots
[![](images/screenshots/v2/edit1_small.jpg)](images/screenshots/v2/edit1_big.jpg)
The main editor window. It's elegantly simple interface allows you to access all editing tools.
[![](images/screenshots/v2/edit2_small.jpg)](images/screenshots/v2/edit2_big.jpg)
The Tile Editor. The Toolkit features some of the highest definition graphics available for any RPG engine available.
[![](images/screenshots/v2/edit3_small.jpg)](images/screenshots/v2/edit3_big.jpg)
The Board Editor allows you to design the screens of your game. The board editor is one of the most advanced aspects of the Toolkit. It allows you to add extensive lighting effects to your game (note the shadows).
[![](images/screenshots/v2/edit4_small.jpg)](images/screenshots/v2/edit4_big.jpg)
A darkness effect has been applied to the board. The Toolkit's graphics engine allows for extensive use of lighting effects.
[![](images/screenshots/v2/edit5_small.jpg)](images/screenshots/v2/edit5_big.jpg)
The Character Editor features a wide array of stats and player graphics animations. All stats can be directly modified by you when the game is running though the powerful RPGCode scripting language, or you can opt to have the Toolkit take care of them for you.
[![](images/screenshots/v2/edit6_small.jpg)](images/screenshots/v2/edit6_big.jpg)
The Toolkit's most powerful feature is the RPGCode scripting language. The Toolkit features one of the most complete languages in any RPG Editor today. You can take total control of graphics, lighting, player additions, menus, you name it!
