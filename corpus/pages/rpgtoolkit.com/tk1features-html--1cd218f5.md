# Software

**RPG Toolkit Development System, Version 1**
This is where it all started. The beginning of the RPG Toolkit. It's simple, yet powerful. It runs on pretty well anything. For a long time, this was RPG Toolkit Development System (now replaced with version 2). You will be impressed by the raw power this engine conceals. If you are looking for more power, better graphics and an easier interface, check out . **the** [version 2](tk2features.html)
**Features and Specs**
- System requirements: IBM Compatible computer running MS-DOS 3 or better. Windows 3 reccomended. *Any*
- Files can be read by Version 2
- Simple to use, DOS-based interface.
- Complete flexibility in game design with RPGCode.
- Internal fighting engine.
- Many enemies (250) and players (30) allowed in your game.
- game worlds. The size of your game is only limited by your available harddrive space. **Huge**
- Plays wav and midi files.
- Many many more features.
