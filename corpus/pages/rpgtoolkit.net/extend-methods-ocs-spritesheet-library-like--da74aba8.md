OC's Spritesheet Library
**Allows you to create animations out of a single image.**
1. About
2. Reference
3. Examples
Allows you to create custom sprite objects and animations out of a single image. You can control the sprite in a number of ways, and you can queue up animations.
It's very easy to use and can easily be implemented into any type of game.
