**Lets you make HTTP requests, letting you load a webpage or upload a file.**
1. About
2. Reference
3. Examples
Allows you to make HTTP requests from the RPG Toolkit. You can load a page using getURL or upload a file using putURL. Also includes the added ability to store and retrieve text from the clipboard.
Download has sample PHP scripts that show you how to make the plugin communicate with your web server.
