Notepad++ Autocomplete and Syntax files
**For those that use Notepad++ when coding, it adds support for all the rpg code commands and syntax colouring.**
This is an excellent addition for anyone who uses Notepad++ as their text editor of choice. It adds all of the RPG Code commands, as well as, defines RPG Code's syntax enabling syntax highlighting and auto-complete.
*Note: For Vista/WIndows 7 users you must install the userDefineLang to "%APPDATA%/Notepad++." Type it in the address bar of explorer and copy the xml file there instead of where the readme.txt specifies.*
