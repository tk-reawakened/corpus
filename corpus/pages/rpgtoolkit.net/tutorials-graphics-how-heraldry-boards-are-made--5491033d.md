**Tips on shading:**
If you're using Photoshop, you're in luck. I have some tips for you when it comes to shading. :) Photoshop offers a wide array of drawing tools for us to use. Among them are the dodge tool, burn tool, airbrush tool, paintbrush tool, and pencil & eraser tool. It has cool features too like layers and opacity. If you are shading, you don't neccessarily have to pick a color each time you shade. You have 3 options:
- Use dodge/burn
- Use layers/opacity
- Use brush/opacity
Dodging a color means lightening it. If you want a highlight, use dodge, if you want darkening areas, use burn. The tool has 3 modes. Experiment with it and learn to use it. This is the easiest as it automatically shades the piece for you. It can get useless sometimes because somehow the outcome isn't what you want.
Layers are your friend. I don't know the limit of layers in Photoshop, but i've tried up to 50+ i think and i didn't have problems. Create a new layer. Pick a darker color..or you can pick black. Adjust the layer opacity to a certain percentage. Start drawing on that layer.
You will see that you are actually shading the layer/s below it. Good thing with this is that if you made a mistake, you can easily modify that layer w/o affecting the rest of the pic..asuming they're on other layers. Normally i use 20% layer opacity..but it depends on the intensity of light. The higher the intensity, the more opaque it should be.
The last one is for brushes. Pick a brush(Air/Paint/etc.), adjust the brush opacity at a point. when you start shading(with a black forecolor assuming), the parts you stroke will be darkened. When you let go of your mouse, and again strike the same area, it will get darker. The concept here is that therefore repeatedly applying it at the same area shall cause the area to get even darker. **you aply a certain amount of black at an area**
The problem here is that you are working with one layer, so if you made a mistake the entire pic will be affected.
You can do combinations of the three.
And now, let me show you how I put a board into the game.
Draw the background pic. Alright, assuming I did this already and finished a background. **Step 1**
You should know that I don't use tiles. I use tiles for worldmaps, but for towns and dungeons I use images. I'm yet to use dynamic backgrounds though. For now, static backgrounds will have to do. I simply open up the board editor and set the board background to a specific pic: Of course i adjust the board's size to so the picture would exactly fit. **Step 2**
[![](http://www.icestormcity.com/piarts/bSnap1.jpg)](http://www.icestormcity.com/piarts/bSnap1.jpg)
I make the mask. The mask basically serves as the topmost layer in the game. It is very useful for places with sprite obstruction. Other TK game makers use threading in conjunction with canvases, but that won't work on scrolling boards and my boards are all scrolling ones. I save this mask then open up the animation editor. I put is as a single-frame animation and save it. Then I go open up the item editor and incorporate the mask as the default frames for the item. Save the item and all that's left is place it on the board. **Step 3**
[![](http://www.icestormcity.com/piarts/bSnap2.jpg)](http://www.icestormcity.com/piarts/bSnap2.jpg)

It was placed as an item which will not move anywhere. As long as my sprite, or any other sprites are positioned at a higher location than that item, we'll stay it. Try it on an npc. Create a 32x64 npc and try to move to its north side. You'll notice that the npc's upper part will cover your lower part. That's where I based the concept. **Step 3** *y* *under*
