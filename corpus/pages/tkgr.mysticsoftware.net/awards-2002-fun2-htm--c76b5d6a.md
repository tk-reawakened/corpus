# Alcatraz by Craig Reeves

> > Alcatraz by Craig Reeves
> > ________________________________________________________________
> > >
> > > ![](2002_tKgR_Fun_Award.gif)
> > >
> > > Craig's game is very impressive. The introduction let the player think it's going to be a very dark game, but actually the 'dark' story and character is quite realistic while the game in itself is quite fun. The very good thing is that quests are a part of the story... I think it's very professional. It makes the game longer, but not boring.
> > >
> > > [![](funawardSS3.png)](funawardSS3.png)
> > >
> > > The World map looks interesting, because we feel that from a very realistic story it could become a 'fantasy' adventure...
> > >
> > > [![](funawardSS2.png)](funawardSS2.png)
> > >
> > > But the greatest thing in the game is that the player always has something to do, it looks a bit like a game made from a movie - with gameplay elements added. Because there is a kind of 'tension' during the whole story.
> > >
> > > [![](funawardSS1.png)](funawardSS1.png)
> > >
> > > I think Craig has created a very good game, with many good things in it, but most of all his game is fun. And he didn't get the Public Award for nothing.
> > >
> > > Congratulations Craig !
