# Conclusion

> > Conclusion
> > I must say there wasn't any "best game" this year. Because 2002 was a great year, that really showed how different can be 5 excellent toolkit games. That was exciting to make the awards, because now I really look forward the RPGToolkit 3's release and what game-makers will be able to do with it.
> > I think our ever-growing community is going to make more and more popular games.
> > And I have one thing to ask : make free games. Because it proves you're doing it for fun. As an artistic creation. Together we'll be able to make the biggest ressource of free and artistic games. Games that *could* be commercial. But games that are *not* commercial. We don't need to make community games, because if we put all the tk games together, it'd be a great source of artistic creation ! All we have to do is to be friends and forget all the useless arguing in the community. Think about it - and imagine what we could build together.
> > And remember to think about Christopher B. Matthews and all the work he does to allow this. 2003 shall be a great year for TK games.
> > -Martin.
