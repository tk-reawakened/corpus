# > by Xorlak- -Dark Age

=============================================================
> by Xorlak- **-Dark Age**
> > >
> > > >
> > > > **| **KSNiloc** |**
> > > >
> > > > Now to be honest... when I first downloaded, installed, and ran it... I had my doubts... but no more! DarkAge is THE best game I've ever played I'm I can't wait for DarkAge 2!!
> > > >
> > > > Breakdown...
> > > >
> > > > **- Graphics 7/10**
> > > >
> > > > All original enemies which are wonderfully drawn... However the tiles are ripped..
> > > >
> > > > **- BattleSystem 8/10**
> > > >
> > > > When I first got into a battle during the opening sequence I thought: Oh not another drab game that uses the default battlesystem... But it really surprised me. Xorlak really jazzes up the BattleSystem with so many special effect. Special attacks some times miss or are ineffective! WHOA! What a job (done with the internal battlesystem). In DarkAge 2 I'm sure battles will be EVEN BETTER because Xorlak will have complete control over the system!
> > > >
> > > > **- Programming 9/10**
> > > >
> > > > The programming is stupendous!! (To Xorlak: Great stategy creating a blank character to make the board scroll!) The only bug is that in the opening sequence after a got the orb (even when I played through more than once), occansionally the last part would replay. Once I was controlls Mortis in the room where he steals the book from! But I only took off one mark because it was minor (and funny)!
> > > >
> > > > **- MenuSystem 6/10**
> > > >
> > > > The internal system again... but Xorlak has so many equippable items to get and use. PLUS pratically every item (upon use) is accompained by sounds (and or) flashing of the border! Unfortunently some items had problems, the DP gem didn't work...
> > > >
> > > > **- Music and Sounds 8/10**
> > > >
> > > > The wav files were REALLY good especially the murmor in the arena. The modified midis were just that: ripped MIDIs that were slightly modified.
> > > >
> > > > **- Implacation of MIDIs 10/10**
> > > >
> > > > The music was used perfectly... perfectly... perfectly. It really helped to create a nice atmosphere for the game.
> > > >
> > > > **- Characters 9/10**
> > > >
> > > > All the characters seemed to have there only personalities... especially Mortis: (Mortis quotes:)
> > > >
> > > > "Well I did say I was behind you" "Allow me to rephrase that: IT'S NONE OF YOUR BUSSINESS!"
> > > >
> > > > **- Plot 7/10**
> > > >
> > > > Interesting... many say that it's not great... personally I liked it although the main idea was just Vance trying to stop Mortis. But when the doom egg came into play it got better!
> > > >
> > > > **- Anticipation of Next Game 10/10**
> > > >
> > > > All in all... simply I CAN'T WAIT for DarkAge two. Voice your opinion in my poll on the DarkAge forum!
> > > >
> > > > **- Design 9/10**
> > > >
> > > > The caves were designed excellently! You had to do things like push rocks and venture off the path to take a bridge across. And of course the Dark Place.. oh it was wonderful!
> > > >
> > > > Wonderful!! **- Overall 83% A -**
> > > >
> > > > -------------------------------------------------------------------------------------------
> > > >
> > > > If there is a game with style and a fun plot it is Dark Age. I dont know whether it is the dramatic start or the fast paced gameplay but I would suggest this game to anyone who likes to have fun! **Xzar**
> > > >
> > > > **- Overall 9/10**
