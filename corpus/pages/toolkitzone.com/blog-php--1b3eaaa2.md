19 October, 2005
Hmm... I've been meaning to blog for a while, since some interesting things have happened. Nothing interesting enough to overcome my laziness though, until recently. A guy from Nigeria visited our laser tag arena a few days ago. He's planning on setting up a laser tag arena somewhere in Nigeria. He asked us some questions about the equipment, then asked if I wanted to go over there to help set it up. The answer was no. He didn't have all the funds he needed, and his suggestion was that we finance and own the place and he gets it set up and manages it. Since we only set up our laser tag arena about half a year ago, we're still a long way from making back that money, so it would be ridiculous to even look into starting up a new place. The Nigerian thing did sound interesting, and would've been worth considering if we did have the money, but we simply don't. It'd be rather exciting to go live on a completely different continent for a while too :p In other laser tag news, I've managed to hack into the system and edit the games in ways we're not supposed to. The system is really limited. They give you a few games to use, most of which have a few settings to change, and that's all. There's no way to create your own games, and you can't make any big changes to the existing games, so I've wanted to get into the code behind it and change some things that way. I had my first bit of success with that this morning. It took me a while to even find the game data on the system. The scripts behind the games were easy to find (and have the assembly source included with them) but the part that tells the system which games use which scripts, which settings the games use, and that the games even exist, is embedded in a huge database which I can't make head nor tail of. I'd pretty much given up on editing the games when I found an extra piece of software which came with the system (We received no documentation or explantion of the software. We were just left to figure it all out for ourselves) The program can export or import individual games from or to the database, so you can get your games as seperate files, take them to another arena, and install them there. I don't see much point in it really, since any 'new' game that are normally possible to make can easily be replicated by changing a few settings. The tool was invaluable for getting at the game's inner workings though. The file it created was just a zip file with a changed extension, so that was easy enough to get into. I couldn't get all the stuff to compress correctly again though. I have no clue what exactly the profile exporter is doing, but it manages to compress a certain file far more than any compressor I've used can. Anyway, the only file which I can't recompress properly is another zip file which contains the game script. Since I can get at that anyway once the game's imported, I don't need to do anything with that, so I can just replace the other three files in the zip. I wasn't sure if it might bugger the system up if I tried to import my edited profile, so I installed all the software on my laptop and went into work a few hours before we opened so I could plug all the hardware and the site licence into my laptop then try the new game. Everything worked perfectly, and I also fiddled about with a few variables which I didn't understand, and found out what they do. I've only made small changes so far, but now I know it works, I can start doing bigger things and creating entirely new games. It's gonna be neat :) We're only the second site in Europe to try this (or at least, the second one that the European Megazone headquarters knows about) and the first one to have success. I've had many other things happen which I wanted to blog about, but I can't remember any of them now. Crud.
