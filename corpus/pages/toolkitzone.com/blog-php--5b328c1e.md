# User Entries (1)

17 November, 2005
My current work on a set of Classes for a base 3D game engine using OpenGL and other APIs(not yet Implemented) is coming along very nicely. Ive got a basic optimized primitive structure including a Pipefan(Essentially a torus where all Rays(lines) point to an origon vertex) and a cube. So far the engine supports MipMapping, magmapping, multitexturing, mutiple texture formats, texture compression, antialiasing, anisotropic filtering, VBOs, three seperate proprietary formats for IVAs, has embedded display lists and backface culling. I have also including a Texture looping class(for texture animation), static and dynamic billboarding class, a camera class, a frustum class, and a heigtmap class, as well as a 3d Math and collision library. You can find an executable demo here. www.avengersoft.com/downloads/Level_Demo.rar I am very pleased with this initial engine. I also plan on addng my own transform and lighting pipeline and bumpmapping(Modified I can do it better and faster^_^) class next. Anyways as I continue to work Ill provide you all with updates.
