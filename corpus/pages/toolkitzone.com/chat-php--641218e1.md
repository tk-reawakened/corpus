**other**

**LETS GET CHATTING!**
**YOU MUST BE LOGGED IN!**
The chat room was heavily modified and adapted by from its original open source state by Joseph Monti. I would like to take this opportunity to say a huge thanks to John for finally ridding us of the awful Bravenet chat and giving us something clean, stable and customised to our community. **John@aljo**
**access**
Also, make sure you are logged in. The chat room uses your ToolkitZone account as your chatroom profile, so if you're not logged in you can't access the chat. Once logged in, simply click the button on this page and it will launch the chat. Note: You must access chat via this page otherwise it will not load, this is due to the integration with the database that requires information to be sent to the chat room. **If you can't access chat due to Java errors, then you will need to the Java Virtual Machine (click the button at the top right of the page). [download and install](http://java.com)**
**commands**
\help or \? - display this message \disconnect - disconnect from server \whisper - whisper to a user, a message no one else can read \private - start a private message session \ignore - ignores a user \clearignore - clear list of ignores \abuse - sends abuse report to moderators \reconnect - attempt to reconnect to server
