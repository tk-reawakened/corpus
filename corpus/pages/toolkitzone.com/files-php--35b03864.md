A menu creation system by comfox that is run from the Toolkit itself and requires no RPG Coding. Using building blocks called "cells" you can build the menu interface, defining the position and size of the cells, their type (image, button, text, variable, variable-defined image), and the value relating to the type (e.g. text literal for text type). The system uses a popup menu on mouse click which presents the various options such as create, edit and delete cells. Editing allows you to click a cell which brings up a further menu allowing you to modify its settings, you can also render your menu to preview its in-game appearence while editing it. When you're finished you can save the menu to file and then include it in your game how you wish. Comes with detailed ReadMe, covering all the features and how to use them.
