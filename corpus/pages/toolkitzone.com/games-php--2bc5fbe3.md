Well it has been awhile since I have posted anything for my game. Production has been slower than slow lately. It has been very hard to work on my game with work and absolutely no help at all. There are a couple of things that I would like to discuss. Battle System The battle system is taking longer then I thought it would. Right now it is getting absolutely nowhere. I have come up with a few new ideas for it. One is a Limit Break System kind of like the one in Final Fantasy VII. Also being able to upgrade certain weapons to be more powerful. Menu System The menu system is almost done except for the Equipment manager and the items page. I will post screenshots of the menu at a different time. Characters/Spriting This is absolutely getting nowhere. I cannot draw so it is really difficult to create the characters. I am not sure if I want to use ripped characters as it will not feel like I created everything. IF SOMEONE COULD HELP WITH THIS, PLEASE DO!!!! Story This is the only thing that is progressing satisfactorily. It is almost done. I am going on vacation soon so this is something that will be finished by the end of this month/beginning of next month. If I had to guess on a release date, or even on a demo date....I have no idea at all. Once again if anyone wants to help please do. Anthony -Black Diamond Sphere

Anyways, if you want I can lend it to you. How many player and non-player characters are planning to have?
