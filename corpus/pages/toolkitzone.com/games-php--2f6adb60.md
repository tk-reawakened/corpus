**Illicit Soul**
by venstor **Attempting to Change Versions Again...**
April 8 2005, 3:51 am
OK, I've finally figured out how to get the default battle system to actually run in TK3, which means upgrading Illicit Soul is for the first time feasible. Just dumping all the files from TK2 into their respective TK3 folders isn't working out so well, though. I'm going to have to remake most everything I've already done using TK3's editor, I think, and that's going to take a lot of time. TK3 also runs REALLY slowly on the old computer I've been using as my primary machine. (I have a newer computer that runs it fine, but I don't have access to it as often) I'm fairly certain that Illicit Soul will end up being a better game if I switch versions, but I'm not so happy about having to put so much work into the conversion. The actual version I'm going to end up releasing the demo in is entirely up in the air at this point.
