Time for another brutal round of Ultima C&C. Prepare yourself! You're using a traditional menu system reminiscent of The Dragoon. Your design is (generally) very coherent and easy to discern, thus making your menu system usable. Mission accomplished. First, while your design is coherent and easy to understand, you have a number of irregularities in font size; everything that's variable, such as Experience To Next Level (XPTNL) amounts, and for some strange reason the Magic command is in lower or mixed case, and the variable values are in a diffrent font than the rest of the menu, which is bewildering to the eye. Either stick with Comic Sans, or make everything the Serif font that you're using. Further, in the character profiles, the character name/character level subwindow are imperfectly aligned; while your level display is generally always in the same place, the names are in diffrent places, as if you're using a poorly tuned for() loop to draw the text. As for the actual profile images, while there is no real beef with showing the character sprite, it's generally accepted to use a more detailed drawing of some sort as a psychological trick so that when the player reverts to the map view, that they psychologically "draw in" those details on their perception of the player, so as to immerse the player in the experience more. Overall, this is a very good start to a custom menu!TBD
