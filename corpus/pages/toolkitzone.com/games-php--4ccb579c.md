Thoughts
This is one of those rare games that really showcases what can be done with the TK. Asimir created Pancake Stack as an entry in Geep4W's MonoPro contest, and it is simply wonderful. The graphics look a little strange. but you have to take into account that this game was done entirely in RPGCode. No external files were to be created (aside from save games or files generated by the program), so it was done exceptionally well. Lack of sound is understandable, and really didn't have much impact on my judgment of the game overall. It was a perfectly stable game, running so buttery smooth, with no noticeable lag at all. It had a wonderful length, and not once did I get bored playing the nine excellent mini-games. Best thing I've played from the TK in a long time.
