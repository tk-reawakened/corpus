**Project Techy**
by Caliber Mengsk **What Project Techy is About.**
November 17 2005, 2:51 pm
Project techy to put it simply is more when I am bored project.
When working on Mono-Max, it can get a little boring codeing and doing graphics for the same system after a few days/weeks/months, so I made this project to do in my "Off Time" of Mono-Max.
Currently, there isn't much to it, and at the moment, the battle system will not be working till at least tk 3.0.7, as the Item Location command doesn't work at all. This means you can kill without being anywhere NEAR the enemy. Of course, you can't do this in the "demo"... but you can attack. I will be working further on it to where it is a full real time system with jumping. I would also like to slow the game down for a magic system, but still let you move while choosing your magic.
This feature will more then likely not make it in the TK, as I don't think that slowing the game speed down will help much... maybe I'll be able to slow down the charactor speed and the game speed at the same time to get the effect, but I doubt it.
This is all I have time for right now... I'll update later.
