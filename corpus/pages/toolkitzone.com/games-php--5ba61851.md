eternal sphere project
**eternal sphere project**
by EB **Latest work.**
August 21 2005, 10:23 pm
Been working solid on the battle system the last few days which I have decided is going to use ATB rather than pure turn based as mentioned in the past. I also decided only the main character will be playable in battle (Eg: Dark Age 2), this allows me to focus more on some of the features I am working on which include: Combo attacks. Linking special moves. Customizable fighting style. (This allows you to almost create your own special attacks using the combo skill. You enter a combination of keys in a set time limit for either a default skill or a skill linked with magic spell.) Obviously plenty more than just that but I don't want to reveal too much for the time being. Basically having one single character in battle allows for more immersive situations rather than bland party fighting situations. Anyway, I'm not quite ready to post any shots so here are some teaser thumbnails. I've got another batch of screenshots upcoming, as well as some form of alpha/demo release in the near future.
