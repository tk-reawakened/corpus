# Browse

Posted on by (42 views, 2 ) Goals
**Sunday 9.28pm, August 27th 2006** **[Lisha](community.php?user=10048)**comments
Sheesh, I've been updating like god knows what lately, haven't I? Although, yet, I still don't have much to show. =( But now I really have something to say, something that will hopefully results in me actually having something to show. The following comment from Cuzit got me thinking: "Lisha and I are one in the same in the fact that we both have nothing to show for (not much, anyway) as far as our games go, but we've been working like crazy on writing projects." Which is true. That I work much, much more on my writing than on my game, I mean. And then I was asking myself, Why? True, I do enjoy writing more than I enjoy gamemaking, but that probably has something to do with the fact that I simply haven't done much gamemaking. =P But I finally came to a conclusion. All of the writing work I do in on e-serials, which I have to update every monday, wednesday, and friday. It's an obligation, because people actually read the story (well, at least, some do) and if I don't update on those days, then I'd be letting people down (maybe). The results is that I (usually) get my chapters done. With this game, however, people aren't playing it as I make it. Therefore, I don't really have an set goals. I think that if I did, then I'd work much, much better. If I'd had goals since the beginning, the game would probably be almost done by now. So I'm starting to set specific goals for myself now. Current goal: I want to finish all planning for the barn section of the game by next Sunday, 1 week from today. If I don't, whack me over the head with a cello. No more updates until then. I'll give you all a break from my near-spamming showers of updates.
