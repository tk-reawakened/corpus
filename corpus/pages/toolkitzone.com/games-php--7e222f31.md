The game demo will be released some time this week. I need to go through a few programs and reedit them since I changed a few features. You will run into a few errors, but notthing Major. Now, the game is based on days. The demo will go up to day 7 of the story line, then its the end. When and if you download the demo, please let me know of any errors that may have occrued while you were playing so I can quixkly correct it. Also, please give me any feedbacks for the game. The game will be uploaded in 2 ways. The first will be the full file, for those with fast connection speeds, the other will be in 3 chunks. Info about that chunks will be posted on the website when I have created the chunks. The Chunk files though probably will be uploaded this weekend. -------------------- Known Gitchs in the demo Due to the lack of time, not everything I wanted added to Outsets is in it. The game will lack alot of stuff, but will include plenty of stuff to do in the game. Here are a few things that was planned for the demo that will not be released. - Slot Machines in Casino isn't added - Tutorials located on the computer hasn't been added - Item menu hasn't been programmed (You will not need the item menu anyway in the demo) - Animation for all clothing, except the default clothing, have not been created. (If you buy a new pair of clothin, the animations like diggingor watering will not play when you use that watering can or shovel) - Mining job isn't in the game, but the mining game is. (Check the mines) - Buried Treasure program hasn't been added Also, 5 Building can not be accessed in the game. - Libary - Yanto Stadium - NeoTech Store - Arcade (Big Yellow Building) - Club Fox - Also, the Big Roller section of the Casino isn't complete. You may enter it, but there will be notthing there. Now, for Errors Not mainy errors has been reported from the game, but their are a few gitchs. - Some times the background might just dissapear. To fix this, Press the "f" Button on the keyboard. - When accessing and exiting the menu, you can still move around, but buttons will seem like theu are not working (like enter, A, S, D, Space, etc..) This occurs because the flash movie playing in the game is set above everything, so once the flash movie stops playing, the engine acts as if you do not have the window selected. To fix this, click away from the game window(like, click the task bar or your desk top), then click the game window again. As more gitchs and errors occur, I will post them. I apologize for not fullying testing every inch in the game ^^..
