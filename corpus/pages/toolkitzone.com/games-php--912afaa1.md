# Sabbath (Working Title)

June 13, 2006, 11:00 am
Design
This is a brand-new game from Joseph Gaston Productions. It is an official replacement to the Revenge of Vinnie series and is currently awaiting the release of 3.0.7 so that serious work can actually get done. The first chapter of the story should be posted by next Friday. FEATURES: -A brand new BS based upon FFX's CTB (the concept, not the graphics!) -New menu system (design yet to be determined) -New weapons system ASSISTANCE REQUESTED: -Graphics -Music -Programming (maybe)
**Sabbath (Working Title)**
by phantom_x1986 **Starting Work**
June 9 2006, 2:56 pm
I'm finally going to start work on my brand new project known simply as Sabbath. Now, as some of the older members of this community may know, none of my games were ever that in-depth, cool, graphically awesome, or just plain good. This is what Sabbath hopes to change. I want this game to be a fully-featured TK game. I envision this game taking every possible advantage the TK has to offer. I want to use the programming language to create a powerful new battle system. I want to push the TK to its limits as far as possible. However, due to my apparent lack of skill, I need assistance. I humbly request for a few volunteers to add to my project team to help me out with the Graphics, the Music, and perhaps the Programming. I don't expect the "big" members of the community to help, nor do I expect an outpoor of support. To be perfectly honest, I don't really expect any help. But it would be greatly apprieciated. Please note that no TK work has been started as of yet. The only thing that is getting any work done on it is the story.
