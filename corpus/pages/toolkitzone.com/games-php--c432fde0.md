This is the Winter 2006 Expo Demo of the long awaited Eternal Sphere. Remember to download the patch listed in Technical if you are having speed issues, and as always, feedback is appreciated! Note: This is the same Demo that has been available at the Winter 2006 Expo for the last couple of weeks.
**Technical**
Please download the following if you are having speed issues with the Demo: (Most notably, speed issues with the Message Window.) KNOWN BUGS NOT LISTED IN README: (AS OF 17/12/06) ******************************** [+] Quest Book duplication bug upon re-entering and re-exiting Atlas caves after certain story scene. [+] Bug upon selecting "resume" in the menu after using portions of the advancement menu. Use [F] to exit menu if experiencing this bug. [+] Character slowdown when trying to enter Darkwood. [+] ATB charge speed issues on low-end machines. [+] Excessive frequency of random battles, this is more of a balancing issue. [+] Upon receiving the game over dialogue, resetting the game prompts you with a "slot error", this is a minor TK-related glitch.
