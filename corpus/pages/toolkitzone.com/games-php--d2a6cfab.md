Heheh... There's tons and tons to code. This CBS is about 60% done. I have about six programs feeding into it. One of those programs consists of well over a thousand lines of code. Here are a few things to get you started, though: Check into the character editor to get the statistics for your characters. Make some kind of method to set all the enemy and player stats into useable variables for the program. (i.e. ENE[1]!, PLYR[1]!) Prepare to use lots and lots of loops, so read up on those. Use square brakets in your variables. (i.e. ENE[1]! ENE[2]!) Because then you can make one program run for multiple variables by inserting a second variable into the brakets. (i.e. ENE[num!]!) Merge text variables with text. (i.e. ENEnam[1]$ + "_rest.png") Hope that helps! I start by laying down the graphics.
