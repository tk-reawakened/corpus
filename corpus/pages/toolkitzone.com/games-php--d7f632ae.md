# Browse

Posted on by (250 views, 2 ) Small update
**Saturday 5.54pm, November 1st 2008** **[Brad](community.php?user=1384)**comments
Hey all, hope everyone and their games are doing well. I mostly just wanted to pop my head in and assure everyone the game is moving along. Also, Aas I've been finishing up planning, there's some changes I figured I'd talk about in case anyone was interested. The biggest change is that, from a narrative standpoint, the game is no longer a comedy - it's now a drama. Not that the game won't try and make you laugh a little bit, but at the center of the game is a serious story of grief, pride, and sacrifice. So that should be interesting. I've also cut out a nice chunk of the game that focused on combat in order for the story to move faster. That also means the game will be shorter now - you can expect to finish it in a little over an hour now instead of closer to two. That also falls in line with a game design philosophy I want to continue to experiment past 3GNB I refer to "sit-size games" - basically, it's the idea of creating a game that is meant to be completed in one sitting. Also, the gameplay formula has been largely revamped. I don't want to bore you with the details, but it's something cool and different that is very simplified but also hopefully pretty fun and satisfying. It's still a RPG. And lastly, a bit of a graphics change. After some experimenting, I decided to go with large bitmap boards instead of traditional tile-based boards. It will largely still appear tile-based, and I'm still using a lot of the tiles I've shown, but basically I'm going to create a board in Toolkit, take a screenshot, throw it into Photoshop, and add a lot of lighting effects and environment details that can't really be done with tiles. My hope is that it creates a more convincing and interesting atmosphere. That's it.
