# The Dragoon

September 28, 2005, 7:05 pm
Demo
A Starflare Productions project that combines strategic and deep gameplay with an involving story to create an exceptional experience.
**The Dragoon**
July 18 2004, 12:51 pm
A half an hour demo from Revival Gaming featuring custom systems, excellent gameplay, and an introduction to the story of Davia and the Dragoon. If you are having any visual problems in the game, change your screen resolution to 1024x768 before playing the game. If you have Version 1.0 or Version 1.1, you can download this patch to upgrade your version to Version 1.2: http://www.toolkitzone.com/games.php?view=file&mode=comments&game=70&file=31 Version 1.1 Changes - Any "tkplug0.dll" problems should be resolved. Revival Herb loop fixed. Version 1.2 Changes - Bug in Battle System that caused the game to "randomly" close fixed. Battles occur less frequently. Small board bugs fixed. Battle System visual changes. Message Window problems fixed.
