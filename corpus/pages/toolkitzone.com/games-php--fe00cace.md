I have just downloaded this demo and I played it for about 1 hour. First impression: you really did a great job with it ! I gave it a 5/5 rating, which it really deserves. But I have the same problem with a (more minimalistic) battle system I coded for my game, maybe one can't avoid that battlesystems coded with RPG code will run rather slow so I didn't count this in for the rating. I'm looking forward to playing the full game, keep up the great work !
