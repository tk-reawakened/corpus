# filters

submitted by on 07 September, 2004 [machsprinter](forums/profile.php?mode=viewprofile&u=3204)
This is a program for an Item Fusion Shop, similar to the Synthesis Shops in Final Fantasy IX. It allows you to combine two items to create one more useful item. It works well and it looks great (see the screenshot) The only problem is that the code is considerably larger than it needs to be. If it was shorter and hence easier to change to your own needs, or if it was put into a method form, this would have a recieved a rating of 5. Note: This shop program only works on TK3
