# filters

submitted by on 16 November, 2004 [TK Game Boy](forums/profile.php?mode=viewprofile&u=304)
Rather odd set of voice clips consisting of the word "Question" and then different clips for each number. Not the most relevant set of sound effects ever, but if you're making a quiz game or mini-game - perfect! TKGB has also provided a little example program to play the relevant sound file after user input of a number.
