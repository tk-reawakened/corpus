# filters

submitted by on 22 December, 2004 [spitfire](forums/profile.php?mode=viewprofile&u=35)
If you're too lazy to make your own Menu/ Mwin, or you just don't have the skills or a good program to create a menu/mwin yourself, then this is a decent set for you to try.
submitted by on 09 December, 2004 [spitfire](forums/profile.php?mode=viewprofile&u=35)
Simple custom message window, allowing for display at the top or bottom of the screen and up to four lines of text that you can specify. You can include character profiles by naming the image the same as the character name you pass to the message window. Short and simple, good for new users to pickup and expand from.
