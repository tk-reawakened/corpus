# filters

submitted by on 05 August, 2004 [Gnarf](forums/profile.php?mode=viewprofile&u=374)
Simple position saving tool that you can easily implement into your game. Allows you to, at any time, save the current board, x, y layer positions with a simple command. At any point you can then use the second command to send the character back. Help document included.
