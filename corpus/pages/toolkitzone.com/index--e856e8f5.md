# filters

submitted by on 18 December, 2004 [Horizon](forums/profile.php?mode=viewprofile&u=50)
A simple but handy mwin. It is used similarly to the default message window, in that you add each line of text to the message window with a seperate line of code. Generally, this is an advantage over other custom message windows, as you can use other code between lines of text. It also has support for profile pictures, which is always a nice feature for an mwin.
submitted by on 02 January, 2004 [Horizon](forums/profile.php?mode=viewprofile&u=50)
Handy method for adding a fading text effect to your game, the program comes with each part described to help you understand the code. Customizable features include rate at which text fades and position on screen.
