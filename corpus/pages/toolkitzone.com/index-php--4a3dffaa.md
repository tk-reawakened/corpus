release 3.0.3
posted on 2004-05-24 15:24:57 by [cbm](forums/profile.php?mode=viewprofile&u=51)
Good morning, everyone. For everyone in Canada (and the rest of the Commonwealth, I would expect), I hope you are enjoying your day off! Vampz recently organized another open source release. I have spent the weekend merging the changes into the official source tree, and I am pleased to deliver version 3.0.3 ready for download. This is the second official release to use the contributions of open source developers. This time around there was help from Delano, Euix, Geoff, John@aljo, KSNiloc, Vampz, Woozy and myself. This version includes a lot of bug fixes, new RPGCode commands, and large improvements to the board editor and many of the other editors. Many of you will probably be excited to know that RPGCode now supports object oriented programming (Thanks, KSNiloc!) Read history.txt for a complete overview. I have re-released 3.0.3c, which contains all of Woozy's and Delano's changes.
