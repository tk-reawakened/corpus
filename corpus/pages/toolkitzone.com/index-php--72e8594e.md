# About Other

submitted by on 20 February, 2004 [Colin](forums/profile.php?mode=viewprofile&u=226)
Allows you to make save points so when you get a game over, have a spell or some other trigger you can use it to send you back to the last point specified as the send back point. I see great potential in many games for this code.
submitted by on 02 January, 2004 [DBZ FAN Y2K](forums/profile.php?mode=viewprofile&u=20)
RPG Code program that lets you create your own 3D objects with the Toolkit. Latest update allows you to define the colours used in the editor.
submitted by on 19 March, 2004 [Jer1400](forums/profile.php?mode=viewprofile&u=85)
Although a very cute program and worthy recognition, for most people this program would not run correctly. It uses Leuf's Read/Write plugin which doesn't seem to like WinXP. There are other Read/Write plugins out there that Jer could convert to such as mine. *wink* *wink* But still a very well demonstrated look of RPGCode Power!
submitted by on 07 September, 2004 [machsprinter](forums/profile.php?mode=viewprofile&u=3204)
This is a program for an Item Fusion Shop, similar to the Synthesis Shops in Final Fantasy IX. It allows you to combine two items to create one more useful item. It works well and it looks great (see the screenshot) The only problem is that the code is considerably larger than it needs to be. If it was shorter and hence easier to change to your own needs, or if it was put into a method form, this would have a recieved a rating of 5. Note: This shop program only works on TK3
submitted by on 29 September, 2004 [Koeran](forums/profile.php?mode=viewprofile&u=3617)
A small collection of programs, with the required images. It includes a bank with an ATM, a roulette table and a shares program. Only the ATM program is documented, but they are all fairly self explanitory. These could make a nice addition to any game in a modern day setting.
submitted by on 21 March, 2004 [Marc](forums/profile.php?mode=viewprofile&u=380)
This is an extension to the Supersayen program. Makes it that much better with status bars and all that good stuff. Wanna learn more? read the readme. he has a very good description of it.
submitted by on 11 January, 2004 [comfox](forums/profile.php?mode=viewprofile&u=27)
Somewhat bizarre program. It consists of a Triangle you create in 3d space. There is no readme but the options do rather explain themselves in the program. To move your triangle around afterwards use the directional keys. Nice effort by Comfox.
submitted by on 26 March, 2004 [Mick](forums/profile.php?mode=viewprofile&u=799)
A little adventurous and want to create a bunch of items that can be merged together into another item? This program does the trick, somewhat. Without the other stuff like the items and pictures he used all you see is a bunch of black squares. Worth a look into though and might lead to some new ideas.
submitted by on 02 September, 2005 [DarkMoon](forums/profile.php?mode=viewprofile&u=7310)
This program enables the user to add a cheat system to their project. The program includes cheats like: 'Heal', 'HealAll', 'Restore', and 'RestoreAll'. The logic is rather simple, so adding onto this program is a simple task.
submitted by on 17 September, 2004 [thing](forums/profile.php?mode=viewprofile&u=1072)
All the fun of etch-a-sketch in an rpgcode program. The uses are rather limited, but it's nice and fun.
