# my files

**about 'my files'**
The 'My Files' tool allows you to submit resources to the site which other users can view, download and comment on. The tool allows you to manage those files, sort them, filter them, update them and keep tabs on your most popular. The 'Stuff' feature allows any user with at least 100 posts to upload up to 1mb worth of files to use anywhere for anything! A great storage place for signature banners and the like.
**To access these features all you have to do is register with the site!**
