release 3.0.2 source
posted on 2004-04-29 21:21:43 by [cbm](forums/profile.php?mode=viewprofile&u=51)
I'm happy to announce the release of the 3.0.2 source to the community. This release is the culmination of the efforts of several open-source developers in the community. Delano brings significant strides in usable isometric movement for trans3. The isometric system in trans3 is now far more stable and fluid than it was before. John@aljo brings us some fixes to #CallShop and #Save, as well as a bunch of assorted runtime errors. #CallShop continues to require windowed-mode to work. KSNiloc offers several new RPGCode commands for direct file manipulation. This has long been the domain of plugins, but now file I/O is native in RPGCode. Vampz has rounded up some fixes for the Toolkit3.exe editor. He has made editing isometric boards more stable, and he has temporarily fixed the memory leak that has plagued the editor for so long. All changes have been merged into the official source tree, which you can download here.
RPG Toolkit source code that has been open-sourced generally falls into one of two licenses: A BSD-style license. The main TK3 distribution and the plugin SDK are released under this license. A derivative of the AC Open License. It's intention is to require source code changes to be re-released to the community. It's spirit is similar to the popular LGPL, however it has a clause that allows code originally released under the AC Open License to remain under the AC Open Licence. The interntion is to allow the plugin SDK to remain under a very open-ended license (the AC Open License), even though other released source code might fall under the more restrictive AC Open License Derivative (such as the Fight Plugin).
