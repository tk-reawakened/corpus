# toolkit menu

The RPG Toolkit is a Role Playing Game Editor and Engine. It's powerful. One of the most powerful RPG Engines on the internet today. With the Toolkit, a beginner can have a simple game up and running within 15 mintues of installation. A serious game can take months to complete. The Toolkit gives you the tools and flexibility you need to create your own game the way you want it. The Toolkit's philosophy is that the ability to create games should be accessable to us all. It's therefore easy to use, but it has multiple layers of complexity. You can get deeper and deeper into the inner workings of your game and customize it as much as you wish. The Toolkit does not shape your game. Your game shapes the Toolkit...
System Requirements
- Celeron 500MHz or faster processor
- 64MB or more RAM
- Windows 98, ME, 2000, XP or higher
- Monitor capable of running at 800x600 resolution (at least).
- DirectX 8
- An active imagination!
Features
- Editor
- Fully integrated development environment. All the tools you need are included.
- MDI interface allows you to edit more than one file at a time.
- Allows you to create a new game with a few clicks of the mouse. After that, everythign you need is right there, including:
- Tile editor
- Board editor
- Animation editor
- Player / NPC / Enemy editors
- and many more!
- Multilingual.
- Includes a setup wizard that allows you to quickly and easily package your game to be downloaded from your website.
- Includes a media player for listening to MP3's or other media while you work or for listening to the media from your game.
- Includes a large library of default media including graphics and music to use in your games.
- Engine
- Version 3 is backwards-compatible with version 2 games, so there is a huge library of legacy games to play.
- Huge game worlds supported -- the engine can handle anything your harddrive can hold.
- All characters and NPCs can be any size with any number of animation frames.
- Advanced scripting with RPGCode3. RPGCode is a scripting language that allows you to customize your game even further. If you want to do something, RPGCode will probably let you.
- Excellent multitasking system. Allows many things to happen 'simultaneously' in your game. Apart from moving NPCs and players around, this lets you run coundown clocks, simulate weather or run a real-time battle system.
- Includes everythign you need to make a game. You don't have to make your own battle system. You don't have to create your own menu system. But of course you can if you want to!
- Advanced plugin support
- Create your own menu system or battle system in C++, or use the ones included.
- Nearly all of the Toolkit's functionality can be accessed via the plugin SDK. This allows you to extend the engine's abilities with nearly unlimited success.
- Graphics
- Ability to create 2D top-down and 3D-style isometric games. And you can mix both styles in your game.
- Supports multiple resolutions (640x480, 800x600, 1024x768) and mutliple color depths (16-bit, 24-bit, 32-bit).
- Advanced 2D graphics engine sitting atop DirectX offers flexibility and . speed
- Cool graphics effects like parallaxing, zooming, panning, translucency.
- Lighting effects on boards create shadows or ambience.
- Multimedia
- Support for many graphics formats including JPEG, GIF, PNG, BMP, and many more.
- Many audio formats natively supported including MIDI, WAV, MP3, OGG, MOD, XM, IT and many more.
- The Toolkit has a large community of game enthusiasts supporting it. Meet new people on the forums, in the chat rooms or on the hindreds of Toolkit related sites. You'll get lots of help when you need it.
