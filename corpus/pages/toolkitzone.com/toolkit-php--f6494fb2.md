# toolkit menu

This is where it all started. The beginning of the RPG Toolkit. It's simple, yet powerful. It runs on pretty well anything. For a long time, this was the RPG Toolkit Development System (later replaced with version 2 and now version 3). You will be impressed by the raw power this engine conceals. If you are looking for more power, better graphics and an easier interface, check out version 2 or 3.
System Requirements
- IBM Compatible computer running MS-DOS 3 or better. Windows 3 or better reccomended. Any
- An active imagination!
Features
- Files can be read by Version 2
- Simple to use, DOS-based interface.
- Complete flexibility in game design with RPGCode.
- Internal fighting engine.
- Many enemies (250) and players (30) allowed in your game.
- Huge game worlds. The size of your game is only limited by your available harddrive space.
- Plays wav and midi files.
- Many many more features.
