# Click to enlarge

Three Guys No Beer
*Click to enlarge*
**Date Added**
1.0 Sunday 3.13am, February 17th 2008
This is the full game of Three Guys No Beer. Entering development in late December 2007, the focus of this project was to create a short but fun full game in a short period of time. The game features three different difficulties, and each one takes around an hour and a half to complete. Players should be aware that this game includes drug references, brief nudity, and strong language.
**Technical**
This game was entirely developed in 3.1. All graphics and code are original. Johnstein was the Lead Tester of the project, and Devastation created the sound effects. Players that experience black screen flickering should decrease their Hardware Acceleration through their Control Panel. Players running Windows Vista will need to run the game as an Administrator if an error occurs when the game boots up.
