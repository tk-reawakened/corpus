The RPG Toolkit is a free, open-source software application capable of creating 2D role-playing games. It was first released in 1997 by Christopher B. Matthews, but has been developed solely by the community in more recent years, spanning three major releases. It features a robust scripting language called RPG Code, as well as plugin support which provides users with additional functionality, hypothetically allowing one to create any kind of game they want. | | | | RPG Toolkit
