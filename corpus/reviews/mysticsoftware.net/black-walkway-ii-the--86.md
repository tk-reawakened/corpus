# Black Walkway II, The

> *Review by TKGB*
> The first Black Walkway wasn't such a bad game and it was pretty good. The graphics were very unorganised and some of the editing was done badly. So is the second part better? Oh yes it is. This game is the way the first one should of been. It's nicely planned and not bad looking at all. It still uses the default tilesets but alot of TK games are still good with the defaults, namely Chimerae Empire. Plot (1) - This game takes place 80 years after the first one. You play as patrick, the grandson of Mark. You start out by going to a cave and fighting Dark. After you do, you go home only to find out the king is dead. So do you just sit there crying your eyes out? No! You go and get revenge. -------------------------------------------------------------------------------- Art (1) - Little improvement in the art department. The tiles are all ripped but umlike the first one, it's nicely put here. Instead of the tiles from the Jewel of Destiny, he used RM2K tiles and actually placed them where they exactly need to be so everything looks like an actual place instead of just a big wopping mess. There are profile pics for the message windows but most of them are taken from Chrono Cross and not all of them are used well like a boy has Kid's profile pic and Kid is a girl. Besides some annoyances, the art is way better than the first one. -------------------------------------------------------------------------------- Music (1) - The music is still ripped and from the first walkway which is ripped but this music seems alot better fitted in this game. We got alot of music from other games and yet were found a place here in this game. The sound effects are the same as the first one such as when the enemy screams "UGH! I'm hit" in a teenagers voice (he). -------------------------------------------------------------------------------- Enviroment (1) - Here we go. The enviroment is the same as the first walkway but now it's spruced up. Everything is matched to the first part but with different tiles and neatly placed to actually look like towns. So what really made the difference was the use of tiles because I believe that even if the places looked good in the first game, they would still look unfit because the game used the tileset from the Jewel of Destiny so this gets a point. -------------------------------------------------------------------------------- Programming (1) - This game now has programming. What I mean is true programming besides #Mwin() and all that. Look at the message window. Nicely done. Also in the end of a battle, you get a stat report. There is even a fighting engine when you enter a gym, and yet the game still uses the default battle system which I suspect that all this programming comes from MS and the use of the programs available and that's what the other game needed. Glad to atleast have a helping hand here. -------------------------------------------------------------------------------- Characters (1) - FINALLY! Good solid characters that are true heroes unlike the nobody's in the other game. We got the prince Patrick trying to avenge the king, Dark the bad dude of the game, Elliot who is after dark and many others to meet. Now this makes the game more adventurous and exciting...at least for a TK game. -------------------------------------------------------------------------------- Menu (0) - Still the same menu. After playing part one, it's kind boring to me. The same gradient background and big lettering along with the buttons. I wanted something different. Oi and the game says that theres an error when equiping anything to Patrick so you gotta use the E button to equip. Not really good. -------------------------------------------------------------------------------- Fight (0) - If there is an available different BS for the gym, why does the game uses the same BS for the real fights? The gym's fight battle is way more fun than this one which outshadows the default BS. The enemies are ripped from all over the place and some are edited VERY BADLY like Dark is Crono from Chrono Cross but all grey with purple hair. BLEGH! Im gonna be sick. -------------------------------------------------------------------------------- Game Play (0) - You walk really great and battles don't jump all over you from every single step. Some of the stuff does make the game go slow, especially the conversations. For some reason the Mwin takes a couple a seconds to load every line of conversation. Example: Line 1 in this line takes a couple of seconds to load. Since it's big and red you know that is not all there is to the message. The second line comes in and you assume that is it for the message so you press SPACE to skip it only to see in a flash that there was more and if you are a curious person, you would want to know what that third line says so you quit and reload the game only to find out that the third line is useless to read. Oi. I find that really anoying. -------------------------------------------------------------------------------- Fun Factor (1) - Gameplay may suck but this game is great. This does has the adventure factor that every RPG needs to succeed. You encounter friends, enemies, and some weirdo trees (he he). The world isn't such a bad place either. You got towns designed with a great planning on it like the first town outside in the overworld. I think it's pretty neat the game used the L shape design and made the castle in the sky. It deserves a point. -------------------------------------------------------------------------------- Conclusion (7/10) - A real fixer upper from the first game. Though everything seems to be lazidly done such as default tiles and Chrono Cross profile pics but if that don't really bother you than this game is really good.
