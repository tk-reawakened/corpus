# Friends and Enemies

> *Review by TK Game Boy*
> Freinds and Enemies Reviewer: TK Game Boy Game Author: Composition Software -------------------------------------------------------------------------------- This is a great game with an original story and some dramatic theme into it and thats something I have never seen in any RPG game. Graphics- The graphics look good. I cant tell if there original though. The characters look like they have been worked on and put some thought on them. Media- From silly themes to that eerie feeling, the music in this games is probably the best that goes along with the scenes. Plot- Like I said. It has a dramatic theme into it. The way each of the character talks to each other is something out of 3D RPGs fitted into 2D. Programming- There aint a lot of fancy pograming in this game but it does the job, in some aspects anyways. Game Play- Good game play. The fighting is the default that comes with the toolkit and the speed is a little too fast. Fun Factor- This is a fun game but not one you would spend a lot of time in. It does have some great game play into it but not so much effort in many aspects. Bugs- There are little bugs in this game. When youre in the beginning on the game and you try to communicate with the box, it all links up together. This may be annoying but nothing to be concerned about. CONCLUSION- Nice game. Composition Software can really whip up a story (its too bad they no longer exits). Rating: 7/10
