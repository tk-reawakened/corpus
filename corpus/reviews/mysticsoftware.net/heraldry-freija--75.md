# Heraldry: Freija

> *Review by RPGAnalyst*
> Heraldry:Freija has the best graphics so far in all of the TKGame's DEMO roster. Not only is it beautiful, but I've never seen any other TK game with graphics such as it. It's also the first TK3 game to come out, so I'd give a for that. The first thing that is manifested is the gorgeous hand-drawn backgrounds. At first I thought it was scanned, but later I learned it was CGed directly in Photoshop. Great artistic talent to the artist. The sprites are good-looking too, but I'm hoping some isometric walking directions would come out sometime next release. Also, they've got a cool intro. It was released as a separate file though, as TK3 couldn't play files correctly. Not much to brag about. There's one outstanding soundtrack off the title screen, but after that you'll get a short melodic tune at the first board, then the default world map BGM at the world map. The game then turns mute at the city. I can tell for sure that the developers weren't focusing on music when they released this. The first release was bug-filled. Luckily, the team released a patch to fix these bugs. However, being in TK3, it is meant to have bugs, but these fon't account for the programming of the game, since they wouldn't be able to do anything about it(unless they opt to wait for the most stable TK3). I like the time system. It runs just fine. I also like the feel of the menu system, too bad it's unfinished, but the interface is easy to comprehend. No battle system yet, so I guess I'll be holding my full comments on programming when all important aspects are done. Just wander around and talk to people. And also...avoid hitting them! All the programs will stop working when you accidentally crossed paths with a wandering npc. I think this is a TK3 engine problem. Let's just hope the next demo will have that fixed. No one would dare say they'll never play H:F again when it comes out. Overall, H:F came down as an average game, but let's not judge the game by the demo. Afterall, if you were visiting the Pigments Arts website, you'll find out that the sole purpose of the demo is to test TK3 as well as the time system in the game...but reviews are reviews. Still this game is definitely one to wait for. **Overview**
